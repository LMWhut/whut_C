常量

程序运行时其值不能改变的量，现代说法分为四类：

① 字面量，指“源代码里直接写出来的值”，强调写法

② 符号常量，如 #define PI 3.14中的PI

③ 枚举常量，如 enum { RED = 1 }; 中的 RED

④ const 修饰的只读变量，如 const int n = 10;中的n

类型示例说明
整型字面量123、579、0123、0x1F十进制 / 八进制 / 十六进制
实型字面量3.14、2.5e3、.5小数形式或指数形式
字符字面量'A'、'a'、'\n'单引号括起来的单个字符
字符串字面量"Hello"、"C"双引号括起来的字符序列
注意 八进制以 0 开头（如 0123），十六进制以 0x 开头（如 0x1F）；0579 是非法的八进制（含 9）。
变量：程序运行时其值可以改变的量

程序运行时，系统为每一个变量分配一个内存单元，变量名与内存单元地址之间建立一一对应的关系。

引用变量名，实际上就是引用该变量名所对应地址单元的内容。

变量名　　 → 　　内存地址　　→ 　　内存单元中的值
例子 变量 x 存在地址 123456 的内存单元中，值为 15；
程序里写 x = x + 1，实际是取出 15，算出 16，再写回该地址。

变量初始化

在变量定义的同时赋予初值。

一般格式
数据类型 变量 = 初值;
示例
int n1 = 123;
int n2 = 456;

警告 未赋初值的变量，其值是一个随机数，不是 0。直接使用会导致不可预知的结果。
变量赋值
赋值运算符 =
变量名 = 表达式;

作用：将右边表达式的值赋给左边的变量。

  • 一个变量可以先后被多次赋值，但只保存最后一次赋的值。
  • 优先级：14（较低）
  • 结合方向：自右向左
int a, b, c;
a = b = c = 5;        // 从右往左：c=5, b=5, a=5
a = (b = 5);         // 等价于上面的单步
// (a = b) = 5;      // 错误！左边必须是变量

printf() 的返回值

printf() 函数返回一个 int 型值，表示实际输出的字符数（不含字符串结束符 '\0'）。

int n = printf("Hello");    // n = 5
int m = printf("123 + 456 = %d\n", 579);
// 输出 "123 + 456 = 579\n" 共 16 个字符，m = 16
失败情况 如果输出发生错误，printf() 可能返回一个负数，表示写入失败。
输入函数 scanf()
调用格式
scanf("格式说明", 地址表列);
  • 格式说明的含义与 printf 相同
  • 地址表列由若干地址组成，各地址之间用逗号分隔
  • 变量地址的表示形式：&变量名
  • 输入数据时，以回车、Tab、空格相隔
int n1, n2;
scanf("%d", &n1);
scanf("%d", &n2);
输入：123 ⏎ 456 ⏎ 或 ：123 456 ⏎
scanf() 注意事项
核心规则 若输入函数中包含普通字符，这些普通字符在输入时必须原样键入。
写法输入示例结果
scanf("%d,%d", &a, &b);3,4a=3, b=4
scanf("%d:%d:%d", &h,&m,&s);12:30:5h=12, m=30, s=5
scanf("a=%d,b=%d", &a,&b);a=12,b=24a=12, b=24
推荐 初学阶段，格式串里尽量只写 %d、%f 等格式说明符，不要加普通字符，避免输入时还要原样敲入。
例：两数互换

输入 a、b 的值，把 a 和 b 中的值进行交换。

#include <stdio.h>
int main()
{
    int a, b, t;
    printf("input a,b:\n");
    scanf("%d%d", &a, &b);
    t = a;
    a = b;
    b = t;
    printf("a=%5d\nb=%5d\n", a, b);
    return 0;
}
运行结果
input a,b: 100 20 a= 20 b= 100
%5d 指定输出宽度为 5，不足时左端补空格；%05d 则左端补 0。

整数除法与求余：最易错的两个运算符

⚠️/ 整除

两整数相除，结果仍为整数

5 / 2 = 2
-5 / 2.0 = -2.5

一旦有一边是实数，结果就是实数

⚠️% 求余

只有两边都是整数才能求余

5 % 2 = 1
-5 % 2 = -1
5.5 % 2 ← 非法 

int num = 123;
int a, b, c;
a = num % 10;         // 个位：3
b = num / 10 % 10;      // 十位：2
c = num / 100;           // 百位：1
复合赋值运算符
运算符表达式等价于
+=a += 3a = a + 3
-=a -= 4a = a - 4
*=a *= 9a = a * 9
/=a /= 5a = a / 5
%=a %= 6a = a % 6
 
int a = 12;
a += a -= a * a;
// ① a = a - a*a  → a = 12 - 144 = -132
// ② a = a + (-132) → a = -264
自增、自减运算符 ++、--

作用：使变量值加 1 或减 1。

➡️前置 ++i / --i

先执行 i+1 或 i-1，
再使用 i 的值

j=3; k=++j; → k=4, j=4

⬅️后置 i++ / i--

先使用 i 的值，
再执行 i+1 或 i-1

j=3; k=j++; → k=3, j=4 

int a = 3, b = 5, c;
c = (++a) * b;    // a先变4，c = 4 * 5 = 20
a = 3;
c = (a++) * b;    // c = 3 * 5 = 15，然后 a 变 4
注意 ++ / -- 只能用于变量，不能用于常量或表达式：5++、(a+b)++ 都是非法。
逗号运算符和逗号表达式
格式
表达式1, 表达式2, ..., 表达式n
  • 优先级最低（15），结合方向 从左至右
  • 执行时依次计算各表达式的值
  • 整个逗号表达式的值 = 表达式 n 的值
int a;
a = 3*5, a*4, a+5;      // a = 15，表达式的值为 20

int x, y = 7;
float z = 4;
x = (y = y + 6, y / z);   // y=13, 13/4=3, x=3
sizeof 运算符
两种格式
sizeof(类型定义符)
sizeof(表达式)

功能：返回各种数据类型或表达式所占的字节数。

表达式值
sizeof(char)1
sizeof(int)4（多数编译器）
sizeof(float)4
sizeof(double)8
sizeof('a' + 2)4（char 提升为 int）
为什么需要类型转换

✅类型相同

直接运算，结果类型不变

1 / 2 → 两个 int，结果 0（int）
1.0 / 2.0 → 两个 double，结果 0.5

🔄类型不同

需转换为同一类型再运算

1.0 / 2 → int 转 double，结果 0.5
'a' + 3 → char 转 int，结果 100

核心 C 语言中类型转换有两种方式：隐式转换（自动）和强制转换（手动）。
隐式类型转换（自动）

由编译系统自动完成，程序员无需干预。方向是：向字节数多（精度高）的类型转换。

规则示例
float → double表达式中只要有 float，一律先转 double：5 / 2.0 → 2.5
char → int字符参与运算用 ASCII 码值：'a' + 3 → 100
int → double5.0 / 2 → 2 转 double → 2.5
方向 char/short → int → unsigned → long → double，由低到高自动提升。
赋值表达式中的隐式类型转换

原则：右边的值会转换为左边变量的类型。

⬆️低 → 高

整型赋给实型：
值以浮点形式存储，大小不变

int i = 10;
float f = i; → f = 10.0

⚠️高 → 低

实型赋给整型：
直接截断小数部分（不是四舍五入）

int i = 2.56; → i = 2
int i = 2.99; → i = 2

警告 高精度 → 低精度可能丢失信息，使用时要特别小心。
强制类型转换
一般格式
(类型名)(表达式)
示例对比
(double)3 / 2       // 3 先转 double，结果 1.5
(double)(3 / 2)     // 先算 3/2 = 1，再转 double → 1.0

(int)3.6            // 截断小数 → 3
(int)(x + 7.4)      // 先算 x+7.4，再整体截断
(int)x + 7.4        // 先截断 x，再加 7.4
关键 强制转换只改变表达式结果的类型，变量本身的值及类型不会改变。
如 float x = 3.6;，(int)x 之后，x 的值还是 3.6，类型还是 float。
格式符与数据类型必须匹配
警告 printf / scanf 中，如果格式符与变量类型不一致，变量将得不到正确的数据，或输出乱码。
错误写法原因
printf("%d", 6 * fabs(-4));fabs() 返回 double，应用 %f
printf("%f", 6 * abs(-4));abs() 返回 int，应用 %d
scanf("%f", &d);（d 是 double）double 必须用 %lf
scanf("%d", &x);（x 是 float）float 必须用 %f
养成习惯 写代码时，时刻问自己：这个数据是什么类型？应该以什么格式输入输出？
浮点类型数据处理
类型字节数有效数字输入 / 输出格式
float47~8 位%f
double815~16 位输入 %lf，输出 %lf 或 %f
输出说明
  • %f：小数形式，默认 6 位小数
  • %e：指数形式，如 1.234560e+002
  • %g：自动选择较短形式
  • %m.nf：宽度 m，小数位 n
实型常量 十进制小数形式必须有小数点（123. 合法）；指数形式 e/E 前必须有数字，指数必须是整数。
例：求圆的面积和周长
算法分析
  1. 输入半径 r（double）
  2. 计算周长 c = 2πr
  3. 计算面积 s = πr²
  4. 输出 c 和 s
分析 输入量：r；输出量：c、s；均为 double。 
#include <stdio.h>
#define PI 3.14

int main()
{
    double r, c, s;
    scanf("%lf", &r);
    c = 2 * PI * r;
    s = PI * r * r;
    printf("c=%lf,s=%lf\n", c, s);
    return 0;
}
符号常量 用 #define PI 3.14 定义符号常量，便于修改，提高可读性。
例：已知 y = |1 − x³·⁶|，输入 x，求 y
#include <stdio.h>
#include <math.h>

int main()
{
    double x, y;
    printf("x=");
    scanf("%lf", &x);
    y = fabs(1 - pow(x, 3.6));
    printf("y=%.3f\n", y);
    return 0;
}
要点
  • 用数学函数需 #include <math.h>
  • pow(x, 3.6) 求 x 的 3.6 次幂
  • fabs() 对浮点数求绝对值
  • %.3f 输出保留 3 位小数（四舍五入）
PTA 提示 输入实数时，不能要求小数位数；输出小数点后三位会自动四舍五入。
