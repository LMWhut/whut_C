二维数组

第 5 章（二）数组 · 二维数组
主讲：李　民
本讲内容
1定义与存储
由四组并列的一维数组归并为一张二维表，明确行下标与列下标的含义。
2遍历与转置
外层控行、内层控列；只在主对角线一侧交换，每对元素恰好交换一次。
3数组作函数形参
列数必须写明并与实参一致；行数另设参数传入。
贯穿例子 本讲以 int a[2][3] 讲存储，以 int score[30][5] 讲应用；鞍点一节标为选学，不作为考核内容。
引例：三十个学生，三门课程

某班 30 名学生，每人有学号和 C 语言、高数、英语三门成绩。需要按编号输出每人的四列数据。

/* 四组并列的一维数组 */
int id[30], c[30], math[30], eng[30];

/* 一张二维表：30 行，4 列 */
int score[30][4];
改用二维数组的原因 四组一维数组彼此独立，遍历时要同时维护四个下标，也难以保证四组数据属于同一名学生。写成 score[i][j] 后，行下标 i 表示学生，列下标 j 表示课程，同一名学生的记录落在同一行上。
适用场合 行数与列数都固定的数据适合用二维数组组织。本讲后续统一以二行三列的小表演示，便于在一页内完整呈现。
二维数组的定义
类型说明符　数组名[整型常量表达式1][整型常量表达式2];
int a[2][3];
第一维行数，此处为 2，行下标取 0、1。
第二维列数，此处为 3，列下标取 0、1、2。
元素总数2 × 3 = 6 个 int，共 24 字节。
a[0][0]
a[0][1]
a[0][2]
a[1][0]
a[1][1]
a[1][2]
读法 a[2][3] 读作「2 行 3 列」。写下标时先写行、后写列，顺序与定义一致。二维数组常被叫作矩阵，但它在内存中仍是一段连续空间。

地址以实际运行为准 每个 int 占 4 字节，相邻元素地址相差 4。第 0 行末尾 0x61FE28 与第 1 行开头 0x61FE2C 仍然相邻，中间没有空隙。地址由系统运行时分配，具体数值每次可能不同，此处取某次实际运行的结果。
数组名、行名与元素地址
写法地址值含义
a0x61FE20整个二维数组的首地址，也就是第 0 行的首地址。
a[0]0x61FE20第 0 行的名字，代表这一行首元素的地址。
&a[0][0]0x61FE20第 0 行第 0 列元素的地址。
a[1]0x61FE2C第 1 行的名字，代表第 1 行首元素的地址。
数值相同，含义不同 前三行地址值都是 0x61FE20，但 a 指整张表，a[0] 指一行，&a[0][0] 指一个元素。跨过一行要加 12 字节，跨过一个元素只加 4 字节。
与一维数组的联系 a[i] 是二维数组第 i 行的名字，用法与一维数组名一致；a[i][j] 才是该行中的第 j 个元素。
下标到偏移的映射
a[i][j]　等价于　a[0][列数 * i + j]
本例列数为 3：a[1][2]　等价于　a[0][3 * 1 + 2]，即 a[0][5]
要定位的元素a[1][2]，值 6。
换算先跳过第 0 行的 3 个元素，再在本行走到第 2 个，偏移为 5。
地址0x61FE20 + 5 × 4 = 0x61FE34，与表中第六格一致。
结论 编译器按此公式定位元素，其中列数决定每行的步长；这也是函数形参必须写明第二维的原因。
初始化的三种方式
int a[2][3] = {{1, 2, 3}, {4, 5, 6}};  /* 按行 */
int b[2][3] = {1, 2, 3, 4, 5, 6};       /* 按存放顺序 */
int c[2][3] = {{1}, {4, 5}};             /* 部分赋初值 */
a每对内层大括号对应一行，共两行。
b不写内层括号，按内存排列顺序依次填入。
c第一行为 1、0、0，第二行为 4、5、0；未写出的元素补 0。
补零的条件 只要给出了初始化列表，未写出的元素就自动补 0。若写成 int d[2][3]; 而不给列表，局部变量的元素内容不确定。
行可省，列不可省
int a[][3] = {1, 2, 3, 4, 5, 6};   /* 合法 */
int b[2][] = {{1, 2}, {3, 4}};   /* 错误 */
原因 编译器必须知道第二维才能计算 a[i][j] 的偏移。第一维可以由初值个数推得：本例 6 个初值除以每行 3 个，得 2 行。
与一维数组对照 一维数组 int x[] = {1,2,3}; 省略的是唯一的一维，编译器直接数出长度；二维数组只能省行数，不能省列数。
用 sizeof 求行数和列数
int a[][3] = {1, 2, 3, 4, 5, 6};
int rows = sizeof(a) / sizeof(a[0]);      /* 2 */
int cols = sizeof(a[0]) / sizeof(int);    /* 3 */
表达式结果含义
sizeof(a)24整张表占用的字节数。
sizeof(a[0])12一行占用的字节数。
sizeof(a[0][0])4一个元素占用的字节数。
适用场合 sizeof 只在数组定义仍可见的范围内有效。数组作函数形参后，它退化为地址，sizeof 不再给出整表长度，因此行列数要另外传参。
二重循环遍历
int a[2][3], i, j;
for (i = 0; i < 2; i++) {
    for (j = 0; j < 3; j++)
        scanf("%d", &a[i][j]);
}
for (i = 0; i < 2; i++) {
    for (j = 0; j < 3; j++)
        printf("%4d", a[i][j]);
    printf("\n");
}
循环的分工 外层变量 i 控制行，内层变量 j 控制列。固定一行后走完该行所有列，再进入下一行。输出时内层结束后打印一个换行，才能排成矩阵。
三种引用写法
for (i = 0; i < 2; i++)
    for (j = 0; j < 3; j++)
        scanf("%d", &a[i][j]);          /* 按行列位置 */

for (i = 0; i < 2; i++)
    for (j = 0; j < 3; j++)
        scanf("%d", &a[0][3 * i + j]);  /* 按偏移量 */

for (i = 0; i < 6; i++)
    scanf("%d", &a[0][i]);             /* 一层循环 */
三种写法等价 第二种把二维下标换算成一维偏移，第三种直接用一层循环走完六个连续单元。它们访问的是同一段内存，顺序与按行存放一致。
选择依据 需要区分行列时用 a[i][j]，例如求每行的和；只按存放顺序处理全部元素时用一层循环，代码更短。若第二维改变，第二种的常数 3 必须同步修改。
成绩表：按行读入并累计总分
int score[3][5], i, j;
for (i = 0; i < 3; i++) {
    score[i][0] = i + 1;      /* 学号 */
    score[i][4] = 0;         /* 总分清零 */
    for (j = 1; j <= 3; j++) {
        scanf("%d", &score[i][j]);
        score[i][4] += score[i][j];
    }
}
列的含义 第 0 列放学号，第 1 至 3 列放三门成绩，第 4 列放总分。score[i][4] 在读入前必须清零。

成绩表：输入、计算、输出
int score[30][5], i, j, m, n = 3;
scanf("%d", &m);
for (i = 0; i < m; i++) {
    score[i][0] = i + 1;  score[i][4] = 0;
    for (j = 1; j <= n; j++) {
        scanf("%d", &score[i][j]);  score[i][4] += score[i][j];
    }

printf("学号\tC语言\t高数\t英语\t总分\n");
for (i = 0; i < m; i++) {
    printf("%d\t", score[i][0]);
    for (j = 1; j <= n; j++) printf("%d\t", score[i][j]);

容量与实际个数分离 数组按 30 人声明，实际人数 m 由键盘输入，所有循环边界用 m 而非 30。这与一维数组的做法一致。
矩阵转置：只走上三角
for (i = 0; i < n; i++)
    for (j = 0; j < i; j++) {
        t = a[i][j];
        a[i][j] = a[j][i];
        a[j][i] = t;
    }
为什么 j 小于 i a[i][j] 与 a[j][i] 成对交换。若内层从 0 走到 n−1，每对会交换两次，矩阵回到原样。只走上三角，每对恰好交换一次；主对角线不用动。

矩阵转置：完整程序
int a[10][10], n, i, j, t;
scanf("%d", &n);
for (i = 0; i < n; i++)
    for (j = 0; j < n; j++) scanf("%d", &a[i][j]);
for (i = 0; i < n; i++)
    for (j = 0; j < i; j++) {
        t = a[i][j];
        a[i][j] = a[j][i];
        a[j][i] = t;
    }
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++)
        printf("%5d", a[i][j]);
    printf("\n");
}
对齐输出 %5d 让每个元素占 5 列，不足时补空格，各列才能对齐，与一维数组用制表符是同一目的。
二维数组作函数形参：成绩表拆分
/* 函数原型：第二维必须写明 */
void readScore(int s[][5], int m);
void output(int s[][5], int m);

int main(void)
{
    int score[30][5], m;
    scanf("%d", &m);
    readScore(score, m);
    output(score, m);
    return 0;
}
void readScore(int s[][5], int m)
{
    int i, j;
    for (i = 0; i < m; i++) {
        s[i][0] = i + 1;
        s[i][4] = 0;
        for (j = 1; j <= 3; j++) {
            scanf("%d", &s[i][j]);
            s[i][4] += s[i][j];
        }
    }
}
形参与实参 第二维 5 不可省，编译器据此计算每行步长，且须与实参 score[30][5] 一致；第一维可省，行数由 m 传入。s 收到的是 score 的首地址，函数内对 s[i][j] 的改动会写回实参数组。output 的实现与第 14 页的输出循环相同，只需把 score 换成形参 s。
列数为什么不能省
地址(a[i][j]) = 首地址 + i × 列数 × sizeof(int) + j × sizeof(int)
实参：int m[4][4]　形参：int a[][3]　　/* 列数不一致 */
实际后果 本机编译给出 incompatible pointer type 警告。函数仍按每行 3 个元素计算偏移，第 1 行才读入 4 个整数就被当作跨行，转置结果出现一个随机值。
两条规则 其一，形参第二维必须是编译期确定的常量；其二，实参数组的第二维必须与它相同。写成 void f(int a[][3]) 就只能接收第二维为 3 的数组。
可选路径 C99 起可用可变长数组作形参，写作 void f(int n, int a[][n])，要求 n 在数组参数之前声明。这一写法留待指针一章展开，本讲不采用。
选学：找出矩阵的鞍点

鞍点指某个元素既是所在行的最大值，又是所在列的最小值。矩阵可以没有鞍点。

int x[4][3] = {{1,2,3},{2,3,4},{3,4,5},{0,0,1}};
for (i = 0; i < 4; i++) {
    max = x[i][0];
    row = i;
    column = 0;
    for (j = 1; j < 3; j++)
        if (x[i][j] > max) { max = x[i][j]; column = j; }
    for (k = 0; k < 4; k++)
        if (x[k][column] < max) { row = column = -1; break; }
    if (row > -1) printf("鞍点 x[%d][%d]=%d\n", row, column, max);
}
本例结果 鞍点为 x[3][2] = 1：第 3 行最大值是 1，第 2 列最小值也是 1。求行最大值与列最小值各用一层循环，外层仍是遍历行的循环。此页不作为考核要求。

考点分布 第 1 题考下标范围，第 2 题考初始化推断，第 3 题考地址步长；三题都依据按行连续存放的规则。
第 1 题　元素个数

3 × 4 = 12 个元素。行下标范围 0 至 2，列下标范围 0 至 3，最后一个元素是 a[2][3]。

写成 a[3][4] 会越过整张表的末尾，编译时没有提示。

第 2 题　行数推断

2 行。6 个初值，每行 3 个，编译器据此推得第一维为 2。

int rows = sizeof(a) / sizeof(a[0]);   /* 2 */
第 3 题　形参的第二维

编译器计算 a[i][j] 的地址时必须知道列数，否则无法求出每行的步长。第二维不可省略，应写成 void f(int a[][4])，并保证实参数组的列数也是 4。

本讲小结
要点结论
逻辑结构a[i][j]，先行后列，下标均从 0 起。
存储结构按行连续存放，相邻元素相差 4 字节，行与行之间没有空隙。
初始化可省第一维，不可省第二维；部分赋初值时其余元素补 0。
遍历外层控行、内层控列；一层循环按偏移量访问同样有效。
函数形参第一维可省，第二维必须写明且与实参一致。
总述 二维数组在逻辑上是矩阵，在内存中仍是一段连续空间；列数决定每行的长度，二维下标据此换算成一维偏移。

行下标与列下标共同确定一个元素的位置。
