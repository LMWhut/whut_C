【例 5-1】引例：统计平均分
问题 某组（10 人）刚刚结束了 C 语言期中考试，现在需要统计本组学员的平均分，以及高于平均分的人数。
先解决第一个子问题：求平均分
float score, sum = 0, aver;
for(i = 1; i <= 10; i++){   // 逐个读入成绩并累加
    scanf("%f", &score);
    sum += score;
}
aver = sum / 10;              // 得出平均分
难点 上面的程序只能“边读边算”，读完一个成绩就被下一个覆盖，无法把 10 个成绩都保留下来再与平均分比较。
引例：求高于平均分的人数
要比较“每个成绩”与平均分，必须先把 10 个成绩都存住

✕办法一：重新输入

计算完平均分后，再让学员把成绩重新输入一遍，输入的同时与平均分比较。若学员人数较多，工作量翻倍，明显减慢计算速度。

✕办法二：10 个独立变量

设置 score1、score2 …… score10 共 10 个变量。此时不能使用循环，只能逐个处理；若人数改变，同一段代码就无法复用。

症结 简单变量一次只能存一个值；而本问题需要一次性保存一批同类型数据并反复使用——这正是“数组”要解决的场景。
5.1 什么是数组
  • 数据类型除 int、float、char 等基本数据类型外，C 语言还提供了构造数据类型，来满足不同应用的需要。
  • 构造数据类型由基本数据类型按一定规则组成，也称作“导出类型”。
  • 构造类型实例常见的构造数据类型包括 数组、结构体、共用体 等。
核心 数组（array）能把具有相同类型的数据组合在一起，通常用于处理批量数据。
解决办法：引入“数组”
思路 引入构造数据类型——数组，解决“一次输入、多次使用”的需求：把 10 个成绩连续存放在一组同名变量中，再统一与平均分比较。
英语释义

An array is a data type that uses subscripted variables and makes possible the representation of a large number of homogeneous values.

一次输入，全部保留，可反复使用

一维数组的定义格式
定义格式
类型定义符　数组名[整型常量表达式]；
【例如】 int a[6];

类型说明符

数组中所有元素的数据类型。

数组名

标识符。是所有数组元素统一的名字，代表内存起始地址。

整型常量表达式

一维数组中元素的个数（数组长度），用 [ ] 括起来。

内存映像：int a[6];
a[0]
a[1]
a[2]
a[3]
a[4]
a[5]
  • 数组名 a 表示内存首地址，是地址常量。
  • 编译时系统为数组分配连续内存。
  • 内存字节数 = 元素个数 × sizeof(元素类型)。
本例 a 在内存占 24 字节（6 × 4 字节）。
可用 sizeof(a) 取得。
方括号内是“整型常量表达式”
  • 一维数组定义中，方括号内为整型常量表达式。
  • 该表达式的值必须为正数，表示数组的大小，即数组中元素的个数。
  • 数组元素下标范围：0 ～ size - 1。
易错 下标从 0 开始计数。定义了 int a[6];，元素是 a[0] … a[5]，没有 a[6]。
提示 size 通常用 #define 定义为符号常量，便于统一修改。
定义时的注意事项
// 用符号常量指定元素个数
#define size 50
float  score[size];
char   name[20];
注意 通常数组一旦定义，大小就不能再改变。常用符号常量指定元素个数，提高可维护性。
C99 之后 允许用变量表示数组大小（变长数组 VLA），但使用受限，需编译器支持。
注意：可变长数组（VLA）的使用
  • 编译器：使用可变长数组前，必须先确认编译器是否支持。
  • 取值：用变量定义数组长度前，必须先获取该变量的值。
  • 数组大小：数组一旦定义，大小就不能再改变（无论常量还是变量定义）。
// 赋值得到长度
int n = 50;
double score[n];
// 输入得到长度
int n;
scanf("%d", &n);
double score[n];

初始化的语法格式
语法格式
类型说明符　数组名[整型常量表达式] = {值1, 值2, …, 值n};
int a[6] = {0, 2, 4, 6, 8, 10};
注意 使用可变长度数组定义数组时，不可进行数组元素初始化！
全部初始化时，数组大小可置空
int a[6] = {0, 2, 4, 6, 8, 10};
int a[]   = {0, 2, 4, 6, 8, 10};   // 两者等价
等价展开 a[0]=0; a[1]=2; a[2]=4; a[3]=6; a[4]=8; a[5]=10;
规则 当全部元素均初始化时，方括号中的数组大小可以省略，编译器按初值个数自动确定长度。
部分初始化：未赋值元素自动补 0
int a[6] = {1, 2};          // 只给前两个赋初值
int a[]   = {1, 2};          // 等价于 a[0]=1; a[1]=2;
int count[10] = {0};       // 全部 10 个元素均为 0
规则 a[0]=1; a[1]=2; a[2] ~ a[5] 自动为 0。只给前面部分元素赋初值时，其余元素由系统自动赋 0。
易错 当定义语句中不同时给所有元素赋初值时，方括号内不得为空：int a[]; ×（错误）
定义 vs 初始化：元素初值从哪来？

①不初始化

int a[6];

所有元素值均为随机值（程序运行前内存单元中遗留的数据）。

②全部赋初值

int a[6]={1,2,0,4,0,0};

或 int a[]={1,2,0,4,0,0};

所有元素都获明确值：a[0]=1,…,a[5]=0。

③部分赋初值

int a[6]={1,2,0,4};

已给的前 4 个获值，未初始化元素由系统补 0：a[4]=0, a[5]=0。

习题 5.2.2
有定义：int x[10] = {0, 2, 4}; 则数组 x 在内存中所占字节数是：__________
👉 点击显示答案
答案 40 字节。 数组长度由方括号中的 10 决定（与初值个数无关），10 × sizeof(int) = 10 × 4 = 40。
要点 内存大小取决于数组长度（方括号内的值），不是初值个数；未赋初值的元素仍占空间并补 0。
数组元素的引用格式
1　数组元素的引用格式
数组名[下标]
下标可以是
  • 常量
  • 变量
  • 表达式
例如
a[1+2]
score[i]
score[i+3]
a[a[4]]
说明 下标可以是常量、常量表达式、变量、变量表达式，甚至可以是另一个数组元素。
说明（1）：下标从 0 开始
数组元素的下标是元素在该数组中的位置，即距 a[0]（数组首位置）的偏移量。
  • a[3] 是距离 a[0] 为 3 个存储单元的元素；
  • a[0] 是距离首位置 0 个存储单元的元素（即第一个元素）。
核心 下标 从 0 开始，第 k 个元素是 a[k-1]。这是 C 语言数组最容易出错的地方。
说明（2）（3）：引用规则
  • （2）单个引用：引用数值型数组元素时，只能单个引用，不能一次引用整个数组。
    a = {3,4,5,6,7}; ×　　a[6] = {3,4,5,6,7}; ×
  • （3）下标不要越界：下标超出数组范围，会导致错误的程序结果（甚至崩溃）。
引用能做 赋值、输入输出、参与表达式运算…… 针对单个元素进行。
2　获取数组元素的值
  • 可以在定义数组时对全部或部分变量赋值（即数组的初始化）。
  • 可以在语句中为变量赋值或输入——通常借助循环语句批量完成。
套路 用循环变量 i 作下标，遍历 a[0] … a[size-1]，即可批量输入 / 输出 / 处理数组。
【例 5-2】利用循环输入数组元素
要求
  • 输入时，以空格分隔数据；
  • 输出时，数据间以逗号分隔，末尾没有多余符号。
程序运行示例
7 10 27 22 16↙ 7,10,27,22,16
【例 5-2】代码
#include <stdio.h>
int main(){
    int i, a[5];
    for(i=0; i<5; i++)      // 用循环输入数组元素
        scanf("%d", &a[i]);
    for(i=0; i<4; i++)      // 输出前 4 个，带逗号
        printf("%d,", a[i]);
    printf("%d", a[i]);        // 单独输出最后一个，不带逗号
    return 0;
}
关键技术 用 i 作下标遍历数组；前 4 个用 printf("%d,", a[i]) 输出逗号，最后一个单独输出避免末尾多余逗号。
用循环直接为数组赋初值
int main(){
    int i, a[5];
    for(i=0; i<5; i++)
        a[i] = i;          // 用循环对数组直接赋初值
    for(i=0; i<5; i++)
        printf("%d,", a[i]);
    printf("\n");
    return 0;
}
运行结果
0,1,2,3,4,
用交互的循环结构对数组赋初值
int main(){
    int i, a[5];
    for(i=0; i<5; i++){
        printf("a[%d]=", i);   // 提示当前下标
        scanf("%d", &a[i]);
    }
    for(i=0; i<5; i++)
        printf("%d,", a[i]);
    printf("\n");
    return 0;
}
要点 先打印 a[i]= 提示，再读入，交互更友好；仍用循环变量 i 作下标。
下标越界：差一错误 off-by-one error
规则 有 N 个元素的数组，其元素下标允许取值范围为 0 到 N-1，不存在下标为 N 的元素。 
#include <stdio.h>
int main(){
    int i, a[10];
    for(i=1; i<=10; i++){   // 错误：下标 1~10，越界！
        a[i] = 0;
        printf("%d ", a[i]);
    }
    return 0;
}
错在哪 循环用了 i=1 … i<=10，访问了不存在的 a[10]，正确的下标应是 0 … 9。
下标越界为何会“死循环”？
通常编译器按内存递减方式分配内存，使得内存中 a[9] 之后的 4 个字节正好分配给循环变量 i。
连锁反应 本来计数器 i 要把并不存在的 a[10] 设为 0；实际是把 i 自身的值设成了 0。循环体内 i++ 又把 i 变回 10，于是陷入死循环！
教训 越界访问不会报错，却会悄悄破坏其他变量——务必保证下标在 0 … size-1 范围内。
【例 5-3】一维数组的基本操作
任务 定义长度为 10 的整型一维数组，并完成以下功能：
  • ⑴ 从键盘输入 10 个整数，分别存放在 10 个数组元素中；
  • ⑵ 输出数组中的各元素值；
  • ⑶ 按逆序输出数组中的各元素值。
思路 用循环变量 i 作下标：先正序读入并输出，再把循环改成 i=9 … 0 逆序输出。
【例 5-3】代码
#include <stdio.h>
int main(){
    int i, a[10];          // 定义数组
    for(i=0; i<10; i++)      // 输入数组元素
        printf("第%d个数据: ", i+1), scanf("%d", &a[i]);
    for(i=0; i<10; i++)      // 顺序输出
        printf("%4d", a[i]);
    printf("\n");
    for(i=9; i>=0; i--)      // 逆序输出
        printf("%4d", a[i]);
    printf("\n");
    return 0;
}
关键技术 逆序只是把循环方向反过来：for(i=9; i>=0; i--)。数组本身不变，仅改变访问顺序。
【例 5-4】用数组解决例 5-1
数据分析 设置包含 10 个 double 的数组 score[10]，存储所有学员成绩，可反复使用并与平均分比较。 
double score[10];   // 存储 10 名学员成绩
整体流程 ① 循环读入并累加求平均分；② 再循环把每个成绩与平均分比较，统计高于平均分的人数。
【例 5-4】代码
#include <stdio.h>
int main(){
    int i, count=0; double score[10], sum=0, aver;
    for(i=0; i<10; i++){ scanf("%lf", &score[i]); sum+=score[i]; }
    aver = sum/10;
    for(i=0; i<10; i++)          // 依次与平均分比较
        if(score[i]>aver) count++;
    printf("该组平均分为:%.2f\n", aver);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}
要点 &score[i] 取得第 i 个元素的地址；用 count 累计高于平均分的人数。
【例 5-5】求最大值与最小值
任务 从键盘输入 10 个数，找出其中的最大值和最小值。
分析

直接用循环也能找出最大/最小值，但要想再输出所有值就不可能了。所以采用数组把数据保存下来。

为何用数组

数组让数据“留得住”，既可比大小，也可随时回看、输出全部元素。

【例 5-5】程序运行示例
运行示例
Enter 10 integers: 1:35 2:12 3:88 4:7 5:53 6:90 7:21 8:64 9:43 10:5 Maximum value is 90 Minimum value is 5
说明 先打印提示逐个读入，再输出最大值与最小值。下面给出具体算法设计与完整代码。
【例 5-5】算法设计
  1. 输入：for 循环输入 10 个整数；
  2. 处理：
    • (a) 先令 max = min = a[0]；
    • (b) 依次用后续的 a[i] 与 max、min 比较（循环）：
      若 max < a[i]，令 max = a[i]；
      若 min > a[i]，令 min = a[i]；
  3. 输出：max 和 min。
关键 用第 1 个元素初始化 max/min，再从第 2 个开始比较，避免“空集合”比较错误。
【例 5-5】代码
#include <stdio.h>
int main(){
    int a[10], i, max, min;
    printf("Enter 10 integers:\n");
    for(i=0; i<10; i++){ printf("%d:", i+1); scanf("%d", &a[i]); }
    max = min = a[0];
    for(i=1; i<10; i++){
        if(max < a[i]) max = a[i];
        if(min > a[i]) min = a[i];
    }
    printf("Maximum value is %d\n", max);
    printf("Minimum value is %d\n", min);
    return 0;
}
【例 5-5】延伸思考
问题 1 在例 5-5 的基础上，如何求平均值？（提示：再开一个 sum 变量，循环里累加。）
问题 2 若这是一个“比赛评分”场景，常需去掉一个最高分、去掉一个最低分后再求平均。如何用数组实现？
思路 总分 = 所有元素之和 − max − min，再除以 (n − 2)。数组让你既能找极值，又能回算总和。
【例 5-6】最小值移到首位
任务 从键盘输入 10 个数，找出其中的最小值，并将其放置在数列的首位（a[0]）。
核心操作 先定位最小值所在位置，再把它与 a[0] 交换。下面给出两种算法与对应代码。
【例 5-6】查找过程追踪（边找边换）
步骤a[0]a[1]a[2]a[3]a[4]a[5]a[6]a[7]a[8]a[9]
初始81787788386773758559
i=1 后78817788386773758559
i=2 后77817888386773758559
i=4 后38817888776773758559
说明 每发现比 a[0] 更小的元素，就立即与 a[0] 交换，保证 a[0] 始终是当前最小值；最终 38 被换到首位。
算法设计-1：边寻找，边交换
方法 1 用 a[0] 与之后的所有元素依次比较；当某个元素 a[i] < a[0] 时，直接把 a[0] 与其交换，保证 a[0] 存放当前最小值。
  • 输入 10 个数给 a[0] ~ a[9]；
  • for(i = 1; i <= 9; i++)：若 a[i] < a[0]，交换 a[0] 与 a[i]；
  • 输出 a[0] ~ a[9]。
特点 一旦发现更小值就立刻交换，共可能发生多次交换（上表 i=1、i=2、i=4 各交换一次）。
方法 1 代码（边找边换）
#include <stdio.h>
int main(){
    int i, t, a[10];
    for(i=0; i<10; i++) scanf("%d", &a[i]);
    for(i=1; i<10; i++)
        if(a[i] < a[0]){ t=a[0]; a[0]=a[i]; a[i]=t; }
    printf("处理后：\n");
    for(i=0; i<10; i++) printf("%4d", a[i]);
    printf("\n");
    return 0;
}
运行示例
输入：81 78 77 88 38 67 73 75 85 59 输出：38 81 78 88 77 67 73 75 85 59
算法设计-2：先找到，再交换
方法 2 先记录最小值的位置（下标 t），最后只把最小值与 a[0] 交换一次即可。
  • min 存最小值（初值首元素），t 存其下标（初值 0）；
  • 依次比较，a[i] < min 时更新 min 与 t；
  • 结束将 a[t] 与 a[0] 交换一次。
方法 2 代码（先找再换）
#include "stdio.h"
int main(){
    int i, t=0, a[10], min, k;
    for(i=0; i<10; i++) scanf("%d", &a[i]);
    min = a[0];
    for(i=1; i<10; i++)
        if(a[i] < min){ min = a[i]; t = i; }
    if(t != 0){ k=a[t]; a[t]=a[0]; a[0]=k; }
    for(i=0; i<10; i++) printf("%4d", a[i]);
    printf("\n");
    return 0;
}
运行示例
输入：81 78 77 88 38 67 73 75 85 59 输出：38 78 77 88 81 67 73 75 85 59
方法 3 代码（直接记下标）
#include "stdio.h"
int main(){
    int i, t, a[10], min, k;
    for(i=0; i<10; i++) scanf("%d", &a[i]);
    t = 0;
    for(i=1; i<10; i++)
        if(a[i] < a[t]) t = i;
    if(t != 0){ k=a[t]; a[t]=a[0]; a[0]=k; }
    for(i=0; i<10; i++) printf("%4d", a[i]);
    printf("\n");
    return 0;
}

与方法 2 区别：直接用 a[t] 比较，无需单独的 min 变量，t 始终指向当前最小值下标。

【例 5-7】数据循环左移一位
背景 在例 5-1 中，老师发现输入成绩错位——第 1 个成绩 score[0] 本应是最后一个学生的成绩。于是需要把数据整体循环左移一位。
目标 把 score[1] 移到 score[0]，score[2] 移到 score[1]，……，score[9] 移到 score[8]；最后把最初的 score[0] 放到 score[9]。
【例 5-7】初始数据与下标
i0123456789
a[i]38817888776773758559
思路 把除 score[0] 外的所有数据向左（向前）移动一位；C 语言中的“移动”通过为目标位置赋值实现：score[i] = score[i+1];
注意 移动前，必须先把将被覆盖的 score[0] 复制一份，否则它会丢失。
【例 5-7】移位过程

依次执行 score[i] = score[i+1]（i = 0 … 8），每个元素被后一个覆盖：

i0123456789
初值38817888776773758559
i=0 后81817888776773758559
i=1 后81787888776773758559
……81788877677375855959
收尾 最后执行 score[9] = k（k 为事先保存的原 score[0]），完成“循环”左移。
【例 5-7】关键说明
  • 需要将除 score[0] 外的所有数据向左（向前）移动一位：score[1]→score[0]，score[2]→score[1]，……，score[9]→score[8]。
  • C 语言中“移动”通过为目标位置赋值达成：score[i] = score[i+1];
  • 移动前，必须先把将被覆盖的 score[0] 复制一份，否则数据丢失。
顺序很重要 必须从 i=0 开始往后覆盖；若从后往前覆盖，前面的数据会被提前破坏。
【例 5-7】代码
#include <stdio.h>
int main(){
    int i, score[10], k;
    for(i=0; i<10; i++) scanf("%d", &score[i]);
    printf("\n");
    k = score[0];            // 复制首元素，以免被覆盖
    for(i=0; i<9; i++){ score[i] = score[i+1]; } // 后一位前移
    score[i] = k;              // 原首元素放到末尾
    printf("移动后：\n");
    for(i=0; i<10; i++) printf("%d ", score[i]);
    printf("\n");
    return 0;
}
运行示例
输入：81 78 77 88 38 67 73 75 85 59 移动后：78 77 88 38 67 73 75 85 59 81

【例 5-4】（函数版）数据分析
任务 仍是用数组解决例 5-1，但把“统计高于平均分人数”封装成函数，体会数组在函数间传递的方式。 
double score[10];   // 存储 10 名学员成绩
关键 数组作为函数参数时，传递的是首地址，函数内可通过下标访问全部元素，且能修改原数组。下一页给出主函数，下下页给出被调函数。
【例 5-4】（函数版）主函数
#include <stdio.h>
int main(){
    int i, count=0;
    double score[10], sum=0;
    for(i=0; i<10; i++){ scanf("%lf", &score[i]); sum+=score[i]; }
    // 调用函数 countNum 计算高于平均分的人数
    count = countNum(score, 10, sum/10);
    printf("该组平均分为:% .2f\n", sum/10);
    printf("高于平均分的人数为:%d\n", count);
    return 0;
}
调用方式 countNum(score, 10, sum/10)：数组名 score 即首地址，10 为长度，sum/10 为平均分。
被调函数：countNum
int countNum(double a[], int n, double aver)
{
    int i=0, cnt=0;
    for(; i<n; i++)
    {
        if(a[i] > aver) cnt++;
    }
    return cnt;
}
要点 形参 double a[] 接收数组首地址，函数内用 a[i] 访问原数组元素；返回高于平均分的人数 cnt。
