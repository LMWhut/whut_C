字符数组

第 5 章（三）数组 · 字符数组
主讲：李　民
本讲内容
1字符数组与结束符
字符数组存放字符的 ASCII 码；末尾另有 '\0' 的字符数组才能按字符串处理。
2输入与输出
%s 遇到空白就停；fgets 可以读入空格，但要限制长度并去掉换行符。
3字符串处理函数
strlen、strcpy、strcat、strcmp；最后用选择法排列五个字符串。
与前一部分衔接 字符数组是一维数组的一个特例，二维字符数组存放多个字符串。本讲沿用「容量与实际个数分离」以及「数组名代表首地址」两条结论。
引例：怎样存一个名字

需要保存姓名 Hello 并能整体输出。用五个 char 变量只能逐个字符处理，用字符数组可以整体输入输出。

char c[5] = {'H', 'e', 'l', 'l', 'o'};   /* 只是五个字符 */
char a[10] = "Hello";              /* 是一个字符串 */
两种写法的差别 第二种写法在 o 之后自动存入一个 '\0'。有了它，printf("%s", a) 才能确定输出到哪里为止。第一种没有结束符，只能按下标逐个字符输出。
术语 '\0' 是 ASCII 码为 0 的字符，写作反斜杠加数字 0；它与字符 '0' 完全不同，后者的 ASCII 码是 48。

字符数组一定是字符串吗
char a[5] = {'a', 'b', 'c', 'd', 'e'};   /* 不是字符串 */
char b[6] = {'a', 'b', 'c', 'd', 'e', '\0'}; /* 是字符串 */
char c[] = "abcde";                    /* 是字符串，长度 6 */
数组 a五个单元全被字母占满，没有 '\0'。只能逐个处理字符，不能用 %s、puts 或 strlen。
数组 b、c末尾有 '\0'，可以作为字符串整体处理。两者内容完全相同。
判定标准 数组里是否存放了 '\0'，决定了它能否按字符串处理。这与数组本身的类型无关，只看实际内容。
初始化的等价写法
char a[6] = {"abcde"};   /* 带花括号 */
char a[6] = "abcde";     /* 等价 */
char a[]    = "abcde";     /* 长度自动为 6 */
char a[6] = {'a','b','c','d','e'}; /* 末位补 '\0' */
char a[] = {'a','b','c','d','e','\0'}; /* 同样等价 */
三种不等价的情况 char a[5] = "abcde"; 长度不足，编译报错；char a[5] = {'a','b','c','d','e'}; 没有结束符；char a[] = {'a','b','c','d','e'}; 长度为 5，同样不是字符串。
省略长度的后果 用字符串常量初始化时，长度自动取字符数加 1；用字符列表初始化时，长度就是列表项数，不会凭空补出 '\0'。
初始化的三条规则

1长度要留余量

数组长度应大于等于字符串有效长度加 1。空间不足时编译报错，或写入越界。

2引号不能混

单引号括单个字符，如 'a'；双引号括字符串，如 "a"，后者多一个 '\0'。

3不能整体赋值

✗ a = "abc";　定义后再整体赋值

✗ a[] = "abc";　定义后再指定长度

两种写法都非法。数组名是地址常量，只能在定义时初始化，定义之后用 strcpy 复制。

与整型数组一致 第三条并不是字符数组特有的限制，一维整型数组同样不能整体赋值。区别在于字符串有专门的复制函数，整型数组需要逐个元素处理。
多个字符串：二维字符数组
char s[3][13] = {"How are you", "Good morning", "Good bye"};
写法地址所指
s0x61FC20整个二维字符数组的首地址。
s[0]0x61FC20第 0 行的首地址，也就是该行字符串「How are you」。
s[1]0x61FC2D第 1 行的字符串，起点相差 13 字节。

第二维的含义 13 是每行最多能放的字节数，要取最长字符串的长度加 1。第一维的行数可以省略，由初值个数推断；第二维不能省略，理由与整型二维数组相同。
三种读入方式
方式结束条件能否读入空格
scanf("%c")读满指定次数能，空格也是一个字符。
scanf("%s")遇到空格、Tab、回车不能，空白即终止。
fgets(a, n, stdin)读到换行或满 n−1 个能，但换行符会留在串里。
关于 gets gets 不检查长度，可能写越界；C99 起已不推荐使用，C11 中正式移除。本讲所有例题均使用 fgets。旧教材或题库中若出现 gets，按「无上限的读入」理解即可，不要在新代码中使用。
选择依据 要逐个字符判断时用 %c；读入不含空格的单词用 %s；读入一整行文字用 fgets。
逐字符输入：必须读满
char name[15];  int i;
for (i = 0; i < 15; i++)
    scanf("%c", &name[i]);
循环不会因为回车停下 %c 把空格和回车都当作普通字符。用户必须输入满 15 个字符循环才结束，而且数组中没有 '\0'，不能按字符串整体输出。 
for (i = 0; i < 14; i++)
    name[i] = getchar();
name[i] = '\0';   /* 手工补上结束符 */
补结束符 只读 14 个字符，第 15 个单元留给 '\0'。这样数组才成为字符串，才能交给 puts 或 strlen 处理。
读到回车为止：while 写法
char name[15];  int i = 0;
while ((name[i] = getchar()) != '\n')
    i++;
name[i] = '\0';
puts(name);
边界 最多只能输入 14 个字符。第 15 个单元要留给 '\0'；若输入更长，循环会越过数组末尾。

用 %s 读入整个字符串
char name[15];
scanf("%s", name);      /* 变量名前不加 & */
printf("%s\n", name);    /* 输出时不加 \0 */

char city[10][20];
for (i = 0; i < 10; i++)
    scanf("%s", city[i]);   /* 第 i 行的首地址 */
为什么不用取地址符 数组名本身代表首地址，scanf 需要的是地址，因此写 name 和 city[i] 即可。写成 &name 类型不符，多数编译器给出警告。
读入时自动补结束符 %s 在读入结束后自动写入 '\0'，这与逐字符读入不同。但它不会把换行符留在字符串里。
%s 的两条限制
限制一：长度不受控 %s 不检查数组容量：一直读到空白符，把字符全部写入，再补 '\0'。有 n 个单元时输入超过 n−1 个字符就越界，编译器不报错。写明宽度才有限制：%14s 最多读入 14 个有效字符。
宽度里含 \0 吗 不含。宽度只数读入的字符，'\0' 由系统额外写入，还要占一格。因此 15 个单元必须写 %14s；写 %15s 需 16 格，最后一格越界。
限制二：空白 空格、Tab、回车都被当作字符串终止。输入 Good morning 时，%s 只读到 Good，morning 会留给下一次读入。
方式（数组 15 格）最多写入换行符
scanf("%14s", a)14 个字符 + '\0'留在输入流
fgets(a, 15, stdin)14 个字符 + '\0'存进字符串
用 fgets 读入一整行
char a[12];
fgets(a, 12, stdin);
printf("%s", a);
两个要点 第二个参数 12 是最多写入的字节数，实际最多存 11 个字符加一个 '\0'。若读入中遇到换行，换行符会保留在字符串里，不会被替换成结束符。

char s[15];
fgets(s, 15, stdin);
s[strcspn(s, "\n")] = '\0';

不要混用 scanf 与 fgets
int n;  char s[80];
scanf("%d", &n);          /* 回车留在输入流 */
fgets(s, 80, stdin);    /* 只读到那个回车 */
printf("整数%d和字串%s", n, s);  /* 字串为空 */
现象 输入 123↵ 再输入 Hello↵，s 是空串。scanf 读到数字即返回，换行留在输入流，被紧随的 fgets 立即读走。
易错：前置空格不管用 scanf(" %d", &n) 开头的空格只跳过本次读入之前的空白。残留回车是上一次 %d 读完留下的，在本句开始前就已存在，跳不到它。
有效：空格放在 %d 后面 scanf("%d ", &n) 或 scanf("%d\n", &n)：格式串末尾的空白会跳过本次转换之后的所有空白，包括上次残留的回车。注意它要等到下一个非空白字符出现才返回，交互式输入时需再敲一个字符才继续。 
scanf("%d ", &n);   /* 末尾空格吃掉残留回车 */
fgets(s, 80, stdin);   /* 这次读到 Hello */
输出的三种方式
方式遇到 \0 时的处理是否换行
puts(s)输出到此停止自动换行：它把结尾的 '\0' 转换成换行符输出，不是串里另有一个换行。
printf("%s", s)输出到此停止不换行，'\0' 不输出也不转换，需要另写 \n。
printf("%c", s[i])不识别结束符由循环控制，逐个字符输出。
 
char s[2][5] = {"Boy", "Girl"};
puts(s[0]);   puts(s[1]);      /* 行名即字符串 */
printf("%s\n", s[0]);   printf("%s\n", s[1]);  /* 输出相同 */
二维字符数组的访问 s[i] 是第 i 行的首地址，可整体交给 puts 或 %s；s[i][j] 才是该行中的单个字符。

字符串复制：strcpy
✗ 最易错：不能用赋值号 str1 = "Wuhan"; 非法。数组名是地址常量，不能作赋值左值。定义时可以用字符串常量初始化，定义之后只能借助 strcpy 复制，或逐个元素赋值。 
char str1[10];
strcpy(str1, "Beijing");   /* 复制进去 */
puts(str1);
strcpy(str1, "Wuhan");     /* 覆盖原内容 */
puts(str1);
三件事 把第二个参数中的字符连同 '\0' 一起复制到第一个数组；第二个参数不变；函数返回第一个数组的首地址。
目标空间必须够 str1 的容量必须大于被复制字符串的长度加 1。strcpy 不检查目标大小，空间不足会越界写入，这是它最常被诟病的地方。
字符串连接：strcat
char str1[12] = "World", str2[6] = " Cup";
printf("%s", strcat(str1, str2));
World Cup
连接的过程 找到 str1 末尾的 '\0'，从那个位置开始写入 str2 的内容，最后再写一个 '\0'。结果是 World Cup，str2 保持不变。
空间计算 str1 原串长 5，str2 长 4，连接后有效字符 9 个，加上结束符需要 10 个单元。声明为 12 是够的；若写成 char str1[8] 就越界。
字符串比较：strcmp
int r = strcmp(s1, s2);
/* r == 0　相等 */
/* r > 0　s1 大 */
/* r < 0　s1 小 */
strcmp("abcd", "ABCD")大于 0：'a' 的 ASCII 码大于 'A'。
strcmp("ABCD", "AbCD")小于 0：第 2 个字符 'B' 小于 'b'。
strcmp("pen", "pencil")小于 0：前面相同，'\0' 小于 'c'。
比较规则 从第一个字符开始按 ASCII 码逐对比较，遇到不同字符即返回差值符号；全部相同则比较结束符，返回 0。按此规则比较，即得字典序。
相等比较：三种数据三种写法
数据类型正确的相等判断
整数a == b
浮点数fabs(a - b) < 1e-6
字符串strcmp(a, b) == 0
 
char a[] = "abcd", b[] = "abcd";
if (a == b)  printf("Yes");  /* 结果总是 No */
为什么是 No 数组名代表首地址。两个数组各占一段空间，a == b 比较的是两个首地址是否相同，与里面的字符无关。若要比较内容，必须写 strcmp(a, b) == 0。
大小写转换函数
strlwr("AbCd");   /* abcd */
strupr("AbCd");   /* ABCD */
函数归类 strlen、strcpy、strcat、strcmp 属于标准库，各平台都提供。strlwr、strupr 是常见的扩展函数，不在 ISO C 标准中，移植时要留意。
典型用途 登录验证时忽略用户名大小写：先把输入统一转成小写，再与预存的用户名用 strcmp 比较。可以避免因大小写不同而被判为不相等。
综合案例：五个字符串排序

读入五个由空格分隔的单词，按字典序输出。数据用 char str[5][80] 存放，每行是一个字符串。

for (i = 0; i < 4; i++) {
    t = i;
    for (j = i + 1; j < 5; j++)
        if (strcmp(str[t], str[j]) > 0) t = j;
    if (t != i) {
        strcpy(tem, str[i]);
        strcpy(str[i], str[t]);

}

综合案例：完整程序

问题：读入五个用空格分隔的单词（如 red yellow blue green white），按字典序由小到大逐行输出，结果为 blue green red white yellow。每个单词不超过 79 个字符。

char str[5][80] = {""}, tem[80] = "";
int i, j, t;
for (i = 0; i < 5; i++) scanf("%s", str[i]);
for (i = 0; i < 4; i++) {
    t = i;
    for (j = i + 1; j < 5; j++)
        if (strcmp(str[t], str[j]) > 0) t = j;
    if (t != i) { strcpy(tem, str[i]); strcpy(str[i], str[t]); strcpy(str[t], tem); }
}
for (i = 0; i < 5; i++) puts(str[i]);
列大小 80 的含义 每个字符串最多 79 个有效字符，第 80 个单元放 '\0'。题目保证输入长度小于 80，不会越界。这与一维数组「容量与实际个数分离」是同一条原则。
字符数组作函数参数
void sortStrings(char s[][80], int n) {
    int i, j, t;
    char tem[80];
    for (i = 0; i < n - 1; i++) {
        t = i;
        for (j = i + 1; j < n; j++)
            if (strcmp(s[t], s[j]) > 0)
                t = j;
        if (t != i) {
            strcpy(tem, s[i]);
            strcpy(s[i], s[t]);
            strcpy(s[t], tem);
        }
    }
}
int main(void) {
    char str[5][80];
    int i;
    for (i = 0; i < 5; i++)
        scanf("%s", str[i]);
    sortStrings(str, 5);
    for (i = 0; i < 5; i++)
        puts(str[i]);
    return 0;
}
形参与实参 形参 char s[][80]：第二维必须写 80，编译器据此算每行步长。调用 sortStrings(str, 5) 传的是 str 的首地址，函数内的 strcpy 直接改变实参；行数 n 另传。

本讲小结
要点结论
字符串以 '\0' 结尾的一维字符数组；长度至少比有效字符数多 1。
输入%s 遇空白停止；fgets 保留换行，须用 strcspn 去掉。
输出puts 自动换行，%s 不换行，%c 逐个输出。
四个函数strlen 求有效长度，strcpy 复制，strcat 连接，strcmp 比较。
相等判断字符串内容用 strcmp，不能用 == 比较数组名。
总述 能否按字符串处理，取决于数组中有没有 '\0'，与数组长度无关。
