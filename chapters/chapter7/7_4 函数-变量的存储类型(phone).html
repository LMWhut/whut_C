本讲小结
这一讲讲什么
上一讲说的是「这个名字在代码哪几行有效」。这一讲换一个问题：写变量时前面能加哪个关键字，加了之后它放进哪块内存、存在多久。
  • auto不写它就是它，变量放栈区
  • static放静态区，函数返回也不收回；写在函数外，只本文件可见
  • extern只是声明，东西定义在别的文件里
  • register建议放寄存器，编译器可以不理
掌握到哪一步static 用在局部变量这一种要会写，其余三个知道名字和一句话的区别就够了。
内存里分四块地方
代码区编译好的机器指令，只读。
静态区全局变量、static 变量。程序一启动就划好，存在到程序结束。
栈区局部变量、形参。进函数才分配，返回就收回，编译器自动管理。
堆区malloc 这类函数动态申请的空间，第 6 章再讲。
int g;              /* 函数外：静态区 */
void f(void)
{
    int k;          /* 栈区 */
    static int s;   /* 静态区 */
}
放哪块区，看两件事写在哪：函数里还是函数外。加没加 static：加了就绕过栈区，直接进静态区。
四个关键字，先看全貌
int x;栈区，出函数就收回，初值是残留值，只有本函数能用。
static int x;（写函数里）静态区，到程序结束，初值 0，作用范围还是本函数。
static int x;（写函数外）静态区，到程序结束，初值 0，只有本文件能用。
extern int x;东西在别处，自己不占内存，跟定义一样存在。
register int x;寄存器，出函数就收回，只是一个建议。
两处值得盯一下register 只是建议，编译器可以不理；extern 不分内存，只替别处报个名字。
static 局部：只初始化一次
void f(void)
{
    static int k = 0;  /* 只给一次 */
    k++;
    printf("%d ", k);
}
int main(void)
{
    f(); f(); f();
    return 0;
}
1 2 3
三次调用，静态区里只有一个 k第 1 次：0 加 1 输出 1；第 2 次：1 加 1 输出 2；第 3 次：2 加 1 输出 3。static int k = 0; 那一行只在程序启动时算过一次，后两次直接跳过。
和第 7 节比一比同样调用三次，没加 static 输出 1 1 1，加了 static 输出 1 2 3。
static 改了什么只改了存在哪：从栈搬到静态区，于是函数返回也不收回。作用域没变，还是只有 f 能用，main 里照样看不见 k。
static 写在函数外面：只在本文件可见
/* a.c */
static int cnt = 10;
void addA(void) { cnt++; }
int  getA(void) { return cnt; }

/* b.c */
static int cnt = 20;
void addB(void) { cnt += 2; }
int  getB(void) { return cnt; }
A=11 B=22
改的是什么改的是名字对别的文件可不可见。加了 static，这个名字不往外送，链接的时候别的文件找不到它。
不加会怎样两个文件都写 int cnt;，链接时会报重复定义。加了 static，两个 cnt 各管各的。
函数也一样函数前面加 static，就是只给本文件用，别的文件调不到。
extern 和 register：知道有这两个就行
extern：声明，不是定义extern int g; 只是告诉编译器「有这么个名字，定义在别的文件里」，不分配内存。
int g = 0;        /* 定义：内存在这儿 */
extern int g;     /* 声明：不占内存 */
写几次定义全程序只能一处，声明可以写多次。两个 .c 文件怎么编到一起，真用到时再查。
register：只是一个建议意思是「这个变量用得勤，尽量放进 CPU 寄存器」。尽量，编译器可以直接忽略。
register int i;
int *p = &i;       /* 取地址：报错 */
为什么报错寄存器不在内存里，没有地址，所以 register 变量不能取地址。
本讲小结
  • ① 内存分四块栈区放局部变量和形参，静态区放全局和 static，堆区靠 malloc，代码区放指令
  • ② static 局部放进静态区，只初始化一次，函数返回不收回，连调三次输出 1 2 3
  • ③ static 在外名字只在本文件可见，别的文件找不到；函数前面加 static 也是这个意思
  • ④ 其余两个extern 只是声明，不分配内存；register 只是建议，还不能取地址
一句话加哪个关键字，决定变量放进哪块内存、存在多久。四种写法里，先把 static 局部这一种用熟。
