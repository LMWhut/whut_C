变量放在哪，存在多久

第 7 章（四）变量的存储类型
主讲：李　民
这一讲讲什么
上一讲说的是「这个名字在代码哪几行有效」。这一讲换一个问题： 写变量时前面能加哪个关键字，加了之后它放进哪块内存、存在多久。
关键字一句话
auto 不写它就是它，变量放栈区
static 放静态区，函数返回也不收回；写在函数外，只本文件可见
extern 只是声明，东西定义在别的文件里
register 建议放寄存器，编译器可以不理
掌握到哪一步 static 用在局部变量这一种要会写，其余三个知道名字和一句话的区别就够了。
内存里分四块地方
代码区编译好的机器指令
静态区全局变量、static 变量
栈区局部变量、形参
堆区malloc 申请的空间（第 6 章）

一个变量写出来，编译器先要决定把它放进哪一块。这个决定不是在运行时做的，编译的时候就已经定下了。

两句话记住 栈区是进函数时才分的，静态区是程序一启动就分好的。
栈区那块地方还会复用：函数返回就标成空，下次调用谁都能拿去用，不先清零。 
int g;              /* 函数外：静态区 */
void f(void)
{
    int k;          /* 栈区 */
    static int s;   /* 静态区 */
}
放哪块区，看两件事 写在哪：函数里还是函数外。
加没加 static：加了就绕过栈区，直接进静态区。
堆区这里不展开，知道有这一块就行。
四个关键字，先看全貌
怎么写放在哪存在多久默认初值谁能用
int x;
（等于 auto）		 栈区出函数就收回残留值本函数
static int x;
（函数内）		 静态区到程序结束0本函数
static int x;
（函数外）		 静态区到程序结束0本文件
extern int x; 别处跟定义一样不分内存整个程序
register int x; 寄存器出函数就收回残留值本函数
两处值得盯一下 register 只是建议，编译器可以不理；extern 不分内存，只替别处报个名字。
「存在多久」这一列，就是这一讲要讲的东西，后面每个关键字都围着它转。
看一遍：三个变量存在多久
代码
int g = 0;             /* 全局 */void f(void){    int k = 0;        /* 局部 */    static int s = 0; /* 静态局部 */    k++;  s++;  g++;    printf("%d %d %d\n",k,s,g);}int main(void){ f(); f(); f(); return 0; }

static 写在函数外面：只在本文件可见
/* a.c */
static int cnt = 10;
void addA(void) { cnt++; }
int  getA(void) { return cnt; }

/* b.c */
static int cnt = 20;
void addB(void) { cnt += 2; }
int  getB(void) { return cnt; }
A=11 B=22

两个文件各有一个 cnt，名字一模一样，编译链接一起过，谁也不撞谁。因为它们都加了 static。

static 在这儿改的是什么 改的是「名字对外的可见性」。加了 static，这个名字不往外送，链接器根本不知道它的存在。
不加会怎样 两个文件都写 int cnt;， 链接时会报重复定义。加了 static，两个 cnt 各管各的。
函数也一样 函数前面加 static，就是只给本文件用，别的文件调不到。
extern 和 register：知道有这两个就行
extern：声明，不是定义 extern int g; 只是告诉编译器「有这么个名字，定义在别的文件里」，不分配内存。 
int g = 0;        /* 定义：内存在这儿 */
extern int g;     /* 声明：不占内存 */
定义全程序只能一处，声明可以写多次。两个 .c 文件怎么编到一起，真用到时再查。
register：只是一个建议 意思是「这个变量用得勤，尽量放进 CPU 寄存器」。尽量， 编译器觉得不合适就直接忽略，也不告诉你。 
register int i;
int *p = &i;       /* 取地址：报错 */
寄存器不在内存里，没有地址，所以 register 变量不能取地址。
这一讲记住一句 写函数只要会用一个：static 局部，让变量在两次调用之间保住值。
本讲小结

① 内存分四块

栈区放局部变量和形参，静态区放全局和 static，堆区靠 malloc 申请，代码区放机器指令。

② static 局部

放进静态区，只初始化一次，函数返回不收回。连调三次，输出 1 2 3。

③ static 写在函数外

名字只在本文件可见，别的文件找不到。函数前面加 static，也是这个意思。

④ extern 与 register

extern 只是声明，不分配内存；register 只是建议，还不能取地址。

一句话 加哪个关键字，决定变量放进哪块内存、存在多久。四种写法里，先把 static 局部这一种用熟。
