先看一个问题：三个循环，同一段事儿
/* 求 C(10,3) = 10! / (3! × 7!) */
long f1 = 1, f2 = 1, f3 = 1;
int i;

for (i = 1; i <= 10; i++) f1 *= i;
for (i = 1; i <= 3;  i++) f2 *= i;
for (i = 1; i <= 7;  i++) f3 *= i;

printf("%ld\n", f1 / (f2 * f3));
120
看出来了吗 三个循环长得一模一样，只差一个上限：10、3、7。
危险在哪 如果哪天要改成「累加」而不是「累乘」，你得改三处。 改两处忘一处，这种错误编译器不报，运行时才出鬼。
注意 这段代码没有错，能跑，结果也对。它的问题不在对错， 在于这三段活儿没有名字。
不用换 double 三个数都是 long，除的是整数。组合数一定除得尽， 所以 %ld 就对。换成 double 反倒引入小数误差。
抽出去，给它一个名字
/* 算 k 的阶乘 */
long fact(int k)
{
    long r = 1;
    int i;
    for (i = 1; i <= k; i++) r *= i;
    return r;
}

/* 用的时候，只要说出「几的阶乘」 */
printf("%ld",
       fact(10) / (fact(3) * fact(7)));
变化 三遍重复的循环 → 一个函数 + 一行调用。 以后要算 20 的阶乘，也只是 fact(20)。
关键 函数把「怎么做」藏了起来，只把「做什么」露在外面。 看到 fact(10)，你不需要读循环，就知道它在算 10 的阶乘。
于是 要改算法？只改 fact 一处，三处调用自动跟着变。

定义一个函数：四个零件
int max(int a, int b)
{
    return a > b ? a : b;
}
读法 「int 类型的 max，要两个 int，交回一个 int」。把这一句念顺，这个函数你就看懂了。
零件本例作用
返回类型int交回什么类型；不交写 void
函数名max以后就用这个名字叫它
参数表(int a, int b)需要你给什么；不给写 ()
函数体{ … }真正干活的地方
语法骨架：一张图记住
返回类型  函数名(参数表)
{
    语句1;
    语句2;
    return 表达式;   /* 有返回值才写 */
}
位置 函数要写在 main 的外面， 不能写在 main 的花括号里面： C 语言不允许函数嵌套定义。
三处最容易漏 ① 返回类型不能省。老教材省了默认 int，现代编译器直接报错。
② 每个参数都要写类型。(int a, b) 是错的，要写 (int a, int b)。
③ 函数体后面不加分号。只有声明和调用才加分号。
对照记忆 定义像「写菜谱」：材料、步骤全写清，放那儿备用。
调用像「点菜」：只说菜名和份数，不管怎么做。
形态一：无返回值、无参数
/* ① 定义：写清函数名和函数体 */
void printTitle()
{
    printf("=== 成绩统计 ===\n");
    printf("学号  姓名  成绩\n");
}

int main()
{
    printTitle();      /* ② 调用 */
    printTitle();      /* 再调一次 */
    return 0;
}
void 「空」的意思：不往回交值。函数干完就结束，调用处拿不到东西。
调用三件套 函数名 + 括号 + 分号：printTitle(); 括号不能省，哪怕里面什么都没有。
=== 成绩统计 === 学号 姓名 成绩 === 成绩统计 === 学号 姓名 成绩
形态二：无返回值、有参数
void printScore(int no, int score)
{
    printf("第 %2d 位：%3d 分\n",
           no, score);
}

int main()
{
    printScore(1, 92);
    printScore(2, 78);
    return 0;
}
形参就是变量 no 和 score 进了函数， 就是两个普通变量，能读能算能打印。
一句话说清 同一段活儿，换个数据再做一遍，这就是参数的用处。
第 1 位： 92 分 第 2 位： 78 分
形态三：有返回值、无参数
int getChoice()
{
    int c;
    scanf("%d", &c);
    return c;
}

int main()
{
    int op = getChoice();
    printf("你选了 %d\n", op);
    return 0;
}
什么时候用 数据不用你送进去：函数自己从键盘读、自己取系统时间。 括号里空着，但结果它交回来。
看清楚这一行 op = getChoice();
等号右边的这一次调用，整个被它的返回值顶替。 所以这一行等价于：先调函数拿到数，再赋给 op。
换个写法 不接收也行：getChoice();， 值被丢掉了，但函数确实执行过。
形态四：有返回值、有参数（最常用）
double power(double x, int n)
{
    double r = 1.0;
    int i;
    for (i = 1; i <= n; i++) r *= x;
    return r;
}

int main()
{
    printf("%.2lf\n", power(2.0, 10));
    return 0;
}
送进去，交回来 这是完整形态：进去有参数，出来有返回值。 数学里的函数几乎都能直接翻成这种形态。
返回值也能直接参与运算 power(2,10) + 1、 power(2,10) / 2 都合法， 因为调用处拿到的就是一个数。
1024.00
四种形态，一张表
形态定义长什么样典型例子
无返无参void f()打印表头 printTitle()
无返有参void f(类型 名)打印一条记录 printScore(no, score)
有返无参类型 f()读一个选项 getChoice()
有返有参类型 f(类型 名)算乘方 power(x, n)
怎么记 两个问句就够了：它要交东西回来吗？（定 void 还是类型） 它需要你给它东西吗？（定参数表空不空）。
提醒 用得最多的是有返回值、有参数这一种。最简单的 无返回值、无参数也别小看：把一段固定动作打包、起个名字，程序立刻好读。
return 干三件事
int check(int x)
{
    if (x < 0)
        return 0;      /* 提前走 */
    if (x > 100)
        return 100;    /* 提前走 */
    return x;          /* 正常交货 */
}
check(-5) → 0 check(95) → 95 check(120) → 100
① 立刻结束函数 后面的语句一句都不再执行，直接把控制权交回调用处。
② 交回一个值 值的类型必须和「返回类型」对得上。写 int 却 return 3.7，会被截成 3。
③ 一次只带一个值 想带回多个？得靠指针或数组，那是第 8 章的事。
常见坑 return 后面写代码 = 永远执行不到。编译器给警告，别忽略。
先声明，后使用
#include <stdio.h>

double power(double x, int n);  /*声明*/
int main()
{
    printf("%.2lf\n", power(2, 10));
    return 0;
}

double power(double x, int n)   /*定义*/
{
    double r = 1.0;
    while (n-- > 0) r *= x;
    return r;
}
为什么需要 编译器从上往下读代码。读到 main 里的 power(2,10) 时，它还没见过这个函数，就会报「未声明的标识符」。
声明的作用 提前告诉编译器：有这么个函数，长这个样子。它长什么样，就是返回类型、名字、参数表。
顺手 声明也可以写成 double power(double, int);， 参数名可以省，类型不能省。
声明和定义，差在哪
　声明定义
干什么只写返回类型、函数名、参数把函数体完整写出来
有没有函数体没有，以分号结尾有 { }，不加分号
能写几次可以写多次只能写一次
什么时候必须写定义写在调用之后时永远必须有
两个省事的办法 ① 把函数定义写在 main 前面，就不用单独声明了。
② 函数多了以后，把声明集中放在文件开头（以后配 .h 头文件就是这么来的）。
别混 double power(double x, int n) 后面带分号＝声明； 带花括号＝定义。看结尾就知道是哪一个。

作业里的题：最大公约数和最小公倍数
题目 输入两个正整数 M 和 N（都不超过 1000），输出它们的最大公约数， 再输出最小公倍数，中间空一格。这版能过，12 行。
输入　511 292 输出　73 2044
算法就一句 两数相除留余数，余数不为 0 就把「小数、余数」当成新的一对再做一遍； 余数为 0 时，那个小数就是最大公约数。最小公倍数是两数之积再除以它， 先除后乘，免得溢出。 
#include <stdio.h>
int main()
{
    int m, n, a, b, r;
    scanf("%d %d", &m, &n);
    a = m;  b = n;
    while (b != 0) {       /* 辗转相除 */
        r = a % b;  a = b;  b = r;
    }
    printf("%d %d", a, m / a * n);
    return 0;
}
注意看 a 和 b：停的时候 b 已经变成 0，答案留在 a 里。
同一道题，把辗转相除拎出来
int gcd(int a, int b)
{
    int r;
    while (b != 0) {
        r = a % b;
        a = b;  b = r;
    }
    return a;
}
形状 两个数进去，一个数出来，跟第 14 页的 power(x, n) 一个形状。里面的 a、b 是形参。 
int main()
{
    int m, n, g;
    scanf("%d %d", &m, &n);
    g = gcd(m, n);
    printf("%d %d", g, m / g * n);
    return 0;
}
main 剩下什么 读进来、求最大公约数、算最小公倍数、打出去，四行。程序行为一点没变，511 292 进去，还是 73 2044 出来。 gcd 写在 main 上面，第 17 页那条「先声明后使用」也满足了。
拆与不拆，拿三个改动试一遍
后来遇到的情况上一页那种写法这一页这种写法
题目改成三个数求公约数六行再抄一遍，变量另起一套gcd(gcd(a,b), c)，一行
换一道新题，也要约分换个程序，从头再想一遍把 gcd 贴过去，只改输入输出
发现 a、b 写反了要改用一次改一次，抄三遍改三遍只改 gcd 里那两行
隔一周再回来看代码12 行，算法混在中间8 行，一眼看到整个流程
说句实话 总行数没有变少：函数 9 行，main 8 行，加起来比原来还多几行。 少的是 main 里要同时装着的东西。拿到一个程序先读 main， 能看出它在干什么，这就够了。
还有一条 跨程序复用，还是得把 gcd 那九行复制走。 但复制的是现成、有名字、验过的代码，不用再想一遍辗转相除怎么转。

题目 输入一个分数，输出它的最简分式。分子分母都是正整数， 输入形如 66/120。

再看一道：打印菱形图案
题目 输入正奇数 n，打印高 n 的菱形，每个星号后跟一个空格。 （n 已读入；变量已声明）
* * * * * * * * * * * * * * * * * * * * * * * * * 
for (i = 1; i <= (n+1)/2; i++) {  /* 上半 */
    s = (n+1)/2 - i;  /* 缩 s 格 */
    for (j = 1; j <= s; j++) printf("  ");  /* 两空格 */
    for (j = 1; j <= 2*i-1; j++) printf("* ");  /* 打星 */
    printf("\n");
}
for (i = (n-1)/2; i >= 1; i--) {  /* 下半 */
    s = (n+1)/2 - i;  /* 同上 */
    for (j = 1; j <= s; j++) printf("  ");
    for (j = 1; j <= 2*i-1; j++) printf("* ");
    printf("\n");
}
两段只有第一行不同，里面四行一个字不差。 缩进打两个空格、星号打「星加空格」，都是两个字符一步，上下一格对一格。
一行图案，抽成一个函数
void printLine(int i, int n)
{
    int j, s = (n+1)/2 - i;
    for (j = 1; j <= s; j++)
        printf("  ");
    for (j = 1; j <= 2*i-1; j++)
        printf("* ");
    printf("\n");
}
只管一行 给它第几行、总共几行，它还你一行图案。 
int main()
{
    int n, i;
    scanf("%d", &n);
    for (i = 1; i <= (n+1)/2; i++)
        printLine(i, n);
    for (i = (n-1)/2; i >= 1; i--)
        printLine(i, n);
    return 0;
}
两个 for 只差 i 怎么走 循环体都是 printLine(i, n)，一星后跟一个空格的写法全程序只写了一次。

连续 6 行「读数 → 判断奇偶 → 打印」，在三个地方原样出现。要不要抽成函数？
A. 不用，能跑就行 B. 要，第二次就该拆
答案 1 · 哪个定义合法
选 B。A 第二个参数 b 没写类型，C 漏了返回类型，D 有返回值却写成 a+1;，没有 return，交回去的是个不确定的值。B 四个零件齐全。
再点一次「看解析」收起来
答案 2 · swap 白忙一场
选 B，x 和 y 还是 3 和 5。调用时传进去的是值的副本：a、b 是另外两块内存，在里面怎么换都动不到 x、y。这一讲先记住结论，下一讲讲透为什么，第 8 章用指针才能真正换过来。
再点一次「看解析」收起来
答案 3 · 两次调用加起来
选 C，10。f(-7) 返回 7，f(3) 返回 3，7 + 3 = 10。注意这一行里发生了两次独立调用，各自算各自的，互不影响。
再点一次「看解析」收起来
答案 4 · 要不要拆
选 B。同一段代码出现第二次，就是最硬的拆分信号；而且这六行能一句话说清（「读一个数，判断奇偶，打印」），三条信号占了两条。抽成 void checkOne() 之后，三处都变成一行调用，将来改打印格式只改一处。

本讲小结
  • ① 为什么要拆main 越长，改一处越容易漏三处
  • ② 怎么拆写出来 → 圈重复 → 抽出去 → 原处换调用
  • ③ 四个零件返回类型、函数名、参数表、函数体
  • ④ 四种形态有无返回值 × 有无参数，两个问句就能定
  • ⑤ 拿作业试过gcd、约分、菱形，三道题都改成了函数版
记住这一条 函数就是给一段代码起名字。有了名字，你才能在另一处说「把这件事做一遍」， 而不必把细节再抄一遍。
