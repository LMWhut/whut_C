这一章解决的是 「怎么分」：把一个大程序切成几个小块，每块只管一件事，各自有名字。 这个小块，就叫函数。
先看一个问题：三个循环，同一段逻辑
/* 求 C(10,3) = 10! / (3! × 7!) */
long f1 = 1, f2 = 1, f3 = 1;
int i;

for (i = 1; i <= 10; i++) f1 *= i;
for (i = 1; i <= 3;  i++) f2 *= i;
for (i = 1; i <= 7;  i++) f3 *= i;

printf("%ld\n", f1 / (f2 * f3));
120
观察 三个循环结构完全相同，只差一个上限：10、3、7。
危险在哪 如果哪天要改成「累加」而不是「累乘」，你得改三处。 改两处忘一处，这种错误编译器不报，运行时才出鬼。
注意 这段代码没有错，可以运行，结果也正确。问题不在对错， 在于三段逻辑没有名字。
不用换 double 三个数都是 long，除的是整数。组合数一定除得尽， 所以 %ld 就对。换成 double 反倒引入小数误差。
提取成函数，为它命名
/* 算 k 的阶乘 */
long fact(int k)
{
    long r = 1;
    int i;
    for (i = 1; i <= k; i++) r *= i;
    return r;
}

/* 调用时只写几的阶乘 */
printf("%ld",
       fact(10) / (fact(3) * fact(7)));
变化 三遍重复的循环 → 一个函数 + 一行调用。 以后要算 20 的阶乘，也只是 fact(20)。
关键 函数把「怎么做」隐藏起来，只把「做什么」暴露在外。 看到 fact(10)，你不需要读循环，就知道它在算 10 的阶乘。
于是 要改算法？只改 fact 一处，三处调用一并更新。

定义一个函数：四个零件
int max(int a, int b)
{
    return a > b ? a : b;
}
读法 「int 类型的 max，需要两个 int 参数，返回一个 int」。把这一句读顺，这个函数就清楚了。
零件本例作用
返回类型int返回什么类型；不返回写 void
函数名max以后就用这个名字叫它
参数表(int a, int b)需要你给什么；不给写 ()
函数体{ … }实际执行计算的语句
语法骨架：一张图记住
返回类型  函数名(参数表)
{
    语句1;
    语句2;
    return 表达式;   /* 有返回值才写 */
}
位置 函数要写在 main 的外面， 不能写在 main 的花括号里面： C 语言不允许函数嵌套定义。
三处最容易漏 ① 返回类型不能省。老教材省了默认 int，现代编译器直接报错。
② 每个参数都要写类型。(int a, b) 是错的，要写 (int a, int b)。
③ 函数体后面不加分号。只有声明和调用才加分号。
对照记忆 定义像「写菜谱」：材料、步骤全写清，放那儿备用。
调用像「点菜」：只说菜名和份数，不管怎么做。
形态一：无返回值、无参数
/* ① 定义：写清函数名和函数体 */
void printTitle()
{
    printf("=== 成绩统计 ===\n");
    printf("学号  姓名  成绩\n");
}

int main()
{
    printTitle();      /* ② 调用 */
    printTitle();      /* 再调一次 */
    return 0;
}
void 「空」的意思：不返回值。函数执行完毕后结束，调用处得不到结果。
调用三件套 函数名 + 括号 + 分号：printTitle(); 括号不能省，哪怕里面什么都没有。
=== 成绩统计 === 学号 姓名 成绩 === 成绩统计 === 学号 姓名 成绩
形态二：无返回值、有参数
void printScore(int no, int score)
{
    printf("第 %2d 位：%3d 分\n",
           no, score);
}

int main()
{
    printScore(1, 92);
    printScore(2, 78);
    return 0;
}
形参就是变量 no 和 score 进了函数， 就是两个普通变量，能读能算能打印。
一句话说清 同一段逻辑，换一组数据再执行一次，这就是参数的作用。
第 1 位： 92 分 第 2 位： 78 分
形态三：有返回值、无参数
int getChoice()
{
    int c;
    scanf("%d", &c);
    return c;
}

int main()
{
    int op = getChoice();
    printf("你选了 %d\n", op);
    return 0;
}
什么时候用 数据不由调用方传入：函数自行从键盘读取、自行获取系统时间。 参数表为空，但仍有返回值。
看清楚这一行 op = getChoice();
等号右边的这一次调用，整个被替换成它的返回值。 所以这一行等价于：先调用函数取得返回值，再赋给 op。
换个写法 不接收也行：getChoice();， 值被丢掉了，但函数确实执行过。
形态四：有返回值、有参数（最常用）
double power(double x, int n)
{
    double r = 1.0;
    int i;
    for (i = 1; i <= n; i++) r *= x;
    return r;
}

int main()
{
    printf("%.2lf\n", power(2.0, 10));
    return 0;
}
参数传入，返回值传出 这是最常用的形态：double 传入，double 返回。 数学里的函数几乎都能写成这种形态。
返回值也能直接参与运算 power(2,10) + 1、 power(2,10) / 2 都合法， 因为调用处得到的就是一个数。
1024.00
四种形态，一张表
形态定义的形式典型例子
无返无参void f()打印表头 printTitle()
无返有参void f(类型 名)打印一条记录 printScore(no, score)

怎么记 两个问句就够了：它有没有返回值？（定 void 还是类型） 它需不需要参数？（定参数表空不空）。
提醒 用得最多的是有返回值、有参数这一种。最简单的 无返回值、无参数也别小看：把一段固定动作打包、起个名字，程序立刻好读。
return 的三个作用
int check(int x)
{
    if (x < 0)
        return 0;      /* 提前返回 */
    if (x > 100)
        return 100;    /* 提前返回 */
    return x;          /* 正常返回 */
}
check(-5) → 0 check(95) → 95 check(120) → 100
① 立刻结束函数 后面的语句一句都不再执行，直接把控制权交还调用处。
② 返回一个值 值的类型必须和「返回类型」对得上。写 int 却 return 3.7，会被截成 3。
③ 一次只带一个值 想带回多个？得靠指针或数组，那是第 8 章的事。
常见坑 return 后面写代码 = 永远执行不到。编译器给警告，别忽略。
先声明，后使用
#include <stdio.h>

double power(double x, int n);  /*声明*/
int main()
{
    printf("%.2lf\n", power(2, 10));
    return 0;
}

double power(double x, int n)   /*定义*/
{
    double r = 1.0;
    while (n-- > 0) r *= x;
    return r;
}
为什么需要 编译器从上往下读代码。读到 main 里的 power(2,10) 时，它还没见过这个函数，就会报「未声明的标识符」。
声明的作用 提前告诉编译器：有这样一个函数，形式如下。它的形式就是返回类型、名字、参数表。
顺手 声明也可以写成 double power(double, int);， 参数名可以省，类型不能省。
声明和定义，差在哪
　声明定义
作用只写返回类型、函数名、参数把函数体完整写出来
有没有函数体没有，以分号结尾有 { }，不加分号
能写几次可以写多次只能写一次
什么时候必须写定义写在调用之后时永远必须有
两个省事的办法 ① 把函数定义写在 main 前面，就不用单独声明了。
② 函数多了以后，把声明集中放在文件开头（以后配 .h 头文件就是这么来的）。
别混 double power(double x, int n) 后面带分号＝声明； 带花括号＝定义。看结尾就知道是哪一个。

作业里的题：最大公约数和最小公倍数
题目 输入两个正整数 M 和 N（都不超过 1000），输出它们的最大公约数， 再输出最小公倍数，中间空一格。这一版可以通过，12 行。
输入　511 292 输出　73 2044
算法 辗转相除法第 4 章已讲过，不再重复。最小公倍数写成 m / a * n，先除后乘。
为什么加 a = m; b = n; m、n 还要用来算最小公倍数，辗转相除交给副本 a、b 去做。 
#include <stdio.h>
int main()
{
    int m, n, a, b, r;
    scanf("%d %d", &m, &n);
    a = m;  b = n;
    while (b != 0) {       /* 辗转相除 */
        r = a % b;  a = b;  b = r;
    }
    printf("%d %d", a, m / a * n);
    return 0;
}
注意看 a 和 b：停的时候 b 已经变成 0，答案留在 a 里。
同一道题，把辗转相除提取出来
int gcd(int a, int b)
{
    int r;
    while (b != 0) {
        r = a % b;
        a = b;  b = r;
    }
    return a;
}
形状 两个数传入，一个数传出，与第 14 页的 power(x, n) 一个形状。里面的 a、b 是形参。 
int main()
{
    int m, n, g;
    scanf("%d %d", &m, &n);
    g = gcd(m, n);
    printf("%d %d", g, m / g * n);
    return 0;
}
main 剩下什么 读入、求最大公约数、求最小公倍数、输出，四行。程序行为没有变化，输入 511 292，输出仍是 73 2044。 gcd 写在 main 上面，第 17 页那条「先声明后使用」也满足了。

再看一道：打印菱形图案
题目 输入正奇数 n，打印高 n 的菱形，每个星号后跟一个空格。 （n 已读入；变量已声明）
* * * * * * * * * * * * * * * * * * * * * * * * * 
for (i = 1; i <= (n+1)/2; i++) {  /* 上半 */
    s = (n+1)/2 - i;  /* 缩 s 格 */
    for (j = 1; j <= s; j++) printf("  ");  /* 两空格 */
    for (j = 1; j <= 2*i-1; j++) printf("* ");  /* 打星 */
    printf("\n");
}
for (i = (n-1)/2; i >= 1; i--) {  /* 下半 */
    s = (n+1)/2 - i;  /* 同上 */
    for (j = 1; j <= s; j++) printf("  ");
    for (j = 1; j <= 2*i-1; j++) printf("* ");
    printf("\n");
}
两段只有第一行不同，里面四行一个字不差。 缩进打两个空格、星号打「星加空格」，都是两个字符一步，上下一格对一格。
一行图案，提取成一个函数
void printLine(int i, int n)
{
    int j, s = (n+1)/2 - i;
    for (j = 1; j <= s; j++)
        printf("  ");
    for (j = 1; j <= 2*i-1; j++)
        printf("* ");
    printf("\n");
}
只管一行 传入第几行与总行数，输出对应的一行图案。 
int main()
{
    int n, i;
    scanf("%d", &n);
    for (i = 1; i <= (n+1)/2; i++)
        printLine(i, n);
    for (i = (n-1)/2; i >= 1; i--)
        printLine(i, n);
    return 0;
}
两个 for 语句仅循环变量的走向不同 循环体都是 printLine(i, n)，一星后跟一个空格的写法全程序只写了一次。

封装到哪一层为止 判据两条：能否一句话说清，以后会不会单独修改。两条都成立才拆。

答案 · 一个函数，字符作参数
void printChar(int n, char c)
{
    int i;
    for (i = 1; i <= n; i++)
        printf("%c ", c);
}
void printLine(int i, int n)
{
    printChar((n+1)/2 - i, ' ');
    printChar(2*i-1, '*');
    printf("\n");
}
"%c " 表示一个字符后面跟一个空格：传 ' ' 得到两个空格，传 '*' 得到星号加一个空格，宽度都是两个字符。函数名换成一个、实参各多一个字符，main 一行不用动。

int main()
{
    int m, n, i, k, num = 0, sum = 0;
    scanf("%d %d", &m, &n);
    for (i = m; i <= n; i++) {
        for (k = 2; k < i; k++)
            if (i % k == 0) break;
        if (k == i && i >= 2) {
            sum += i; num++;
        }
    }
    printf("%d %d\n", num, sum);
    return 0;
}
题目 输入两个正整数 M 和 N（2 ≤ M ≤ N ≤ 10000），统计 M 到 N 之间（含两端）有几个素数，并求这些素数的和。
算法三步 ① 读入 M 和 N；
② i 从 M 到 N，每一步判断「i 是不是素数」，是则计数并累加；
③ 输出个数与和。
中间那一步，你能一句话说清吗 「i 是素数吗」五个字，落到代码上是三行循环加一个判断。第 7 页说过，能用一句话说清就是应当拆分的信号。

提取之后 传入一个数，返回是或不是 
int isPrime(int n)
{
    int i;
    for (i = 2; i < n; i++)
        if (n % i == 0) break;
    if (i == n && n >= 2) return 1;
    return 0;
}
返回值不一定是个数 前面 power(2, 10) 算出 1024，gcd(511, 292) 算出 73，都是数值；isPrime 算出来只有 1 和 0，它在回答「是」还是「不是」。
判闰年、判回文、判完全数都是这个形状，调用处写成 if (isPrime(i))，读起来就是一句自然语言。

A 版 试到 √n 就停，但没有管 0、1 和负数 
int isPrime(int num)
{
    int i;
    for (i = 2; i <= sqrt(num); i++)
        if (num % i == 0) break;
    if (i > sqrt(num)) return 1;
    return 0;
}
B 版 速度相同，多一道守卫 
int isPrime(int num)
{
    int i, p = 1;
    if (num < 2) return 0;
    for (i = 2; i <= sqrt(num); i++)
        if (num % i == 0) p = 0;
    return p;
}
0 和 1 两个输入：A 版给 1，B 版给 0
A 版错在哪 循环一次都不跑时 i 停在 2，i > sqrt(num) 成立，0 和 1 就被判成素数。B 版那行守卫，堵的就是这里。
