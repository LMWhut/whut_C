单分支 if 语句（含流程图）
回顾if 后圆括号内是表达式，值为非 0 即"真"、0 即"假"。
格式
if ( 表达式 )
    内嵌语句;
执行过程
  • 计算表达式的值
  • 非 0 → 执行内嵌语句
  • 0 → 跳过，执行 if 的下一条
int score = 85;
if (score >= 60)
    printf("及格！\n");
读图真 → 执行语句；假 → 跳过，两条路都汇合到结束。
单分支 if 判断题（对照流程图）
问题当 a > b 时交换 a、b 的值，哪段代码正确？

❌ 代码段 A

if (a > b)
    t = a;
a = b;
b = t;

只有 t=a 受 if 控制，a=b / b=t 在 if 语句外面，总会执行。

✅ 代码段 B

if (a > b) {
    t = a;
    a = b;
    b = t;
}

三条语句都在 {} 内，作为一个整体受 if 控制。

单分支 if 语句：表达式的类型
说明if 后圆括号内的表达式可以是任何类型，只要能算出 0 或非 0。 
if (a == b && x == y)   printf("a=b, x=y");
if (3)    printf("OK");   // 3 非0，恒真
if (a)    printf("%d", a); // 等价于 if(a!=0)
if (x) ... // 等价于 if(x!=0)
if (!x) ... // 等价于 if(x==0)
常见写法
if (x) ≡ if (x != 0)
if (!x) ≡ if (x == 0)
单分支——复合语句（大括号的重要性）
问题多条语句必须用大括号 { } 括起来，否则只有第一条受 if 控制。

❌ 错误示例

if (score >= 60)
    printf("及格！\n");
printf("拿学分！\n");  // 总执行

第二句不受 if 控制，逻辑错误。

✅ 正确示例

if (score >= 60) {
    printf("及格！\n");
    printf("拿学分！\n");
}

两条语句整体受 if 控制。

结论无论几条语句，推荐总是加大括号，更清晰、更安全。
例：模拟路口交通信号灯系统
要求输入 g/G → 可通行；r/R → 不可通行；y/Y → 等待。 
char light; 　　// 信号灯
scanf("%c", &light);

if (light == 'g' || light == 'G')
    printf("Green light on. Go!\n");

if (light == 'r' || light == 'R')
    printf("Red light on. Stop!\n");

if (light == 'y' || light == 'Y')
    printf("Yellow light on. Wait!\n");
思路三个独立的 if 语句分别处理三种字符，互不干扰。
运行输出
输入 g ：Green light on. Go! 输入 r ：Red light on. Stop! 输入 y ：Yellow light on. Wait!
双分支 if-else 语句
格式
if ( 表达式 )
    语句1;
else
    语句2;
执行过程
  • 非 0 → 执行语句 1
  • 0 → 执行语句 2
if (steps > 10000)
    printf("运动达人！\n");
else
    printf("加油哦！\n");
注意else 不能单独存在，必须与 if 配对。
读图非此即彼：有且仅有一个分支被执行。
例：信号灯（双分支写法）
要求输入 g/G 提示可通行，其他字符提示不可通行。 
char light;  scanf("%c", &light);

if (light == 'g' || light == 'G')
    printf("Green light on. Go!\n");
else
    printf("Green light not on. Cannot go!\n");
对比单分支用三个独立 if；双分支用一个 if-else 处理"通行/不通行"。
运行输出
输入 g ： Green light on. Go! 输入 x ： Green light not on. Cannot go!
例：判断三边能否构成三角形
分析任意两边之和 > 第三边则可构成三角形，计算面积；否则报错。 
#include <stdio.h>
#include <math.h>
int main() {
  double a, b, c, s, area;
  scanf("%lf %lf %lf", &a, &b, &c);
  if (a+b>c && a+c>b && b+c>a){
    s = 0.5*(a+b+c);
    area = sqrt(s*(s-a)*(s-b)*(s-c));
    printf("area=%f\n", area);
  } else
    printf("Data error!\n");
  return 0;
}
海伦公式

\[ s=\frac{1}{2}(a+b+c) \]
\[ area=\sqrt{s(s-a)(s-b)(s-c)} \]

关键判定用 && 连三个不等式。
输入 → 输出
3 4 5 → area=6.000000 1 2 3 → Data error!
条件运算符 ? :
格式
表达式1 ? 表达式2 : 表达式3
执行过程
  • 先计算表达式 1
  • 若为 非 0（真） → 取表达式 2 的值
  • 若为 0（假） → 取表达式 3 的值
特点它是 C 语言中唯一一个三目运算符，常用于简化简单的 if-else 赋值。
示例：求两数最大值
max = (a > b) ? a : b;
等价于 if-else
if (a > b)
    max = a;
else
    max = b;
运行示例
设 int a = 5, b = 8;
执行 max = (a > b) ? a : b; 后，max 结果为 8。
因为 a > b 为假（0），所以取 b 的值。
条件运算的常见应用
目的表达式
求绝对值abs = (x >= 0) ? x : -x;
非负整数奇偶性odd = (x % 2 == 1) ? 1 : 0;
小写转大写c = (c>='a'&&c<='z') ? c-32 : c;
三数最大值max=(a>b && a>c)? a : (b>c ? b:c);
判断 x 符号s = x>0 ? 1 : (x<0 ? -1 : 0);
建议当 if-else 的两个分支都是给同一变量赋值时，可用条件运算符简化。
逻辑运算符的"短路求值"
短路&& 与 || 一旦能确定整体结果，就不再算后面的表达式：&& 遇假即停，|| 遇真即停。 
int x = 0;
if (x != 0 && 1/x > 0.5)   // x==0 时右半不执行
    printf("ok\n");      // 巧妙避免"除零"
int a[5]={1,2,3,4,5}, i=9;
if (i < 5 && a[i] == 3)   // i>=5 时右半不执行
    printf("found\n");    // 避免数组越界
注意短路是"安全特性"，但勿依赖它执行有副作用的语句，可读性差。
嵌套 if 语句（含流程图）
格式
if (表达式) {
    if (表达式1)
        语句1;
    else
        语句2;
} else {
    if (表达式2)
        语句3;
    else
        语句4;
}
执行从上到下依次判断，遇第一个真条件执行对应语句后跳出。
读图外层分支里再嵌一层判断，逐层缩小范围。
例：判断 x 的符号
要求x>0 时 y=1；x=0 时 y=0；x<0 时 y=-1。
写法一：按 x>=0 分支
if (x >= 0)
    if (x == 0) y = 0;
    else        y = 1;
else
    y = -1;
写法二：按 x!=0 分支
if (x != 0)
    if (x > 0) y = 1;
    else       y = -1;
else
    y = 0;
对比两种写法结果一致，第一种更直观；嵌套时注意 else 与哪个 if 配对。
else if 多分支结构（含流程图）
格式
if (表达式1)
    语句1;
else if (表达式2)
    语句2;
...
else
    语句n;
说明这是双分支在 else 中嵌套 if 的简化形式，多分支最常用。
读图逐层判断，命中即执行并结束；全不中走 else。
例：根据分数评定等级
要求≥90→A　≥80→B　≥70→C　≥60→D　<60→E（不及格） 
int score;  scanf("%d", &score);
if (score >= 90)      printf("A\n");
else if (score >= 80) printf("B\n");
else if (score >= 70) printf("C\n");
else if (score >= 60) printf("D\n");
else                  printf("E\n");
关键不用写 score < 90：前面已按序排除，能走到这行必然 <90。顺序很重要！
输出
输入 85 → B　　输入 58 → E (不及格)
例：输入年、月，输出该月天数
分析大月 31 天；小月 30 天；2 月闰年 29、平年 28。闰年：(year%4==0 && year%100!=0) || year%400==0。 
int year, month, days;
scanf("%d %d", &year, &month);
if (month==1||month==3||month==5||month==7||
    month==8||month==10||month==12)   days = 31;
else if (month==4||month==6||month==9||month==11) days = 30;
else {
  if ((year%4==0 && year%100!=0) || year%400==0) days = 29;
  else days = 28;
}
输出
2024 2 → 29　　2023 2 → 28　　2023 4 → 30
悬空 else：else 到底与哪个 if 配对
原始代码
if (a > b)
    if (c > d)
        x = 1;
    else
        x = 2;
分析else 与离它最近、尚未配对的 if 配对。即内层 if (c > d)，而非外层 if (a > b)。
✅ 用大括号强制配对
if (a > b) {
    if (c > d) 
        x = 1;
} else
    x = 2;
原理加了花括号 { } 之后，内层的 if...else 就成了一个完整的整体，外层的 else 就只能和 外层的 if (a > b) 配对了。
悬空 else 对比
思考以下两段代码运行结果一样吗？
代码 1
int a=2, b=-1, c=2;
if (a < b)
  if (b < 0) c = 0;
  else    c++;
printf("%d\n", c);
代码 2
int a=2,b=-1,c=2;
if (a < b) {
  if (b < 0) { c = 0; }
  else   { c++; }
}
printf("%d\n", c);
答案都输出 c = 2：a < b 为假，外层整体不执行。嵌套时务必加大括号。
单选练习
题目以下程序段运行后的输出结果是（　　）。 
int x=1, y=0;
if (!x) y++;
else if (x == 0)
    if (x) y += 2;
    else y += 3;
printf("%d\n", y);
分析x=1→!x=0 跳过；x==0 为假跳过 else if 整体；y 保持 0，输出 0。嵌套务必加大括号。
综合应用 1：三个数排序（年龄排序）
问题输入三个人的年龄，按从小到大输出。
方法一：比较交换，使 a ≤ b ≤ c
if (a > b) { t=a; a=b; b=t; }   // 调 a,b
if (a > c) { t=a; a=c; c=t; }   // 调 a,c，a 最小
if (b > c) { t=b; b=c; c=t; }   // 调 b,c，c 最大
printf("%d %d %d", a, b, c);
思路三次比较交换即可保证 a ≤ b ≤ c。
三数排序（方法二：条件运算符）
min = (a < b && a < c) ? a : (b < c ? b : c);
max = (a > b && a > c) ? a : (b > c ? b : c);
mid = a + b + c - min - max;
printf("%d %d %d", min, mid, max);
提醒方法二虽"巧妙"，但三层嵌套 ? : 可读性下降——再次印证：复杂逻辑用 if 更清楚。
综合应用 2：随机加法练习
要求计算机随机出 100 以内加法题，回答后：正确 → 鼓励；错误 → 询问是否看答案。 
// 随机加法练习
srand(time(0));                 // 随机种子
a = rand() % 100; 
b = rand() % 100; 
c = a + b;

printf("Please compute: %d + %d = ", a, b);
scanf("%d", &d);

if (c == d)
    printf("Right!\n");
else {
    printf("Wrong, your answer: %d.\n", d);
    printf("See answer(y/n)?");
    scanf(" %c", &q);            // %c 前加空格
    if (q == 'y' || q == 'Y')
        printf("Right answer: %d\n", c);
}
运行示例
Please compute: 37 + 58 = 95 Right! （若输入错误：） Please compute: 37 + 58 = 90 Wrong, your answer: 90. See answer(y/n)? y Right answer: 95
避坑读取字符前留个空格：scanf(" %c", &q);，以跳过上次输入留下的回车符。
随机数函数 rand() 和 srand()
  • ① rand()产生 [0, 32767) 的伪随机整数
  • ② srand()设种子，一般用 srand(time(0))（当前秒）
  • ③ 头文件#include <stdlib.h> 与 #include <time.h>
#include <stdlib.h> 
#include <time.h>
int a, b;
srand(time(0));      // 设定种子
a = rand() % 100;    // 0~99 随机数
b = rand() % 100;
要点不调用 srand()，每次运行产生的序列相同。
输入缓冲区残留字符问题
成因scanf 读取后，输入的换行符 \n 残留在缓冲区，干扰后续输入。

❌ 错误示范

scanf("%d", &num);
ch = getchar();  // 读到残留'\n'

不会等待输入，直接读到换行符。

✅ 正确示范

scanf("%d", &num);
getchar();       // 清掉 1 个空白
ch = getchar();  // 读到用户输入

两次输入间加 getchar() 吃掉残留。

替代① scanf(" %c", &ch);　② scanf("%d\n", &num);　③ while (getchar() != '\n');
注意事项与常见错误
错误类型说明 / 正确做法
忘记大括号if 后多条语句未用 {}，仅第一条受控。即使一条也建议加 {}。
= 误写为 ==赋值误用于判断，条件恒真。比较用 if (a == b)。
分号位置错误if (a>b); 多分号，if 空转。去掉多余分号。
else 未配对else 单独出现，无法编译。检查 if-else 配对。
悬空 elseelse 与错误的 if 配对。用大括号强制配对。
短路误用依赖短路执行有副作用语句。把必执行逻辑独立写出。
输入缓冲区上次换行符影响后续字符读入。加 getchar() 或 " %c"。

  • ④ 条件运算符a?b:c，适合简单赋值
  • ⑤ 短路求值&& 遇假即停、|| 遇真即停
  • ⑥ 多分支嵌套 if / else if 链，顺序很重要
  • ⑦ 常见错误大括号、= 与 ==、分号、else 配对、短路误用、缓冲区
