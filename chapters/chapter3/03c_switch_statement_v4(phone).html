为什么需要 switch 语句？
痛点当条件判断有很多个分支时，用 if-else if 会显得非常臃肿和重复。
用 if-else 写（繁琐）
if (choice == 1)
    printf("查话费");
else if (choice == 2)
    printf("查流量");
else if (choice == 3)
    printf("办套餐");
else
    printf("退出");
用 switch 写（清爽）
switch (choice) {
    case 1: printf("查话费"); break;
    case 2: printf("查流量"); break;
    case 3: printf("办套餐"); break;
    default: printf("退出");
}
结论对于等值判断（等于几），使用 switch 结构更清晰、更易读。
switch 语句：基本格式与执行过程
基本格式
switch (表达式) {
    case 常量1:
        语句组1; break;
    case 常量2:
        语句组2; break;
    ...
    default:
        语句组n;
}
执行过程
  • 计算：计算表达式的值
  • 匹配：依次与常量比较
  • 执行：命中即执行，遇 break 跳出
  • 兜底：全不中则走 default
硬性规定
① switch 后的表达式必须是 整型（int/char/enum）。
② case 后必须是常量（如 1、'A'），不能是变量。
③ 每个 case 后要加冒号。
④ break 用于跳出；省略会穿透。
⑤ case 值必须互不相同。
流程图开始 → 计算表达式 → 与 case 常量比较 → 匹配则执行对应语句组 → 遇 break 跳出 / 否则穿透 → 结束。
核心陷阱：漏写 break 的后果
注意如果漏写了 break;，程序不会跳出 switch，而是会继续往下执行，这叫 穿透（Fall-through）。
❌ 漏写 break（发生穿透）
int score = 1;
switch (score) {
    case 1: printf("A\n");
    case 2: printf("B\n");
    case 3: printf("C\n");
}
// 输出结果 A B C
✅ 正确写法（加了 break）
int score = 1;
switch (score) {
    case 1: printf("A\n"); break;
    case 2: printf("B\n"); break;
    case 3: printf("C\n"); break;
}
// 输出结果 A
结论一旦匹配上某个 case，如果没有遇到 break，就会像滑梯一样把后面的代码全执行一遍。在绝大多数业务场景下，这都是严重的逻辑漏洞。
正向应用：善用穿透合并分支
技巧有时我们会故意省略 break，让多个 case 共用一段代码，使逻辑更简洁。
示例：成绩等级合并
switch (grade) {
    case 'A':
    case 'B':
    case 'C':
        printf("及格\n");      break;
    case 'D':
        printf("不及格\n");    break;
    default:
        printf("Error\n");
}
多个 case 连续写在一起，表示它们共用同一段执行语句。
练习：判断工作日与周末
int day = 3; // 周三
switch (day) {
    case 1: case 2: case 3: 
    case 4: case 5:
        printf("工作日\n");   break;
    case 6: case 7:
        printf("休息日\n");   break;
    default:   printf("输入错误\n");
}
输出如果 day = 3，程序连续穿透 3、4、5，最终打印“工作日”。
练习：输入 1~7，输出星期名（整数 vs 字符）
写法一：用整数判断
int d;
scanf("%d", &d);

switch (d) {
    case 1: printf("Monday");    break;
    case 2: printf("Tuesday");   break;
    case 3: printf("Wednesday"); break;
    case 4: printf("Thursday");  break;
    case 5: printf("Friday");    break;
    case 6: printf("Saturday");  break;
    case 7: printf("Sunday");    break;
    default: printf("Error");    break;
}
输入数字 3 → 输出 Wednesday
写法二：用字符判断
char d;
scanf("%c", &d); // 注意这里是 %c

switch (d) {
    case '1': printf("Monday");    break;
    case '2': printf("Tuesday");   break;
    case '3': printf("Wednesday"); break;
    case '4': printf("Thursday");  break;
    case '5': printf("Friday");    break;
    case '6': printf("Saturday");  break;
    case '7': printf("Sunday");    break;
    default: printf("Error");    break;
}
输入字符 3 → 输出 Wednesday
区别：case '3' 里存的是 ASCII 码 51，不是数值 3！
总结：整数与字符在 switch 中的差异
核心结论 在 C 语言中，case 后面跟的数据必须与 switch 括号里的变量类型完全一致。用 int 就要配数字，用 char 就要配字符。
对比维度用整数判断（推荐）用字符判断
变量定义int d;char d;
输入格式scanf("%d", &d);scanf("%c", &d);
case 写法case 1:case '1':
输入 3 的底层值数值 3字符 '3' (ASCII 码 51)
多字符输入容错较好。输入 13 会匹配失败，走 default。极差。输入 13 会截断为 '1'，导致误判。
为什么推荐用 %d？对于“1~7”这类数字输入，用 %d 读入更安全。遇到非法输入（如 13）可以直接被 default 拦截。
什么时候用 %c？只有当菜单选项是真正的“字母”（如 A、B、C 或 y/n）时，才使用 %c 配合单引号。
综合应用：判断分数段（整数版）
核心思路 利用 score / 10 进行整除，把连续的分数段“降维”成 0~10 的固定整数，从而使用 switch 进行精准匹配。 
int score;
scanf("%d", &score);

switch (score / 10) {
    case 10: printf("满分！\n"); break;
    case 9:  printf("优秀 (90~99)\n"); break;
    case 8:  printf("良好 (80~89)\n"); break;
    case 7:  printf("中等 (70~79)\n"); break;
    case 6:  printf("及格 (60~69)\n"); break;
    default: printf("不及格 (<60)\n"); break;
}
运行示例 输入: 95 → 输出: 优秀 (90~99)
输入: 59 → 输出: 不及格 (<60)
思考：这样写严谨吗？
如果输入了 -5 或 105 会怎样？
· -5 / 10 结果是 0，会输出“不及格”。
· 105 / 10 结果是 10，会输出“满分”。
工程建议：在 switch 前，先用 if (score < 0 || score > 100) 拦截非法分数！
进阶思考如果成绩是带有小数的实数（如 89.5 分），switch 还能用吗？
进阶拓展：如果成绩是带小数的实数？
核心原则 switch 的表达式绝对不能是浮点数。必须先用四舍五入把小数转换为整数。
写法一：手写四舍五入
// 加 0.5 后强转，实现四舍五入
int s = (int)(score + 0.5);
写法二：使用 round() 函数
#include <math.h>
// 标准库四舍五入，返回浮点数
int s = (int)round(score);
round() 函数返回值仍是浮点数，必须用 (int) 强转。
异常测试 如果输入 105.5，如果不拦截，四舍五入后整除得到 10，会错误输出“满分”！通过前置 if 拦截，即可提示“成绩输入错误”。
完整代码（含非法输入拦截）
#include <math.h>

    double score;
    scanf("%lf", &score);
    
    // 1. 先拦截非法数据 (-1 ~ 101 以外)
    if (score < 0 || score > 100) {
        printf("成绩输入错误！\n");
        return 0;
    }
    
    // 2. 将合法浮点数四舍五入转整数
    int s = (int)round(score);
    
    // 3. 利用整除进行分段匹配
    switch (s / 10) {
        case 10: printf("满分！\n"); break;
        ......
        default:  printf("不及格 (<60)\n"); break;
    }
综合案例 1：判断某月有多少天
int year, month, days;
scanf("%d %d", &year, &month);

switch (month) {
    case 1: case 3: case 5:
    case 7: case 8: case 10: case 12:
        days = 31;  break;
    case 4: case 6: case 9: case 11:
        days = 30;  break;
    case 2:
        if ((year%4==0 && year%100!=0) || year%400==0)
            days = 29;
        else
            days = 28;
        break;
}

printf("%d年%d月有%d天\n", year, month, days);
思路把多个相同天数的月份合并到一组，这是 switch 穿透最经典的用法。
2 月处理2 月是特例，所以单独列出，内部使用 if-else 判断是否闰年。
问题如果输入数据异常（数据不符合要求）时，应该如何处理？可以直接加 default: printf("输入错误！"); 吗？
综合案例 1：判断某月有多少天（实现对比）
方法一：switch + 前置拦截
if (month < 1 || month > 12) {
    printf("月份错误\n");
} else {
    switch (month) {
      case 1: case 3: case 5:
      case 7: case 8: case 10: case 12:
            days = 31;  break;
      case 4: case 6: case 9: case 11:
            days = 30;  break;
      case 2:
        if ((year%4==0 && year%100!=0) || year%400==0)
                days = 29;
        else days = 28;
        break;
    }
    printf("%d年%d月有%d天\n", year, month, days);
}
方法二：if-else + 前置拦截
if (month < 1 || month > 12) {
    printf("月份错误\n");
} else {
    if (month == 2) {
      if ((year%4==0 && year%100!=0) || year%400==0)
            days = 29;
      else
            days = 28;
    } else if (month==4||month==6||month==9||month==11) {
        days = 30;
    } else {
        days = 31;
    }
    printf("%d年%d月有%d天\n", year, month, days);
}
方法一逻辑严谨，先用 if 拦截非法输入，再用 switch 利用穿透合并 7 个大月。结构清晰，拓展性最好。
方法二逻辑严谨，将非法数据挡在外面，使用 if-else 实现。

综合案例 2：计算 BMI（switch 巧妙用法）
double weight, height, bmi;
scanf("%lf %lf", &weight, &height);
bmi = weight / (height * height);

int z = 1 * (bmi < 18)
      + 2 * (18 <= bmi && bmi < 25)
      + 3 * (25 <= bmi && bmi < 27)
      + 4 * (bmi >= 27);

switch (z) {
    case 1: printf("Underweight.\n");  break;
    case 2: printf("Normal.\n");       break;
    case 3: printf("Overweight.\n");   break;
    case 4: printf("Obese.\n");        break;
}
为何这样写？ 因为 switch 不能直接判断区间（如 18 <= bmi < 25）。但关系表达式的结果是 0 或 1，乘以对应的数字后，就能把“区间判定”变成了“固定数值判定”。
启示如果遇到范围判断，首选还是用 if-else。这题用 switch 纯属“炫技”，真实工程中可读性不高。
综合案例 2：计算 BMI（switch vs if-else）
✅ 正常写法：if-else（处理区间）
double weight, height, bmi;
scanf("%lf %lf", &weight, &height);
bmi = weight / (height * height);

if (bmi < 18)
    printf("Underweight.\n");
else if (bmi < 25)
    printf("Normal.\n");
else if (bmi < 27)
    printf("Overweight.\n");
else
    printf("Obese.\n");
⚠️ 炫技写法：switch（强行构造整数）
double weight, height, bmi;
scanf("%lf %lf", &weight, &height);
bmi = weight / (height * height);

int z = 1 * (bmi < 18)
      + 2 * (18 <= bmi && bmi < 25)
      + 3 * (25 <= bmi && bmi < 27)
      + 4 * (bmi >= 27);

switch (z) {
    case 1: printf("Underweight.\n"); break;
    case 2: printf("Normal.\n");      break;
    case 3: printf("Overweight.\n");  break;
    case 4: printf("Obese.\n");       break;
}
对比分析
· if-else 法：天然支持区间判断，利用 else if 的顺序性，代码简洁、逻辑清晰。是实际工程中的绝对首选。
· switch 法：利用关系表达式结果为 0/1 的特性，通过乘法累加构造出整数 1~4。虽然语法上没错，但如果区间分得更细，这段表达式会变得极其灾难。
综合案例 3：简易四则运算计算器
int d1, d2, result, valid = 1;
char op;
scanf("%d %c %d", &d1, &op, &d2);

switch (op) {
    case '+': result = d1 + d2;  break;
    case '-': result = d1 - d2;  break;
    case '*': result = d1 * d2;  break;
    case '/': 
        if (d2 != 0) result = d1 / d2;
        else {
            printf("除数不能为0\n");
            valid = 0;
        }
        break;
    default:  printf("运算符无效\n");   valid = 0;
}

if (valid)
    printf("%d %c %d = %d\n", d1, op, d2, result);
知识点融合
① switch 支持字符：因为字符底层就是 ASCII 整数。
② 与 if 结合：在除法分支里，嵌套 if 防止除数为 0。
③ 状态标志位：用 valid 记录本次运算是否成功，只有成功时才输出结果。
运行示例 输入: 5 * 2 → 输出: 5 * 2 = 10
输入: 5 / 0 → 输出: 除数不能为0
switch 与 if-else 的对比

✅ 用 switch 更好

· 判断条件是等值判断（等于具体某个数字或字符）。
· 分支数量非常多（3 个以上）。
· 希望代码结构像菜单一样清晰。

⚠️ 用 if-else 更好

· 判断条件是范围（如 score >= 60）。
· 判断条件是浮点数或字符串。
· 逻辑是区间性质，而不是精准匹配。

核心原则精准匹配用 switch，区间判断用 if-else。
拓展与避坑：警惕非标准的范围写法
⚠️ 注意 如果在网上看到 case 'a' ... 'z': 这种写法，千万不要在考试、作业和正式工程中使用！
❌ GCC 扩展语法（不推荐）
// 仅部分编译器支持，不是标准 C
switch(c) {
    case 'a' ... 'z':
        printf("小写字母");
        break;
}
为什么不行？
① 非标准 C：C99/C11 等标准规定 case 后必须是单个常量。这是 GCC 的私有扩展，用 MSVC 等编译器会直接报错。
② 考试大坑：期末考试和考研 408 经常出选择题，问 case 后面能不能接范围？答案必须是“不能”。
✅ 标准写法 1：if-else（强烈推荐）
// 只要是范围判断，首选 if
if (c >= 'a' && c <= 'z') {
    printf("小写字母");
}
✅ 标准写法 2：穿透合并（仅限短范围）
// 如果是 abc 连续三个字母
switch(c) {
    case 'a': case 'b': case 'c':
        printf("在 a-c 之间");
        break;
}
铁律 switch 专门用于“精准匹配”，if-else 专门用于“范围判断”。
遇到范围判断（无论是数字区间还是字母区间），请老老实实切回 if-else，既标准又清晰。

错误类型错误代码示例原因与正确做法
表达式类型错误switch (3.14)switch 只能接受整型（char/short/int/enum）。
case 后面不是常量int n=1; case n:case 后面必须跟常量（字面量或宏），不能是变量。
漏写 breakcase 1: printf("A");会一直穿透执行下去，直到遇到 break。必须补上。
case 常量重复case 1: ... case 1: ...同一个 switch 里，case 的值不能相同，编译器会报错。
在 case 里定义变量case 1: int x = 5;容易引起作用域混乱。如需定义，请用大括号 { } 包起来。
