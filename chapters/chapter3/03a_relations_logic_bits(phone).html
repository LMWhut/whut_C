本讲内容

🔍 关系运算符

比较大小与相等：< <= > >= == !=，结果是 0/1。

🔗 逻辑运算符

! && || 组合条件，掌握短路求值。

🔧 位运算符

& | ^ ~ << >> 直接操作二进制位。

💡 典型应用

状态标志、掩码、置位/清位、奇偶、异或交换。

本讲学习目标
  • ① 关系运算会用 6 个关系运算符构造条件，理解结果恒为 0 或 1。
  • ② 逻辑运算理解 ! && || 的语义与真值表，掌握短路求值。
  • ③ 复杂条件用 && || 正确表达区间、字符范围、闰年等。
  • ④ 易错点区分 = 与 ==、避免连续不等式、慎用实数相等。
  • ⑤ 位运算理解 6 个位运算符的逐位规则。
  • ⑥ 应用会用位运算做置位/清位/测试与状态标志压缩。
为什么程序需要“选择”？
核心问题 程序能否像人一样，根据不同情况做出不同反应？比如：余额充足才支付、成绩≥60 才合格……这种“如果…就…否则…”的思维，就是选择结构。
本章基石 选择结构的本质是对条件的判断。
判定条件：真与假
条件表达式 用运算符把操作数连成的式子，作为运算数：非 0 即“真”、为 0 即“假”。
表示运算结果：真用 1 表示，假用 0 表示。

🧭 比喻

条件表达式像一道判断题：程序看答案是“是”(1) 还是“否”(0)，来决定走哪条路。

关键认知 早期 C 没有专门的布尔类型，用整数 1/0 充当真假，自 C99 起新增了布尔类型 _Bool。

C99 的布尔类型：
· _Bool 对象只能取 0 或 1；
· 头文件 <stdbool.h> 用宏提供别名 #define bool _Bool，true=1，false=0。
关系运算符一览（6 个）
运算符含义示例结果
<小于3 < 51
<=小于等于5 <= 51
>大于3 > 50
>=大于等于5 >= 31
==等于3 == 50
!=不等于3 != 51
要点 ① 结果只有 0（假）或 1（真）；
② 优先级低于算术运算；
③ == 是两个等号，别写成赋值 =。
关系运算符示例
int a=3, b=2, c=1, d, f;
d = a > b;        // 3>2 为真
f = a > b > c;   // 注意结合方向！
易错提醒
· a > b > c 不是数学的“a 大于 b 大于 c”！
· C 中从左到右算：先 (3>2)=1，再 (1 > 1) = 0。
· 要表达“a>b 且 b>c”必须用逻辑与：(a > b) && (b > c)。

非（!） !0 = 1，!非0 = 0；即“取反”。!1 = 0，!0 = 1。
逻辑运算符：组合条件
运算符名称含义示例结果
!逻辑非取反!01
&&逻辑与都真才真4 && 51
||逻辑或一真即真5 || 01
记忆口诀 · && 像“串联开关”：一个断全断；
· || 像“并联开关”：一个通全通；
· ! 像“反相器”：真变假、假变真。
逻辑运算符示例
int a = 4, b = 5;
printf("%d\n", !a);      // a真→取反
printf("%d\n", a && b);  // 都真
printf("%d\n", a || 0);  // 一真即真
printf("%d\n", !a || b);
0 　　　　// 4 是非 0，视为“真” 1 　　　　// a && b = 真 = 1 1 　　　　// a || 0 = 真 = 1 1 　　　　// !a || b = 真 = 1
逻辑短路求值（一）
什么是短路
&&：左边为假，右边不再计算（结果已定假）；
||：左边为真，右边不再计算（结果已定真）。 
int i = 0, j = 5;
// 安全：i==0 为假，j/i 这个危险除法不会执行！
if (i != 0 && j / i > 2) { ... }
生活例子
① 先问“你带伞了吗？”——没带，就不用再问“能不能借给我？”。
② if (年龄 >= 18 && 查看身份证) —— 年龄不够，就不用再查身份证了。
注意 短路虽然方便，但不要依赖它来“跳过”重要的操作；条件复杂时，写成清楚的 if 语句更好读。
逻辑短路求值（二）· 副作用
经典题执行下面的语句后 b 的值是多少？ 
int a=5, b=6, c=1, x=2, y=3, z=4;
c = (a = c < x) || (b = y > z);
逐步推
① 先算 (a = (c<x)) → (a = (1<2)) → a = 1，括号内为 1（真）；
② || 左边已真 → 短路，右边 (b=y>z) 不执行；
③ 故 b 仍为 6，c = 1。
用逻辑运算表达复杂条件
含义C 语言正确写法
x 在 [a,b] 内(a <= x) && (x <= b)
ch 是英文字母(ch>='A' && ch<='Z') || (ch>='a' && ch<='z')
典型例题：判断闰年 规则：能被 4 整除 且 不能被 100 整除，或 能被 400 整除。 
if ((year % 4 == 0 && year % 100 != 0) 
    || (year % 400 == 0)) {
    printf("是闰年\n");
}
铁律 数学里的连续不等式在 C 中必须拆开用 && 连接；任何“多个条件同时成立”用 &&，“任一成立”用 ||。
常见错误（一）：关系与逻辑
❌ 陷阱1：= 与 ==
if (x = 5) {…} // 这是赋值，值为 5（真），永远执行！
正确写法：if (x == 5) {…}
❌ 陷阱2：连续不等式
if (3 > 2 > 1) {…} // 算成 (3>2)=1, 1>1=0
正确写法：if (3 > 2 && 2 > 1){…}
❌ 陷阱3：实数直接判等
float f=0.1;
if (f == 0.1) {…} // 二进制无法精确表示 0.1，判断可能恒为假。
正确写法：if (fabs(f-0.1) <= 1e-8){…}
课堂练习 · 关系与逻辑
1. 设 int a=3,b=4; 表达式 (a<b) && (a+b>=7) 的值是？
参考答案：a<b 为 1；a+b=7，7>=7 为 1；1 && 1 = 1（真）。
2. 判断下面能否正确表达“x 是 0 到 100 之间的整数”： 0 <= x <= 100
参考答案：不能。应写为 (x >= 0) && (x <= 100)。
3. 若 a=1,b=2；执行 x = a>b && (b=5); 后 b 是多少？为什么？
参考答案：b 仍为 2。因为 a>b 为假，&& 短路，(b=5) 不执行。
为什么需要位运算？
核心问题 计算机底层只认识 0 和 1。C 贴近硬件，提供直接对二进制位(bit)操作的运算符，能高效完成普通算术难以表达的事。

🎯 典型场景

① 用位标志压缩存储多个布尔状态；
② 操作硬件寄存器/网络协议；
③ 加密、压缩、哈希的底层基石；
④ 用位移替代乘除法更快。

🔘 比喻

关系是“比较”，逻辑是“判断”，位运算是“逐位雕刻”——像一面有很多开关的面板，你能精确拨动任意一个。

复合赋值位运算符
与 += 同理&=、|=、^=、<<=、>>= 把运算结果写回左操作数。
int x = 0xA5;   // 二进制 1010 0101
x &= 0xF0;    // 保留高4位，低4位清0 (1010 0000)
x |= 0x0F;    // 低4位全置1 (1010 1111)
x <<= 2;     // 整体左移2位 (1011 1100)
典型应用：位的 置1 / 清0 / 翻转 / 测试
核心思路1 << k 是第 k 位的单点掩码。用它和 x 做位运算，精确操作第 k 位。
// ① 将第 k 位置 1
x |= (1 << k);

// ② 将第 k 位清 0
x &= ~(1 << k);

// ③ 翻转第 k 位
x ^= (1 << k);

// ④ 测试第 k 位是否为 1
if (x & (1 << k)) { /* 为 1 */ }

// ⑤ 判断 n 是否为奇数
if (n & 1) { /* 奇数 */ }
口诀或上它→置1；与上它的反→清0；异或它→翻转；与上它→测试。
典型应用：异或交换两个整数
核心思路利用异或的自反性 a ^ b ^ b → a（三次异或，让 a、b 互换）。
int a = 3, b = 5;
a = a ^ b;   // a = 3^5 = 6
b = a ^ b;   // b = 6^5 = 3
a = a ^ b;   // a = 6^3 = 5
注意当 a、b 指向同一变量时，a ^ a = 0 会清零。工程上更推荐用临时变量交换。
典型应用：用位运算压缩状态标志
核心思路一个 char 有 8 位，可以当作 8 个独立开关使用：每一位代表一个状态。
char flags = 0;   // 0000 0000
flags |= (1 << 0);   // 点亮灯：位0置1
if (flags & (1 << 1)) { ... } // 测试门
flags &= ~(1 << 2);   // 关闭窗：位2清0
价值一个字节即可存 8 个布尔状态，省内存、判断快。
常见错误（二）：位运算
❌ 陷阱1：位运算 vs 逻辑运算
把 &、^、| 写成 &&、||。结果类型不同（整数 vs 0/1），且位运算无短路。
❌ 陷阱2：移位越界
对 int 做 x << 40 → 结果未定义。
❌ 陷阱3：~ 与 !
~5 = -6（位取反）；!5 = 0（逻辑非）。两者完全不同。
❌ 陷阱4：对浮点位运算
float/double 不能做位运算 —— 编译报错。
课堂练习 · 位运算
1. 6 & 3、6 | 3、6 ^ 3 各是多少？
参考答案：6&3=2，6|3=7，6^3=5。
2. 把整数 x 的第 3 位（从 0 计）置 1，写出语句。
参考答案：x |= (1 << 3);
3. 5 << 2 等于多少？它在算术上等价于什么？
参考答案：5<<2 = 20，等价于 5 × 2² = 5 × 4。
本讲小结

关系运算

6 个运算符；结果 0/1；优先级低于算术。

逻辑运算

! && ||；真值表；短路求值。

复杂条件

区间/字符/闰年用 && || 拆写。

位运算 6 种

& | ^ ~ << >>；逐位演算、移位补位规则。

典型应用

置位/清位/测试、异或交换、状态标志压缩。
