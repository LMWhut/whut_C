Code::Blocks 安装配置指南

免费 · 开源 · 跨平台 · 内置 MinGW 编译器

一、软件简介

Code::Blocks 是一款免费、开源、跨平台的 C/C++ 集成开发环境（IDE），支持 Windows、macOS 和 Linux 三大操作系统。它内置 MinGW 编译器，安装后即可直接编写和运行 C 程序，是 C 语言初学者的理想工具。

本课程推荐场景 机房上课、快速上手。机房已预装，功能完整，调试方便。
系统要求 Windows 7 / 10 / 11，至少 500MB 磁盘空间。

二、下载

下载地址：访问 Code::Blocks 官网 http://www.codeblocks.org/，点击 Downloads。

关键操作

在下载页面选择 codeblocks-XX.XXmingw-setup.exe（带 mingw 的版本）。名称中带有 mingw 表示安装包已内置编译器，安装后可直接编译 C 程序。不要下载不带 mingw 的版本，否则需要单独安装编译器，配置复杂。

版本建议 截至 2026 年，推荐使用 Code::Blocks 20.03 或更高版本，内置 MinGW-w64 编译器。

三、安装步骤

1启动安装程序

双击下载的 .exe 文件，进入安装程序，点击 Next。

2同意许可协议

阅读许可协议后，点击 I Agree。

3选择组件

安装程序默认选择 Full（全部安装），直接点击 Next 即可。

4选择安装路径

选择安装位置。注意：路径中不要包含中文或空格，建议安装在 D:\CodeBlocks 或 C:\CodeBlocks 等简洁路径下。点击 Install 开始安装。

5等待安装完成

安装过程约 1–2 分钟，耐心等待。安装完成后点击 Next，再点击 Finish。

6验证安装

打开「开始 → 所有程序」，看到「CodeBlocks」文件夹即表示安装成功，桌面也会生成快捷方式图标。

四、首次启动与配置

1启动软件

双击桌面 CodeBlocks 图标启动软件。

首次启动时，如果弹出编译器自动检测对话框，点击 OK 即可。

2验证编译器

进入主界面后，进入 Settings → Compiler。确认「Selected compiler」为 GNU GCC Compiler。

如果未自动检测到，点击 Auto-detect 让软件自动查找。

汉化（可选）

  1. 下载 Code::Blocks 汉化包，解压后得到 locale 文件夹。
  2. 进入 Code::Blocks 安装目录，依次进入 share → CodeBlocks 文件夹，将 locale 文件夹复制到此处。
  3. 打开 Code::Blocks，选择 Settings → Environment。
  4. 选择 View 选项卡，勾选 Internationalization (needs restart)，在下拉框中选择 Chinese (Simplified)。
  5. 点击 OK，重启 Code::Blocks 即可。
截图建议：Environment 设置界面中 View 选项卡的勾选状态

五、中文乱码解决方案

如果程序输出中文显示为乱码，按以下步骤配置：

1设置编辑器编码

进入 Settings → Editor → Encoding settings，将编码设置为 UTF-8，点击确定。

截图建议：Editor Encoding settings 界面
2设置编译器编码选项

进入 Settings → Compiler，选择 GNU GCC Compiler，切换到 Other compiler options 标签页，在输入框中添加以下内容：

-finput-charset=UTF-8 -fexec-charset=GBK
截图建议：Other compiler options 标签页，红框标注输入的命令
3重新编译

点击 OK 保存，重新编译运行程序，中文即可正常显示。

六、编译运行与调试

  • 编译：按 Ctrl + F9 或点击菜单 Build → Build。
  • 运行：按 Ctrl + F10 或点击工具栏绿色三角形按钮。
  • 调试：在代码行号左侧单击设置断点（红色圆点），点击工具栏红色虫子图标 Debug（或按 F8）启动调试。

常用调试快捷键

单步跳过F7
继续F8
停止调试Shift + F8

七、常见问题排查

问题 原因 解决方案
启动时提示未找到编译器 安装包未包含 mingw 重新下载带 mingw 的版本
编译按钮灰色 未打开项目，只打开了单个文件 通过 File → New → Project 创建项目
中文乱码 编码设置不一致 按第五部分步骤配置
控制台闪退 程序运行完毕后窗口立即关闭 正常现象，可通过断点或添加 getch() 观察
断点无效 Debug 配置未创建 创建项目时勾选「Create Debug configuration」
