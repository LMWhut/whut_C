一句话 前五讲教你怎么控制循环，这一讲解决"数据从哪儿来、什么时候算完"。
案例引入：第二次输入被跳过
写法一读不到字符
int n;  char ch;
scanf("%d", &n);
ch = getchar();
printf("[%c]", ch);
输入：42⏎　输出：[ ]
方括号里不是空的：ch 拿到的就是那个回车 '\n'，printf 原样打了出来，右括号才掉到下一行。
写法二先清干净
int n;  char ch;
scanf("%d", &n);
while (getchar() != '\n') ;
ch = getchar();
printf("[%c]", ch);
输入：42⏎A　输出：[A]
多一行循环，才轮到用户真正敲的那个字符。
输入流与缓冲区：程序到底在读什么
1
敲键盘
字符先存进系统的
行缓冲区
2
按回车
整行才交给程序
末尾多一个 '\n'
3
程序取用
scanf 与 getchar
按各自规则取
4
剩下留着
没取走的字符
还在缓冲区里
关键 缓冲区是程序与键盘之间的一段内存。程序不是"敲一个拿一个"， 而是从这段内存里按需取；取不完，就留在那儿给下一次。
于是 "输入被跳过"不是键盘坏了，是上一轮留下的回车被当成了这一次的输入。
例 4-14：计数器控制，读 10 个字符
/* 读 10 个字符，输出 ASCII 码 */
#include <stdio.h>
int main()
{
    int c, n;
    for (n = 0; n < 10; ++n) {
        c = getchar();   // 读 1 个字符
        printf("%d ", c);  // 输出编码
    }
    return 0;
}
输入：Hi 3.14
     ab
输出：72 105 32 51 46 49 52 10 97 98
数一数这 10 个名额 分两行输入，每行末尾都有一个回车。H=72、i=105、空格=32、3=51、.=46、1=49、4=52、回车=10、a=97、b=98。
特点 循环次数由程序说了算，跟用户输什么无关——这就是"计数器控制"。 连回车都算一个字符，所以名额里常常混着 10。
例 4-15：用一个结束标志收工
/* 输入一行字符，输出字符个数 */
#include <stdio.h>
int main()
{
    int c, n = 0;
    c = getchar();        // 先读第一个
    while (c != '\n') {     // 回车就停
        ++n;
        c = getchar();    // 再读下一个
    }
    printf("%d characters!\n", n);
    return 0;
}
输入：Hello world⏎
输出：11 characters!
思路 循环次数事先不知道，于是约定一个"停"的暗号： 读到 '\n' 就认为这一行结束了。
两个 getchar 不能少 进循环前必须先读一次，否则变量 c 里是随机值， 循环条件一上来就是碰运气。
把它写短：读写合一的写法
原来读一次，写一次
int c, n = 0;
c = getchar();
while (c != '\n') {
    ++n;
    c = getchar();
}
改写读和判断合成一句
int c, n = 0;
while ((c = getchar()) != '\n')
    ++n;
为什么能这么写 赋值表达式 c = getchar() 本身也有值， 值就是刚赋进去的那个字符。所以这一句同时干了两件事：读一个字符，再拿它跟 '\n' 比。
括号不能丢 少写一次"再读一次"，就少一处"忘了写"的机会。但写成 while (c = getchar() != '\n') 是把比较结果赋给 c，意思全变了。
结束标志不止一个：EOF
  • 是什么stdio.h 里定义的宏，值是 −1，含义是"没有更多输入了"
  • 键盘怎么给Windows 按 Ctrl+Z 再回车；Linux / macOS 按 Ctrl+D
  • 与 '\n' 的分工'\n' 说"这一行完了"，EOF 说"输入到此为止"
  • 为什么需要用户要输几行，程序事先不知道，只能等一个"彻底没有"的信号
适用场合 处理一行用 '\n'；处理一直到输入结束的全部内容（多行、重定向的文件），用 EOF。
易错 终端里直接运行程序时，不按 Ctrl+Z / Ctrl+D 就永远等不到 EOF， 这也是很多人以为"程序卡住了"的原因。
EOF 的标准写法，以及 char 的坑
正确用 int 接返回值
int c;              /* 必须是 int */
while ((c = getchar()) != EOF)
    putchar(c);
getchar 返回的是 int：正常字符是 0～255， 特殊值 EOF 是 −1，用一个 int 就能区分开。
错误用 char 接
char c;
while ((c = getchar()) != EOF)
    putchar(c);
char 只有 8 位且带符号：读到字节 0xFF 时， 塞进 char 是 −1，提升成 int 也是 −1，与 EOF 撞车， 循环提前结束、后面的内容被吞掉。
换成 unsigned char 更糟： 它永远不等于 −1，循环停不下来。
scanf 的返回值：它其实会回答你
返回值含义举例
1成功读入并赋值的项数输入 42　读 %d → 返回 1
0第一项就格式对不上，什么都没读到输入 abc　读 %d → 返回 0
EOF还没读到数据，输入就结束了直接 Ctrl+Z 回车 → 返回 EOF
要点 返回值不是"成功与否"这种二值答案，而是读到了几项。 scanf("%d%d", &a, &b) 成功两数返回 2，只读到第一个返回 1。
对照 printf 返回的是输出了多少个字符，scanf 返回的是读到了多少项。一个是出，一个是进。
用返回值控制循环：读到读不动为止
/* 读一批整数，求和与个数 */
#include <stdio.h>
int main()
{
    int x, sum = 0, n = 0;
    while (scanf("%d", &x) == 1) {
        sum += x;
        ++n;
    }
    printf("n=%d sum=%d\n", n, sum);
    return 0;
}
输入：3 7 12⏎ Ctrl+Z⏎
输出：n=3 sum=22
循环条件在问什么 "刚才那一次读成功了吗？"成功就继续读，读不动就收工。
scanf 自带跳过 %d 会自己跳过空格、制表符、回车，所以数字可以分几行输， 也可以一行输几个。这一点 getchar 做不到——它一个字符都不跳。
格式串是模板，空格不是分隔符
scanf 的格式串输入结果（只改格式串，其余不动）
"%d%d"12 34⏎a=12　b=34，返回 2
"%d %d"12 34⏎一模一样，返回 2——那个空格是白写的
"%d,%d"12 34⏎a=12，b 没读到，返回 1
"%d,%d"12,34⏎a=12　b=34，返回 2——逗号必须在输入里真的出现
空白字符：跳过任意空白 空格、\n、\t 都只有一个意思——跳过零个或多个空白。%d 自己就会跳，2个%d之间的空格写不写都一样。
其他字符：必须真的出现 逗号、冒号、字母都是字面匹配：输入里没有，这一项就读不到，后面的跟着崩。题面说"用空格隔开"，就不该写逗号。
"空格是分隔符"说的是输入流；格式串只认三类东西——% 占位符、空白、字面字符。前两类跳过，后一类必须对上。
读实数：%lf，以及那个假成功
int    n;  scanf("%d",  &n);
float  f;  scanf("%f",  &f);
double x;  scanf("%lf", &x);  /* 要 l */
printf 不挑，scanf 挑 输出 double 用 %f 或 %lf 都行；读 double 必须 %lf。格式串得告诉 scanf 往那个地址里写几个字节。 
double x = 0;
scanf("%lf", &x);   /* 输入 12,34 */
scanf()返回 1 x = 12 缓冲区还剩 ",34"
逗号既不是数字也不是小数点，%lf 读到它就停下，把 12 交给x。返回 1 只说"我读到一项"，没说"这一行读干净了"。
下一轮 循环里接着读，还是从那个逗号开始，一样读不到。中文输入法打出的「12，34」，那个全角逗号卡在这儿的情况更常见。
混着用就出事：那个没被读走的回车
写法输入实际结果
scanf("%d", &n);
c = getchar();		42⏎ c 得到 '\n'，不是你以为的那个字符
scanf("%d", &n);
scanf("%c", &ch);		42⏎ ch 得到 '\n'，'%c' 不跳空白
scanf("%d", &n);
while (getchar() != '\n') ;		42⏎ 循环立刻结束（本来就是回车），清了个空
根子 %d 读到第一个不属于数字的字符就停下，那个字符不取走，原样留在缓冲区。 于是下一条读字符的语句，读到的就是它。
常见问题 实验课上"我明明输入了字符，程序却直接跳过去了"，十有八九就是这个回车。
清缓冲区：两种写法，一句别用
/* ① 读到回车为止 */
while (getchar() != '\n') ;

/* ② 让 scanf 自己跳空白 */
scanf(" %c", &ch);

/* 别用：网上到处都是 */
fflush(stdin);
① 最常用 读走直到回车为止的所有字符，回车也一并吃掉。
② 治本 格式串开头加一个空格，意思是"先跳过任意空白"。%c 是唯一要手动加的。
fflush 不是标准写法 C 标准只说它管输出流，对输入流用是未定义行为——微软在 MSVC 里实现成"清空缓冲区"，所以机房里能跑，换 gcc 不一定有用。
判断标准很简单：换一个编译器还对，才是语言给你的；不对，只是某个编译器给的。
两个更隐蔽的坑
坑一%c 连回车都吃
scanf("%c", &ch);   // 读到 '\n'
scanf(" %c", &ch);  // 读到真字符
规范写法是第二行 要读下一个可见字符，一律写 " %c"；确实想读空格本身，才写 "%c"。
坑二清缓冲区清成了死循环
while (getchar() != '\n') ;
/* 输入已结束 → 等不到 '\n' */
规范写法是下面这段 c 用 int，两个条件都判：读到回车停，读到 EOF 也停。 
int c;
while ((c = getchar()) != '\n'
       && c != EOF) ;
经验 凡是"一直读到某个字符为止"的循环，都要顺手防一下 EOF。
例 4-18：做一个能反复算的小计算器
要求 每读入一个格式正确的表达式，就输出结果；输一个非数字字符就退出。
Small Calculator
Enter any no-digit character to stop.
12.8*36.5
12.80*36.50=467.20
254+143.8
254.00+143.80=397.80
a
/* 退出 */
怎么知道该停了 靠 scanf("%f", &left) == 1： 用户输的是字母，第一个数就读不到，返回值不是 1，整个 while 收工。
三种意外 ① 运算符不是 + − * /　② 第二个数不是数字　③ 除数为 0
骨架 while (读得动) { 处理; 出错就清缓冲区再 continue; }
例 4-18 代码（上）：循环条件与容错
#include <stdio.h>
int main(void) {
  float left, right, r;  char op;
  printf("Small Calculator\n");
  printf("Enter any no-digit char to stop.\n");
  while (scanf("%f", &left) == 1) {   // 第一个数是数字才进来
    op = getchar();                       // 紧跟的运算符
    if ((op != '+' && op != '-' && op != '*' && op != '/')
        || scanf("%f", &right) != 1) {      // 运算符错或第二数错
      printf("Format incorrect.\n");
      while (getchar() != '\n') ;         // 清掉本行残留
三处要点 op = getchar() 取的是 %f 停下来的那个字符，就是运算符； || 有短路：op 不合法时右边的 scanf 不执行，right 压根没被赋值；出错后清缓冲区再 continue。
例 4-18 代码（下）：分派与输出
      continue;                          // 重新输入下一个式子
    }
    switch (op) {
    case '+': r = left + right; break;
    case '-': r = left - right; break;
    case '*': r = left * right; break;
    case '/':
      if (right != 0) r = left / right;
      else { printf("Error! divider is 0\n"); continue; }
    }
    printf("%.2f%c%.2f=%.2f\n", left, op, right, r);
  }
  return 0;                              // 在循环外，整个程序只返回一次
}
拿六组数据测一测
你输入屏幕上出现程序走了哪条路
12.8*36.512.80*36.50=467.20格式对，正常算
10/0Error! divider is 0除数为 0，不打结果
5%3Format incorrect.% 不是运算符，短路
3+abcFormat incorrect.运算符对，第二数读不到
10 + 3Format incorrect.多一个空格，op 是 ' '
a（程序结束）第一个数读不到，退出
把清缓冲那句删掉会怎样 输 5%3 会刷出两条 Format incorrect.——残留的 3 又被当成下一轮的开头。可紧接着输 7+2 照样算对，错得断断续续，最难查。
例 4-18 里三处最容易写坏的地方
① return 0 的位置 写进了 while 循环体里，算完第一个式子就返回。要放在循环之后，整个程序只返回一次。
② case '/' 的 break 少了 break，现在它恰好是最后一个分支才侥幸没出错；以后再加一个 case，就会静默地往下跑。每个 case 都要有出口。
③ 出错后没清掉这一行 错误字符留在缓冲区，同一条报错会连着刷两遍（上一页实测）。要清到回车为止再 continue，顺手判一下 EOF。
为什么拿它讲 ① 是一定会犯的硬错误，②③ 是今天不出事、改天出事的隐患。代码能跑，不等于写对了。
作业里的题：PTA 7-8「最佳情侣身高差」
最佳的情侣身高差遵循着一个公式：
（女方的身高）×1.09 =（男方的身高）。
输入格式：第一行给出正整数 N（≤10），为前来查询的用户数。随后 N 行，每行按照“性别 身高”的格式给出性别和身高，其中“F”表示女性、“M”表示男性；身高为区间 [1.0, 3.0] 之间的实数。
输出格式：对每一个查询，在一行中算出其情侣的最佳身高，保留小数点后 2 位。
分析：第一行是个数 N，不是数据；随后 N 行每行两项，中间只有一个空格；女 = 身高×1.09，男 = 身高÷1.09。
左边是输入样例、右边是输出样例。每行末尾都有一个看不见的回车，它也会被读走。
作业里的题：错在哪、怎么写
错在这%c 前面没空格
/* 'F' 女 / 'M' 男 */
int  n, i;
char gender;
double h;
scanf("%d", &n);
for (i = 0; i < n; i++)
    scanf("%c%lf", &gender, &h);
第一轮 gender 拿到的是上一行留下的 '\n'，身高跟着错位，后面全乱。
规范写法%c 前加一个空格
scanf(" %c%lf", &gender, &h);
%d 读完后，回车还留在缓冲区，%c 不跳空白、正好取到它。%lf 自己会跳，所以空格要加在 %c 前面。
样例第一行那个 2 是用 %d 读的，读完把回车留在了缓冲区；紧接着 %c 就来吃这口。
随堂检测
1回车去哪儿了
键盘上敲 42 再敲回车，程序依次执行这两行：
scanf("%d", &n);
ch = getchar();
此时 ch 的值是（单选）：
A. '2' B. '4' C. '\n' D. EOF
2scanf 返回几
键盘上敲 abc 再敲回车，程序执行这一行：
r = scanf("%d", &x);
此时 r 的值是（单选）：
A. 1 B. 0 C. -1 D. 不确定
3实数读歪了
r = scanf("%lf", &x);
敲 12,34 再回车，x 的值是（单选）：
A. x = 12.34 B. x = 12 C. x = 0 D. x 没被赋值
4加了清缓冲之后
scanf("%d", &n);
while (getchar() != '\n') ;
ch = getchar();
敲 42 回车、再敲 A 回车，ch 拿到的是（单选）：
A. '\n' B. 'A' C. '2' D. EOF
答案 1 · 回车去哪儿了
选 C。%d 读走 '4'、'2' 就停，后面那个回车（0x0A）一个字节也没动，还留在缓冲区；getchar 取的就是它。用 [%c] 打印，右括号会掉到下一行。
答案 2 · scanf 返回几
选 B。'a' 一个数字也对不上，返回值是 0，而且它原地没动、还在缓冲区，下一次读到的还是它——不清掉就一直读同一个字符。== 1 为假，循环一次也进不去。
答案 3 · 实数读歪了
选 B：x = 12，r = 1。%lf 读完 12 遇到逗号就停——逗号不是数字、不是小数点，也不是可跳过的空白。缓冲区还剩 ,34，下一轮从这里接着读。
答案 4 · 加了清缓冲之后
选 B：'A'。while 一个字符一个字符取，取到回车为止，正好把 %d 留下的那个回车吃掉，ch 才等到你敲的 A。和第 1 题比：不加这一行，ch 拿到的是 '\n'。
本讲小结
  • ① 输入是流键盘敲的东西先进缓冲区，程序按需取，取不完留着
  • ② 四种停法计数器、'\n' 结束标志、EOF、scanf 返回值
  • ③ 整型后读字符%c 前加一个空格，或先 while 清到回车为止
  • ④ 骨架固定while (读得动) { 处理；出错清缓冲区再 continue； }
  • ⑤ 格式串是模板除了 % 占位符，其余字符都得在输入里对上
记住这一条 程序读到的，永远是你上一次留下的东西——输入问题查不出来的时候， 先怀疑缓冲区里还有残渣，而不是怀疑键盘。
