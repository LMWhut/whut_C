break 与 continue

第 4 章（四）循环结构 · 中途怎么改主意
主讲：李　民
本讲内容

⏹️break：结束整个循环

后面的轮次全部不做了

⏭️continue：跳过这一轮

本轮剩下的语句不做了，下一轮照常

⚖️两者的区别

列成一张表，逐条对照

🕳️最大的坑

while 里的 continue 会死循环

🔢跳出后 i 是几

三种结束方式，答案不一样

🎯例题：判断素数

试到 √m 就够，跳出后看 i 停在哪儿

本讲学习目标
  • ① 会辨给一段代码，说清它执行几次、输出什么
  • ② 会用"找到就停"用 break，"不合格就跳过"用 continue
  • ③ 会防知道 while 里用 continue 为什么会卡死
  • ④ 会算循环结束后 i 是几，分三种结束方式各答一遍
  • ⑤ 会读跳出之后，从 i 的值看出是"找到"还是"试完"
案例引入：判断一个数 m 是不是素数
没有 break　若 m 的值为91， 从 2 试到 90，i = 7 时已经除得尽，剩下 83 轮照样跑
int m = 91, i, flag = 1;
for (i = 2; i < m; i++)
    if (m % i == 0)
        flag = 0;
printf("%d", flag);   // 0：不是素数
加了 break除得尽就跳出，i 停在 7，后面的 8~90 都不试
int m = 91, i, flag = 1;
for (i = 2; i < m; i++)
    if (m % i == 0) { flag = 0; break; }
printf("%d", flag);   // 0：不是素数
区别 除了 break 这一个词，两段代码完全一样。除得尽的那一刻结论已经定了，后面的循环只是在重复同一件事。
break：立刻结束整个循环
while (条件) {
    语句1;
    if (出口条件)
        break;   // 立即跳出
    语句2;      // 本轮不再执行
}
语句3;          // 从这里接着走
作用 放弃剩下的所有轮次，直接跳到循环后面那条语句——语句3。
注意 语句2 也不会执行——不只是退出循环，本轮剩余部分也一并跳过。
两种结束方式 条件为假是正常出口，break 是提前出口。两者都让循环结束，但停的位置不同。
例一：从1开始求加，到和超过 1000为止
int i = 1, s = 0;
while (1) {
    s += i;
    if (s > 1000) break;
    i++;
}
printf("%d %d", i, s);
45 1035
为什么用 while (1) 说不清要转几圈，只知道转到超过 1000 为止。次数不定就用 while，出口写在循环体里。
算一遍 1+2+…+44 = 990，再加 45 得 1035，超过才停。所以 i = 45。
i++ 为什么放在最后 跳出时 i 不再加 1，输出 45；要是挪到 if 语句前面，同样的和对应的就是 i = 46。
例二：输入一批成绩，遇到负数就结束
int x, s = 0, n = 0;
while (1) {
    scanf("%d", &x);
    if (x < 0) break;
    s += x;
    n++;
}
printf("%.2f", (double)s / n);
90 85 78 -1 → 84.33
哨兵值 用一个正常数据里不会出现的值（这里负数）当“到此为止”的信号，这个值叫哨兵。
这题只能用 break 读到哨兵之前，不知道要读几个数，条件写不进括号里。
同类场景 读到文件末尾、读到 0 结束。
continue：这一轮到此为止
int s = 0, n = 0, x;
for (int i = 0; i < 10; i++) {
    scanf("%d", &x);
    if (x < 60) continue;   // 不及格
    s += x;
    n++;
}
printf("%d %.1f", n, (double)s / n);
作用 跳过循环体的剩余部分，本轮结束，直接进入下一轮。
和 break 比 break 结束整个循环，continue 只结束这一轮。
不用它也行 写成 if (x >= 60) { s += x; n++; } 结果一样。但后面要处理的语句一多，这层缩进就碍事了。
循环次数不变 十个成绩照样读了十个。continue 只决定这一轮做什么，不改变循环走几圈。
最大的坑：while 里的 continue
int i = 1, s = 0;
while (i <= 10) {
    if (i % 2 == 0)
        continue;   // 回到条件判断
    s += i;
    i++;            // 永远轮不到
}
i 停在 2，条件永远成立，屏幕上一个字符也不输出。
红色这条路不经过 i++，上去直接判条件
for 里为什么不会 continue 在 for 里跳到表达式3（i++），在 while 里跳到条件判断。差的就是 i++ 这一步。
用 break 还是 continue：三个判据
1整件事都不做了吗
是 → break。哨兵出现、找到即停、文件读完，都是这一种。
2只是这条数据不要吗
是 → 再看第 3 条；不是 → 两个都不用，循环照常走。
3跳过后还剩多少活
只剩一两句 → 用 if 反向包住；剩一长串 → 用 continue。
活少 反过来写成 if (x >= 0) { s += x; n++; }
活多 后面还有一长串，continue 省掉一层缩进 
if (x < 0) continue;
s += x;
n++;
/* 后面还有一串 */
用不上就别用 本来一个 if 就写清的事，拆成 continue 再往回绕，只是给读的人多加一层。
同一段循环，换一个词
break输出 12
for (i = 1; i <= 5; i++) {
    if (i == 3) break;
    printf("%d", i);
}
12
continue输出 1245
for (i = 1; i <= 5; i++) {
    if (i == 3) continue;
    printf("%d", i);
}
1245
差别在哪 break 让 i = 3 之后的轮次全部消失；continue 只让 i = 3 这一轮消失。
switch 里的 break 只跳 switch
for (int i = 0; i < 3; i++) {
    switch (i) {
    case 1: break;      // 只跳 switch
    case 2: printf("*");
    }
    printf("%d", i);
}
01*2
容易错的地方 很多人以为这个 break 能跳出循环，其实它只跳出了 switch。
逐个看
i=0：没有匹配的 case，输出 0
i=1：break 跳 switch，接着输出 1
i=2：case 2 打一个 *，再输出 2
跳出范围 break 只跳出包着它的那对 {}：在 switch 里跳 switch，在循环里跳循环。
循环结束后，i 是几
结束方式i 的值为什么
条件为假（正常）6最后那轮 i++ 照样做了
break（i==3 时）3跳出时不执行 i++
continue6不影响终值，只是少做事
为什么 break 是当场跳出，表达式3 还没轮到；正常结束是判断没过才走，表达式3 已经做完了。
推一遍 for (i = 1; i <= 5; i++) if (i == 3) break;　结束后 i 是 3，不是 6。
例题：判断素数，试到几就够
什么叫素数 大于 1，且只能被 1 和它自己整除的整数。1 不算素数，2 是最小的那个。
怎么判 拿 2、3、4……挨个去除。有一个除得尽，它就不是素数；全都除不尽，才是。 
// m = 97 时，最老实的办法
97 % 2  → 1
97 % 3  → 1
    …
97 % 96 → 1    // 试完 95 次才敢下结论
为什么试到 √m 就够 m 若能写成 a × b（a ≤ b），则 a ≤ √m。大于 √m 的因子，一定有个小于 √m 的跟它配对，试了也没有新结果。
m试到 m-1试到 √m省了
9795 次8 次约 12 倍
1000998 次30 次约 33 倍
1000710005 次99 次约 101 倍
还能再省一步 除得尽就不用往下试了。用 break，后面的轮次一个都不执行。
例题：判断素数的完整程序
int m = 91, i;
for (i = 2; i * i <= m; i++)
    if (m % i == 0) break;   // 找到因子，停
if (i * i > m) puts("是素数");
else printf("不是素数");
91 = 7 * 13
走完却没被 break，说明 i·i 越过了 m——那才是素数。

准备：m = 91，i 从 2 开始；每轮先看 i·i 是否还 ≤ m。

①靠 i 的位置

break 出来的 i·i ≤ m，走完的 i·i > m

②靠标志变量

跳出后还要用 i 的原值，就靠它

③抽成函数

return 0/1；要整个程序一起停，用 exit(0)

随堂检测：两题，动笔推一遍

第 1 题s 等于多少？

int s = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2) continue;
    s += i;
}

答案：s = 30

第 2 题i 最后是几？

int i;
for (i = 1; i <= 10; i++)
    if (i * i > 50) break;

答案：i = 8

两题的关键 第 1 题 i % 2 为真表示奇数，奇数被跳过，累加的是偶数 2+4+6+8+10；第 2 题 8²=64 才超过 50，7²=49 还没超。
本讲小结
遇到的情形写法为什么
次数已知，中途可能提前结束for + break先给上限，命中就跳出
一批数据里找第一个找到就 break循环后靠 i 判断找没找到
某几项不参与计算continue本轮跳过，剩下的照做
  • 跳出后马上用 i是命中处还是越界值，差一。
  • 在 while 里用 continue先看 i++ 有没有被跳过，漏掉就是死循环。
  • 在循环里套 switchbreak 只跳 switch，循环照转。
