循环的嵌套

第 4 章（五）循环结构 · 一层不够就套两层
主讲：李　民
本讲内容

🪆嵌套是怎么回事

外层跑一圈，内层跑一整圈

🧭执行轨迹

把 i 和 j 的每一轮取值摊开看

📐图形与表格

三角形、金字塔、乘法表

🔍嵌套 + 前面学的

素数表、三层枚举、水仙花

⚠️三个坑

同名变量、忘了重置、只跳一层

⏱️效率意识

三层为什么慢，怎么压成两层

本讲学习目标
  • ① 会读说清内层跑了多少圈、总共执行多少次
  • ② 会画行、列、空格三种循环各管什么，能对上号
  • ③ 会写三角形、乘法表能独立默写出来
  • ④ 会算总次数 = 各层次数相乘，能估出量级
  • ⑤ 会避内外层同名、内层变量没重置，这两坑不踩
案例引入：打印 5 行 5 列的星号
✓ 一层就够每行都长一样
for (i = 1; i <= 5; i++)
    printf("*****\n");
***** ***** ***** ***** *****
✗ 一层不够每行的 * 个数不一样
* ** *** **** *****
printf 里那个字符串是写死的——第 i 行要打 i 个 * ，只有一层循环写不出来。
分界 分行不是难点。真正的分界是：一行的内容要不要跟着行号变——要变，就得用两层。
嵌套：外层走一步，内层走一整圈
for (i = 1; i <= 3; i++) {   // 外层
    for (j = 1; j <= 2; j++) { // 内层
        printf("(%d,%d)", i, j);
    }
    printf("\n");
}
(1,1)(1,2) (2,1)(2,2) (3,1)(3,2)

第几次1
i = 1 进外层，j 从 1 开始：先输出 (1,1)。
时针与分针 外层走一格，内层转一整圈；内层每轮都从初值重新开始，不是接着上一轮往下跑。总共 3 × 2 = 6 次，不是 3 + 2。
写嵌套的三条规矩
  • ① 变量别重名外层用 i，内层用 j，再深用 k
  • ② 逐层缩进内层比外层多缩一级，嵌套关系一眼看得出
  • ③ 内层变量要复位for 自动做；while 得自己写 j = 1;
为什么必须分开 内外层共用一个变量，内层会把外层正在使用的值冲掉——外层就乱了套。下一节有实例。
缩进的用处 排版不是好看而已：看缩进就知道谁包着谁，出问题时能立刻定位是哪一层的错。
图形一：直角三角形，内层上界跟着外层走
for (i = 1; i <= 5; i++) {
    for (j = 1; j <= i; j++)
        printf("*");
    printf("\n");
}
* ** *** **** *****
唯一的变化 内层的上界从固定的 5 换成了 i——第几行就打几个。
输出格式 星号之间没有空格，行末也没有。每行就是 i 个 *，紧接着一个换行符。
图形二：金字塔，一行要两个内层循环
for (i = 1; i <= 5; i++) {
    for (j = 1; j <= 5-i; j++)
        printf(" ");   // 空格
    for (j = 1; j <= 2*i-1; j++)
        printf("*");   // 星号
    printf("\n");
}
* *** ***** ******* *********
只有行首有空格（i=1时，* 前有 4 个空格），星号之间、行末都没有。
两个内层的分工 前一个循环输出前导空格（5−i 个），后一个循环输出星号（2i−1 个）；它们是并列关系，不是嵌套，两个循环变量可以重名，都是 j 。
图形三：九九乘法表，行数就是列数上限
for (i = 1; i <= 9; i++) {
    for (j = 1; j <= i; j++)
        printf("%d*%d=%d ", i, j, i*j);
    printf("\n");
}
1*1=1 1*2=2 2*2=4 1*3=3 2*3=6 3*3=9 …
和第 7 页一个套路 内层上界还是 i，只是把星号换成了算式——图形题的骨架都一样。
输出格式 每个算式后面都跟一个空格，行末那个也算——格式串里带了空格，打完才换行。
对齐小技巧 想让各列整齐，用 %-3d 这类定宽格式，别靠手打空格。
嵌套 + break：列出 2~100 的所有素数
int m, i;            // 声明在循环外
for (m = 2; m <= 100; m++) {
    for (i = 2; i * i <= m; i++)
        if (m % i == 0) break;
    if (i * i > m) printf("%d ", m);
}
2 3 5 7 11 13 17 … 97
两层各干什么 外层挨个拿数，内层判断这个数是否是素数。找到了就 break，换下一个数再试。
break 的位置 它只跳出内层，跳完接着走 if (i*i > m)——正好用内层留下的 i 判断结果。
别在内层 for 里定义 i 　　写成 for (int i = 2; ...)，i 出了这个 for 就不能使用了，下面那句 if (i*i > m) 直接编译报错。如果跳出之后还要用的变量，必须在循环前面定义。
三层嵌套：用 1、2、3 组三位数，各位不重复
for (a = 1; a <= 3; a++)
  for (b = 1; b <= 3; b++)
    for (c = 1; c <= 3; c++)
      if (a != b && b != c && a != c)
        printf("%d%d%d ", a, b, c);
123 132 213 231 312 321
三层怎么读 百位 a 固定一个，十位 b 转一圈，个位 c 再转一圈——像三个套在一起的转盘。
试了多少次 3×3×3 = 27 次，其中只有 6 个合格——枚举就是先全试一遍，再筛。
层数一多就不一样了 三层 3³ = 27 次还轻松，五层就是 243 次、八层 6561 次——暴力枚举的天花板就是这么来的。能剪的枝要在浅层剪掉。
内层上界写 i 还是写 n
写法（n = 5）每行打几个 *总次数
j = 1; j <= n5 5 5 5 525
j = 1; j <= i1 2 3 4 515
公式 前者 n²，后者 n(n+1)/2。n 越大差得越多：n=100 时是 10000 对 5050。
别忘了 内层少转一圈，外层照旧——省的是内层，不是行数。
顺带一提 图形题里写 j <= i 不只是为了图形对，也顺手省掉一半空转。
能不能少一层：1! + 2! + … + n!
双层每轮从头算 k!
s = 0;
for (k = 1; k <= n; k++) {
    t = 1;                 /* 每轮重来 */
    for (i = 1; i <= k; i++)
        t = t * i;
    s = s + t;
}
单层接着上一轮往下乘
s = 0; t = 1;      /* 只初始化一次 */
for (i = 1; i <= n; i++) {
    t = t * i;     /* 用的是 (i-1)! */
    s = s + t;
}
单层循环为什么能省 　　k! = (k−1)! × k：双层循环实现中，上一轮刚算出来，下一轮又重头算。内层要算的，外层手里本来就有。n = 5 时两边都 153，乘法 15 次 → 5 次。
再试一题：1 + (1+2) + … + (1+…+n)
双层每轮重算前缀和
s = 0;
for (i = 1; i <= n; i++) {
    p = 0;                 /* 每轮重来 */
    for (j = 1; j <= i; j++)
        p += j;
    s += p;
}
单层p 自己会往前滚
p = 0; s = 0;
for (i = 1; i <= n; i++) {
    p = p + i;    /* 接着上一轮的 p */
    s = s + p;
}
认准这个 p p 是到第 i 项为止的前缀和：p_i = p_(i−1) + i。n = 7 时 s = 84，加法 35 次 → 14 次（双层 28+7，单层 7+7）。
百钱百鸡（一）：理解题意列方程
题目 鸡翁一，钱值五；鸡母一，钱值三；鸡雏三，钱值一。问何以百钱买百鸡？
条件与上界 设 x 只公鸡、y 只母鸡、z 只小鸡：x + y + z = 100，5x + 3y + z/3 = 100。
由此定上界：x ≤ 100÷5 = 20，y ≤ 100÷3 = 33，z ≤ 100——不是随便写的。 
for (x = 0; x <= 20; x++)
  for (y = 0; y <= 33; y++)
    for (z = 0; z <= 100; z += 3)
      if (x + y + z == 100
          && 15*x + 9*y + z == 300)
        printf("%d %d %d\n", x, y, z);
0 25 75 4 18 78 8 11 81 12 4 84
乘 3 的两个好处 ① 同乘 3，z/3 的截断没了；② z = 300 − 15x − 9y，只能是 3 的倍数——让 z 每次加 3 就够，最内层 101 次压到 34 次，全式 21×34×34 = 24 276 次。
百钱百鸡（二）：从三层压到一层
两层 z = 100 - x - y：只数一满 z 就定了，不用再试一轮 
for (x = 0; x <= 20; x++)
  for (y = 0; y <= 33; y++) {
    z = 100 - x - y;
    if (15*x + 9*y + z == 300)
      printf("%d %d %d\n", x, y, z);
  }
一层 两式相减消掉 z：14x + 8y = 200，约成 7x + 4y = 100，固定 x 就解出 y 
for (x = 0; 7*x <= 100; x++)
  if ((100 - 7*x) % 4 == 0) {
    y = (100 - 7*x) / 4;
    z = 100 - x - y;
    printf("%d %d %d\n", x, y, z);
  }
三次对比 三层（z 每次加 3）24 276 次 → 两层 714 次 → 一层 15 次，不加步长则是 72 114 次。z 由只数条件算出、y 由钱数条件解出，每消掉一个未知量就少一层枚举；一层版先判 % 4 == 0 再除，与上一页乘 3 是同一招。
陷阱一：内外层用了同一个变量
✗ 两层都用 i只出一行
for (i = 1; i <= 3; i++) {
    for (i = 1; i <= 3; i++)
        printf("(%d)", i);
    printf("|\n");
}
(1)(2)(3)|
✓ 外层 i、内层 j三行
for (i = 1; i <= 3; i++) {
    for (j = 1; j <= 3; j++)
        printf("(%d,%d)", i, j);
    printf("|\n");
}
(1,1)(1,2)(1,3)| (2,1)(2,2)(2,3)| (3,1)(3,2)(3,3)|
为什么只出一行 内层把 i 推到 4，回外层再 i++ 变 5，条件立刻为假——外层只跑了一轮。
陷阱二：while 实现时内层变量忘了复位
✗ 少了 j = 1只打第一行
int i = 1, j = 1;
while (i <= 3) {
    while (j <= 3) { printf("*"); j++; }
    printf("\n"); i++;
}
*** （下接两行空行）
✓ 每轮开头复位三行
int i = 1, j;
while (i <= 3) {
    j = 1;        // 一定要复位
    while (j <= 3) { printf("*"); j++; }
    printf("\n"); i++;
}
*** *** ***
for 为什么不会忘 内层 for 每轮重进都重跑表达式1；while 得自己补初值。
陷阱三：break 只跳一层，想跳两层得另想办法
✗ 只有 break找到还在继续找
for (i = 1; i <= 3; i++)
    for (j = 1; j <= 3; j++)
        if (i * j == 6) {
            printf("(%d,%d) ", i, j);
            break;        /* 只跳内层 */
        }
(2,3) (3,2)
✓ break + 标志变量只报第一个
found = 0;
for (i = 1; i <= 3 && !found; i++)
    for (j = 1; j <= 3; j++)
        if (i * j == 6) {
            printf("(%d,%d) ", i, j);
            found = 1; break;
        }
(2,3)
两条出口 左边跳出内层，外层照转，3×2 又找到一次；右边用 found 让外层条件变假。
为什么三层嵌套一下就慢了
嵌套层数n = 100 时次数本机耗时
一层100不到 1 微秒
两层10 000约 0.03 毫秒
三层1 000 0003~4 毫秒
四层100 000 0000.34 秒
数哪一句 数最内层那条语句跑了几次，不是数代码行数。行数不随规模变，次数才变。
怎么比快慢 n 从 100 加到 200：一层 2 倍、两层 4 倍、三层 8 倍。三层实测 3 毫秒 → 30 毫秒。次数翻几倍，时间就翻几倍。
每多套一层，次数就乘一个 n。空循环体本机实测：1 亿次 0.34 秒，折算一次 3.4 纳秒。所以能算掉一层就算掉。
水仙花数（一）：从判断一个，到求全部
第一步判断一个三位数
scanf("%d", &m);
x = m % 10;            /* 个位 */
y = m / 10 % 10;       /* 十位 */
z = m / 100;            /* 百位 */
if (x*x*x + y*y*y + z*z*z == m)

第二步外面套一层枚举
for (m = 100; m < 1000; m++) {
    x = m % 10;
    y = m / 10 % 10;
    z = m / 100;
    if (x*x*x + y*y*y + z*z*z == m)
        printf("%d\n", m);
}
这一步是通用套路 求"所有成立的数"：把判断原样搬进循环体，外面套一层枚举。

写法一枚举数，再拆位
for (m = 100; m < 1000; m++) {
    x = m % 10;

for (a = 1; a <= 9; a++)
  for (b = 0; b <= 9; b++)
    for (c = 0; c <= 9; c++) {

都是 900 次 三层那版天生就有 a、b、c，不用拆位；代价是位数一变，层数就得跟着变。
课后挑战：这两题不给代码

①不变初心数

一个数乘 2、3、…、9，各乘积的各位数字之和都相等，这个和就叫它的"初心"。给定一批数，判断有没有不变的初心，有则输出初心，否则输出 NO。

例：18 → 36 和 9、54 和 9、…、162 和 9，初心是 9。

提示 外层枚举乘数 2~9，内层 while 求各位和；一旦不等就置标志、break。

②连续因子

求 N 的最长连续因子序列：几个连续整数（≥2）相乘能整除 N。输出最长长度，以及起始最小的那组。

例：630 → 5×6×7 = 210 能整除 630，长度 3。

提示 外层枚举起点 i 到 √N，内层连续乘；用 maxLen、start 两个变量记住最优解。
它们考什么 不是语法，是能不能自己把嵌套拆对：哪一层枚举、哪一层累加、什么时候该提前退出。
拿到一段嵌套，按这五步读
  • ① 外层跑几次看它的初值、上界、步长
  • ② 内层每轮几圈上界是不是引用了外层变量
  • ③ 总次数各层次数相乘，不是相加
  • ④ 内层变量从几开始每进一次内层，就按初值重新开始，不接着上一轮的末值
  • ⑤ break 在哪一层它只管自己那一层
最省事的办法 拿张纸，把外层每一轮的 i 写成一行，右边标出内层跑了几次——画两三轮，规律自己就出来了。
随堂检测：两题，动笔推一遍

第 1 题s 等于多少？

int s = 0;
for (i = 1; i <= 3; i++)
    for (j = 1; j <= i; j++)
        s += j;

答案：s = 10

第 2 题打印几行几个*？

for (i = 1; i <= 3; i++) {
    for (j = i; j <= 3; j++)
        printf("*");
    printf("\n");
}

答案：3 行，每行分别是3个、2个、1 个

考点 第 1 题逐轮算：1 + (1+2) + (1+2+3) = 10；第 2 题内层起点跟着 i 走，得到倒三角。
本讲小结：五条铁律
  • ① 一句话外层走一步，内层走一整圈——内层是外层循环体的一部分，不是并列关系。
  • ② 次数相乘总次数是 m × n，不是 m + n。三层就再乘一层。
  • ③ 上界跟着外层内层上界写成 i，三角形、九九表一次就通；写死 n 就是满屏方块。
  • ④ 别同名、要复位内外层用 i/j/k 分开；while 实现时内层变量每轮开头必须重新赋值。
  • ⑤ 能少一层就少一层阶乘和、前缀和靠复用中间量，百钱百鸡靠方程消元：能算出来的变量，不必再枚举。
