三种循环各在什么场合上场

一条主线全篇只回答一个问题：判断放在门口，还是放在出口？位置一挪，行为就全变了。
本讲学习目标
  • ① 会写四要素，写完别忘结尾分号
  • ② 会读说清"先执行、后判断"的先后
  • ③ 会辨初值取 101 时，能算出两种结果并解释
  • ④ 会用输入校验、菜单、位数统计能独立写出
  • ⑤ 会选判断该用 while 还是 do-while
怎么算学会了给一段 do-while，能手推出每一轮的变量值，还能说清"它为什么比 while 多执行一次"。
案例引入：猜数字
int n = 37, g;
printf("猜 1~100：");
scanf("%d", &g);
while (g != n) {
    printf(g < n ? "小了："
                  : "大了：");
    scanf("%d", &g);
}
printf("猜对了！\n");
轮输入 gg != 37屏幕上
150真大了：
225真小了：
337假猜对了！
有点啰嗦scanf 写了两遍：循环前一次、循环里一次——同一句话说了两遍。
前提总得让人先猜一次。
想一想n 若由随机数生成，要猜几次事先算不出来，循环次数不确定。
同样的功能，do-while 少写一遍
while 版：输入写两遍
scanf("%d", &n);        // 第一遍
while (n < 1 || n > 100) {
    printf("重输：");
    scanf("%d", &n);    // 第二遍
}
do-while 版：只写一遍
do {
    printf("输入 1~100：");
    scanf("%d", &n);
} while (n < 1 || n > 100);
一句话它把"先做一次"和"不够再来一次"写成了同一份代码——这就是它存在的全部理由。
代价它替你省掉一遍输入，也顺手把"至少做一次"写死了——不需要先做一次时，别用它。
语法与执行流程：先斩后奏
格式
do {
    语句;                /* 先执行 */
} while (条件表达式);    /* 后判断 */
示例：统计位数
int n = 2026, c = 0;
do {
    c++;              // 先记一位
    n /= 10;           // 再砍一位
} while (n > 0);      // 后判断
执行流程
① 先执行一遍：不看条件
② 再算条件：做完才问
③ 真则回头，假则退出
四要素没多没少，只搬了一个家
要素while 里do-while 里
初值循环之前循环之前（不变）
判断条件循环入口循环出口
循环体{ } 内do 与 while 之间
推进循环体里循环体里（不变）
注意初值和推进还在老地方，只搬了"判断"。
记住判断在出口，意味着它至少被执行过一次。
一次反例：初值取 101，两者的不同
问题求 1 到 100 之和，代码几乎一字不差，只把初值改成 101。
while 先判断
int i = 101, s = 0;
while (i <= 100) {
    s += i;
    i++;
}
s = 0　一次没进
do-while 后判断
int i = 101, s = 0;
do {
    s += i;
    i++;
} while (i <= 100);
s = 101　硬做一次
为什么判断在门口，条件不成立一次都不进；判断在出口，人已经进去了。
手工跟踪：i 从 5 开始，每轮减 2
int i = 5;
do {
    i -= 2;
    printf("%d ", i);
} while (i > 0);
输出结果： 3 1 -1
轮进入 i 值减 2 后 i 值i > 0
153真
231真
31−1假
易错循环体执行了 3 次。很多人答"2 次"，因为漏掉最后那轮——做完了才发现该停。
若i的初值是0这一问题用 while 与 do-while 循环输出结果相同，因为 5 > 0 一开始就成立。而当 i = 0：while 一次不做、什么都不输出；do-while 仍做一轮，输出 -2。
当型与直到型：一张表看清
比较项while（当型）do-while（直到型）
判断位置循环入口循环出口
最少执行0 次1 次
条件一开始为假直接跳过做完一遍才退出
适合场景可能一次都不做至少要做一次
最常见的错忘记推进丢了结尾分号
一句话while 可以是 0 次，do-while 至少 1 次。这句话不是用来背的，上面那个 101 的反例才是证据。
陷阱一：结尾那个分号，丢不得

✓ 正确：括号后跟分号

do {
    s += i;
    i++;
} while (i <= 100);  // 有分号

✗ 错误：少了分号

do {
    s += i;
    i++;
} while (i <= 100)   // 没有
编译错误： expected ';' before '}'
为什么整个 do … while(…); 是一条完整语句，语句就得用分号收尾。这是它独有的要求。
看报错的技巧编译器常把错误指在下一行。别急着改下一行，先回头看上一行结尾。
陷阱二：括号里要写"继续"，不是"停止"
人的想法"一直问，直到输入合法为止。"
✗ 直译while (n >= 1 && n <= 100); —— 合法就继续，反了。
✓ 正确while (n < 1 || n > 100); —— 不合法就再来一轮。
要点条件为真时继续循环。
换个问法先想"什么情况下还要再来一次"，再落笔写条件——比背语法管用。
你想说的那句话do-while 括号里表达式
直到输入落在 1~100n < 1 || n > 100
直到猜中g != n
直到除尽（余数为 0）r != 0
场景一：输入不合法，就一直问下去
int n;
do {
  printf("输入 1~100：");
  if (scanf("%d", &n) != 1) {
    while (getchar() != '\n') ;
    n = 0;
  }
} while (n < 1 || n > 100);
printf("%d\n", n);
要点scanf 返回成功读入的项数。敲了字母它返回 0，n 还是旧值。
别漏不清缓冲区，那个坏字符还在，下一秒又读到它——死循环。
为什么必须 do-while不问一次，拿什么判断合不合法？
三种坏输入字母（返回 0）清缓冲区重来；999（返回 1 但越界）交给条件送回；50abc 只读走 50，'abc' 留在缓冲区坑下一次。
场景二、三：菜单与密码，都是"先给一次机会"

菜单：至少显示一次

int op;
do {
  printf("1.录入 2.查询 0.退出\n");
  scanf("%d", &op);
  /* 按 op 处理 */
} while (op != 0);

密码：至少试一次

int pw, cnt = 0;
do {
  printf("密码：");
  scanf("%d", &pw);
  cnt++;
} while (pw != 123456 && cnt < 3);
规律菜单、密码、猜数字、游戏"再来一局"——凡是先给对方一次机会的交互，都是 do-while 的地盘。
经典题：统计一个整数有几位
题目输入一个非负整数，输出位数。0 也是一位数。
int n, c = 0;
scanf("%d", &n);
do {
    c++;          // 记一位
    n /= 10;       // 砍一位
} while (n > 0);
printf("%d\n", c);
输入 2026 → 输出 4
换成while行不行？不行！0 也是一位数。写 while (n > 0)，n = 0 就输出 0 位——错。
经典题：把数字倒着打印
int n;
scanf("%d", &n);
do {
    printf("%d", n%10); // 末位
    n /= 10;           // 砍掉
} while (n > 0);
输入 1230 → 0321
顺序不能反一定先输出末位、后砍末位。反了第一次就把个位砍掉，少打一位。
若末位有0输入 1230 会输出 0321，末尾的 0 也打出来了。
若要"倒序后的数值"，得先累加再输出。
轮nn % 10已输出n /= 10 后
11233312
2122321
3113210 → 停
经典题：辗转相除法求最大公约数
int a, b, r;
scanf("%d%d", &a, &b);
do {
    r = a % b;   // 求余数
    a = b;       // 除数上移
    b = r;       // 余数变除数
} while (r != 0);
printf("gcd=%d\n", a);
适合用 do-while不先做一次除法，根本不知道余数是不是 0。
验一遍a=12, b=8 → r=4, a=8, b=4 → r=0, a=4 → 退出，gcd = 4 ✓
写循环前，先问自己五个问题
  • ① 重复做什么放进 do { } 里的循环体
  • ② 靠什么控制每轮都在变的那个量
  • ③ 初值多少写在 do 之前，和 while 一样
  • ④ 每轮怎么变推进写在循环体里，漏了就死循环
  • ⑤ 什么情况停把它反过来写进 while( )
前四问不变第五问才是分水岭：你写的不是"什么时候停"，而是"什么时候继续"。
套到成绩统计上① 重复读成绩并累加　② 靠成绩本身控制　③ 无初值可给　④ 每轮再读一个　⑤ 停：读到 -1 → 写 while (score != -1)
while、do-while、for，到底用哪个
情形选它理由
次数已知（1 到 100）for三要素写在一行
次数未知，可能不做while先判断，不成立就跳过
次数未知，至少做一次do-while先执行，贴合"先试一次"
中途要跳出break三者通用
拿不准就问一句"第一轮是不是无论如何都要做？" 是 → do-while；否 → while。
别硬凑该用 while 的地方硬套 do-while，就会多执行一次——那是 bug，不是风格。
随堂检测：两题，动笔推一遍

第 1 题：s 等于多少？

int i = 1, s = 0;
do {
    s += i;
    i += 2;
} while (i < 10);

答案：s = 25

第 2 题：输出什么？

int n = 5;
do {
    printf("%d", n--);
} while (n);

答案：54321

考点第 1 题考"先加后判"；第 2 题里 while(n) 等价于 while(n != 0)，非 0 即真。
本讲小结
一句话while 可以是 0 次，do-while 至少 1 次。
两个陷阱结尾分号；条件为真"继续"，不是"停止"。
三个场景do-whilewhile
输入校验不问一次，拿什么判断合不合法循环前得先读一遍
菜单交互菜单至少要露一次面得在循环前再打印一遍
位数统计0 也是一位数n = 0 输出 0 位，错
