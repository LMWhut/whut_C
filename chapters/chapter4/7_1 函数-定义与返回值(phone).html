⬇️ 顺序结构

从上到下，一句一句执行

🔀 选择结构

🔁 循环结构

但是三种结构解决的全是「怎么走」的问题。写到最后，代码还是密密麻麻全挤在 main 里，一百多行，从上拉到下。
这一章解决的是「怎么分」：把一个大程序切成几个小块，每块只管一件事，各自有名字。这个小块，就叫函数。
三个循环，同一段事儿
/* 求 C(10,3) = 10! / (3! * 7!) */
long f1 = 1, f2 = 1, f3 = 1;
int i;

for (i = 1; i <= 10; i++) f1 *= i;
for (i = 1; i <= 3;  i++) f2 *= i;
for (i = 1; i <= 7;  i++) f3 *= i;

printf("%ld\n", f1 / (f2 * f3));
120
看出来了吗三个循环长得一模一样，只差一个上限：10、3、7。
危险在哪如果哪天要改成「累加」而不是「累乘」，你得改三处。改两处忘一处，这种错误编译器不报，运行时才出鬼。
注意这段代码没有错，能跑，结果也对。它的问题不在对错，在于这三段活儿没有名字。
不用换 double三个数都是 long，除的是整数。组合数一定除得尽，所以 %ld 就对。换成 double 反倒引入小数误差。
抽出去，给它一个名字
/* 算 k 的阶乘 */
long fact(int k)
{
    long r = 1;
    int i;
    for (i = 1; i <= k; i++) r *= i;
    return r;
}

/* 用的时候，只要说出「几的阶乘」 */
printf("%ld",
       fact(10) / (fact(3) * fact(7)));
变化三遍重复的循环 → 一个函数 + 一行调用。以后要算 20 的阶乘，也只是 fact(20)。
关键函数把「怎么做」藏了起来，只把「做什么」露在外面。看到 fact(10)，你不需要读循环，就知道它在算 10 的阶乘。
于是要改算法？只改 fact 一处，三处调用自动跟着变。
怎么拆：三段式重构法
  • ① 先写出来按顺序、选择、循环照老办法写完，先让它跑通
  • ② 圈出段落哪几行在做同一件事，用笔圈起来，给它起个名字
  • ③ 抽出去圈里的代码搬到 main 外面，补上返回值
  • ④ 换成调用原来的位置写成 名字(参数)，数据用参数送进去
三个信号，出现任意一个就该拆① 同一段代码写了第二次　·　② 一段代码能用一句话说清（「算阶乘」「打印表头」）　·　③ main 长到要滚动才看得完
别反过来不要一开始就想着「我要写几个函数」。先写通，再拆。一上来就设计函数，新生最容易卡住。
函数是什么：一个黑箱
  • ① 送进去调用时把数据放进括号，这叫参数
  • ② 里面算箱子里怎么算，外面不用管，这叫函数体
  • ③ 交回来算完把结果交回，这叫返回值；也可以不交
这就是抽象你不需要知道 fact 里面是循环还是递归，只要知道：给它 10，它给你 3628800。用一个名字，代替一整套细节。以后你写程序，靠的就是这个。
其实你早就在用了printf、scanf、sqrt 都是别人写好的函数，你只管调用，从没看过它们的源码。这一章要做的，是自己造这样的箱子。
定义一个函数：四个零件
int max(int a, int b)
{
    return a > b ? a : b;
}
读法「int 类型的 max，要两个 int，交回一个 int」。把这一句念顺，这个函数你就看懂了。
  • 返回类型int：交回什么类型；不交写 void
  • 函数名max：以后就用这个名字叫它
  • 参数表(int a, int b)：需要你给什么；不给写 ()
  • 函数体{ … }：真正干活的地方
语法骨架：一张图记住
返回类型  函数名(参数表)
{
    语句1;
    语句2;
    return 表达式;   /* 有返回值才写 */
}
位置函数要写在 main 的外面，不能写在 main 的花括号里面：C 语言不允许函数嵌套定义。
三处最容易漏① 返回类型不能省。老教材省了默认 int，现代编译器直接报错。
② 每个参数都要写类型。(int a, b) 是错的，要写 (int a, int b)。
③ 函数体后面不加分号。只有声明和调用才加分号。
对照记忆定义像「写菜谱」：材料、步骤全写清，放那儿备用。调用像「点菜」：只说菜名和份数，不管怎么做。
形态一：无返回值、无参数
/* ① 定义：写清函数名和函数体 */
void printTitle()
{
    printf("=== 成绩统计 ===\n");
    printf("学号  姓名  成绩\n");
}

int main()
{
    printTitle();      /* ② 调用 */
    printTitle();      /* 再调一次 */
    return 0;
}
void「空」的意思：不往回交值。函数干完就结束，调用处拿不到东西。
调用三件套函数名 + 括号 + 分号：printTitle(); 括号不能省，哪怕里面什么都没有。
=== 成绩统计 === 学号 姓名 成绩 === 成绩统计 === 学号 姓名 成绩
形态二：无返回值、有参数
void printScore(int no, int score)
{
    printf("第 %2d 位：%3d 分\n",
           no, score);
}

int main()
{
    printScore(1, 92);
    printScore(2, 78);
    return 0;
}
形参就是变量no 和 score 进了函数，就是两个普通变量，能读能算能打印。
一句话说清同一段活儿，换个数据再做一遍，这就是参数的用处。
第 1 位： 92 分 第 2 位： 78 分
形态三：有返回值、无参数
int getChoice()
{
    int c;
    scanf("%d", &c);
    return c;
}

int main()
{
    int op = getChoice();
    printf("你选了 %d\n", op);
    return 0;
}
什么时候用数据不用你送进去：函数自己从键盘读、自己取系统时间。括号里空着，但结果它交回来。
看清楚这一行op = getChoice();
等号右边的这一次调用，整个被它的返回值顶替。所以这一行等价于：先调函数拿到数，再赋给 op。
换个写法不接收也行：getChoice();，值被丢掉了，但函数确实执行过。
形态四：有返回值、有参数
double power(double x, int n)
{
    double r = 1.0;
    int i;
    for (i = 1; i <= n; i++) r *= x;
    return r;
}

int main()
{
    printf("%.2lf\n", power(2.0, 10));
    return 0;
}
送进去，交回来四种里用得最多的一种，也是完整形态：进去有参数，出来有返回值。数学里的函数几乎都能直接翻成这种形态。
返回值也能直接参与运算power(2,10) + 1、power(2,10) / 2 都合法，因为调用处拿到的就是一个数。
1024.00
四种形态，一张表
无返无参定义 void f()
举例：printTitle()，打印表头
无返有参定义 void f(类型 名)
举例：printScore(no, score)，打印一条记录
有返无参定义 类型 f()
举例：getChoice()，读一个选项
有返有参定义 类型 f(类型 名)
举例：power(x, n)，算乘方
怎么记两个问句就够了：它要交东西回来吗？（定 void 还是类型）它需要你给它东西吗？（定参数表空不空）。
提醒用得最多的是有返回值、有参数这一种。最简单的无返回值、无参数也别小看：把一段固定动作打包、起个名字，程序立刻好读。
return 干三件事
int check(int x)
{
    if (x < 0)
        return 0;      /* 提前走 */
    if (x > 100)
        return 100;    /* 提前走 */
    return x;          /* 正常交货 */
}
check(-5) → 0 check(95) → 95 check(120) → 100
① 立刻结束函数后面的语句一句都不再执行，直接把控制权交回调用处。
② 交回一个值值的类型必须和「返回类型」对得上。写 int 却 return 3.7，会被截成 3。
③ 一次只带一个值想带回多个？得靠指针或数组，那是第 8 章的事。
常见坑return 后面写代码 = 永远执行不到。编译器给警告，别忽略。
先声明，后使用
#include <stdio.h>

double power(double x, int n);/*声明*/
int main()
{
    printf("%.2lf\n", power(2, 10));
    return 0;
}

double power(double x, int n)/*定义*/
{
    double r = 1.0;
    while (n-- > 0) r *= x;
    return r;
}
为什么需要编译器从上往下读代码。读到 main 里的 power(2,10) 时，它还没见过这个函数，就会报「未声明的标识符」。
声明的作用提前告诉编译器：有这么个函数，长这个样子。它长什么样，就是返回类型、名字、参数表。
顺手声明也可以写成 double power(double, int);，参数名可以省，类型不能省。
声明和定义，差在哪

声明

只写返回类型、函数名、参数表，把函数体省掉，以分号结尾。可以写多次；定义写在调用之后时，必须写。

定义

把函数体完整写出来，有花括号，不加分号。只能写一次；永远必须有。

两个省事的办法① 把函数定义写在 main 前面，就不用单独声明了。
② 函数多了以后，把声明集中放在文件开头（以后配 .h 头文件就是这么来的）。
别混double power(double x, int n) 后面带分号＝声明；带花括号＝定义。看结尾就知道是哪一个。
贯穿案例：成绩统计 v1
main 变成一张目录
#include <stdio.h>
void printTitle();
void printScore(int no, int score);

int main()
{
    int score, n = 0;
    printTitle();
    while (scanf("%d", &score) == 1) {
        n++;
        printScore(n, score);
    }
    printf("共 %d 人\n", n);
    return 0;
}
两个函数各管一件事
void printTitle()
{
    printf("=== 成绩统计 ===\n");
    printf("学号  姓名  成绩\n");
}
void printScore(int no, int score)
{
    printf("第 %2d 位：%3d 分\n",
           no, score);
}
键盘输入 92 78程序输出：
=== 成绩统计 === 学号 姓名 成绩 第 1 位： 92 分 第 2 位： 78 分 共 2 人
v1 到底改善了什么
  • main 变成目录打招呼 → 一条条报成绩 → 报总数，三句话读完
  • 细节藏起来了表头长什么样、第几位怎么对齐，全在两个函数里
  • 改格式只改一处想把「分」改成「points」，只动 printScore
  • 加功能不用重写下一讲要加平均分、最高分，再挂两个函数，main 几乎不动
怎么算分对了看改需求时要动几处。动一处就改完，说明分干净了；要动五处，说明还有一段活儿没抽出来。
顺便这也是团队协作的基础：你写 printScore，同学写 average，最后在 main 里拼起来。
作业题：最大公约数和最小公倍数
题目输入两个正整数 M 和 N（都不超过 1000），输出它们的最大公约数，再输出最小公倍数，中间空一格。这版能过，12 行。
输入 511 292 输出 73 2044
算法就一句两数相除留余数，余数不为 0 就把「小数、余数」当成新的一对再做一遍；余数为 0 时，那个小数就是最大公约数。最小公倍数是两数之积再除以它，先除后乘，免得溢出。
#include <stdio.h>
int main()
{
    int m, n, a, b, r;
    scanf("%d %d", &m, &n);
    a = m;  b = n;
    while (b != 0) {  /* 辗转相除 */
        r = a % b;  a = b;  b = r;
    }
    printf("%d %d", a, m / a * n);
    return 0;
}
注意看 a 和 b停的时候 b 已经变成 0，答案留在 a 里。
同一道题，把辗转相除拎出来
int gcd(int a, int b)
{
    int r;
    while (b != 0) {
        r = a % b;
        a = b;  b = r;
    }
    return a;
}
形状两个数进去，一个数出来，跟前面那个 power(x, n) 一个形状。里面的 a、b 是形参。
int main()
{
    int m, n, g;
    scanf("%d %d", &m, &n);
    g = gcd(m, n);
    printf("%d %d", g, m / g * n);
    return 0;
}
main 剩下什么读进来、求最大公约数、算最小公倍数、打出去，四行。程序行为一点没变，511 292 进去，还是 73 2044 出来。gcd 写在 main 上面，「先声明后使用」那条也满足了。
拆与不拆，拿三个改动试一遍
① 题目改成三个数求公约数
旧写法：六行再抄一遍，变量另起一套。
新写法：gcd(gcd(a,b), c)，一行。
② 换一道新题，也要约分
旧写法：换个程序，从头再想一遍。
新写法：把 gcd 贴过去，只改输入输出。
③ 发现 a、b 写反了要改
旧写法：用一次改一次，抄三遍改三遍。
新写法：只改 gcd 里那两行。
④ 隔一周再回来看代码
旧写法：12 行，算法混在中间。
新写法：8 行，一眼看到整个流程。
说句实话总行数没有变少：函数 9 行，main 8 行，加起来比原来还多几行。少的是 main 里要同时装着的东西。拿到一个程序先读 main，能看出它在干什么，这就够了。
还有一条跨程序复用，还是得把 gcd 那九行复制走。但复制的是现成、有名字、验过的代码，不用再想一遍辗转相除怎么转。
下一道题：约分最简分式
题目输入一个分数，输出它的最简分式。分子分母都是正整数，输入形如 66/120。
输入 66/120 输出 11/20 6/12 → 1/2 11/8 → 11/8 5/5 → 1/1
怎么约分子分母同除以最大公约数。上一题那个 gcd，原样贴在这个程序的开头，一个字都没改。
#include <stdio.h>
/* gcd 那九行贴在这里，一字未改 */

int main()
{
    int zi, mu, g;
    scanf("%d/%d", &zi, &mu);
    g = gcd(zi, mu);
    printf("%d/%d", zi / g, mu / g);
    return 0;
}
main 只剩三件事读一个分数，除以 gcd，打出来。
再看一道：打印菱形图案
题目输入正奇数 n，打印高 n 的菱形，每个星号后跟一个空格。（n 已读入，变量已声明）
* * * * * * * * * * * * * * * * * * * * * * * * * 
/* 上半 */
for (i = 1; i <= (n+1)/2; i++) {
    s = (n+1)/2 - i;  /* 缩 s 格 */
    for (j = 1; j <= s; j++)
        printf("  ");
    for (j = 1; j <= 2*i-1; j++)
        printf("* ");
    printf("\n");
}
/* 下半 */
for (i = (n-1)/2; i >= 1; i--) {
    s = (n+1)/2 - i;  /* 同上 */
    for (j = 1; j <= s; j++)
        printf("  ");
    for (j = 1; j <= 2*i-1; j++)
        printf("* ");
    printf("\n");
}
两段只有一行不同上面两个 for 只有循环条件不一样，里面六行一个字不差。缩进打两个空格、星号打「星加空格」，都是两个字符一步，上下一格对一格。
一行图案，抽成一个函数
void printLine(int i, int n)
{
    int j, s = (n+1)/2 - i;
    for (j = 1; j <= s; j++)
        printf("  ");
    for (j = 1; j <= 2*i-1; j++)
        printf("* ");
    printf("\n");
}
只管一行给它第几行、总共几行，它还你一行图案。
int main()
{
    int n, i;
    scanf("%d", &n);
    for (i = 1; i <= (n+1)/2; i++)
        printLine(i, n);
    for (i = (n-1)/2; i >= 1; i--)
        printLine(i, n);
    return 0;
}
两个 for 只差 i 怎么走循环体都是 printLine(i, n)，一星后跟一个空格的写法全程序只写了一次。
三道题放在一起看
  • 最大公约数重复的是辗转相除那六行 → 抽成 int gcd(int a, int b)，main 里剩读、求、算、打
  • 约分最简分式又用一次辗转相除 → 直接调 gcd，不新写，main 里剩读、约、打
  • 打印菱形上下两半，四行一样 → 抽成 void printLine(i, n)，main 里两个 for，各一行调用
对回三个信号gcd 这条是「同一段代码写了第二次」；菱形 这条是「能用一句话说清」：打印一行，空几个、星几个；约分 这条最省事：已经有人替你写过，直接调。
自己动手这三道题在 PTA 上都有。回去各写两版，放在一起看，比听我讲十遍有用。写的时候别删旧版，两版都留着。
六个常见错误，当堂记住
① 参数漏了类型void f(int a, b) 要写成 void f(int a, int b)，每个参数都要写类型。
② 漏了返回类型f(int a) { … } 要写成 int f(int a) { … }，返回类型不能省。
③ 调用时写了类型f(int a); 要写成 f(3);，调用只给值，不写类型。
④ 忘了写 returnint f() { a + b; } 要写成 int f() { return a+b; }，没有 return，交回去的是垃圾值。
⑤ 想一次返回两个值return a, b; 里那个逗号表达式只取最后一个，实际只交回 b。一次只能返回一个值。
⑥ 定义后面加了分号int f() { … }; 要写成 int f() { … }，定义后面不加分号。
报错认法「expected ')'」多半是参数漏了类型；「control reaches end of non-void function」就是某条路上忘了 return。
随堂检测
第 1 题　哪个定义合法

下面四个函数定义，语法正确的是（单选）：

A. void f(int a, b)
B. int f(int a) { return a; }
C. f(int a) { return a; }
D. int f(int a) { a + 1; }
看解析
选 B。A 第二个参数 b 没写类型，C 漏了返回类型，D 有返回值却写成 a+1;，没有 return，交回去的是个不确定的值。B 四个零件齐全。
第 2 题　swap 之后 x、y 是几
void swap(int a, int b)
{ int t = a; a = b; b = t; }

int x = 3, y = 5; swap(x, y);

此时 x、y 的值是（单选）：

A. 5 和 3
B. 3 和 5
C. 编译错
看解析
选 B，x 和 y 还是 3 和 5。调用时传进去的是值的副本：a、b 是另外两块内存，在里面怎么换都动不到 x、y。这一讲先记住结论，下一讲讲透为什么，第 8 章用指针才能真正换过来。
第 3 题　两次调用加起来是几
int f(int n) { return n > 0 ? n : -n; }

f(-7) + f(3)

上面这个式子的值是（单选）：

A. -4
B. 4
C. 10
D. 7
看解析
选 C，10。f(-7) 返回 7，f(3) 返回 3，7 + 3 = 10。注意这一行里发生了两次独立调用，各自算各自的，互不影响。
第 4 题　判断：要不要拆

连续 6 行「读数 → 判断奇偶 → 打印」，在三个地方原样出现。要不要抽成函数？

A. 不用，能跑就行
B. 要，第二次就该拆
看解析
选 B。同一段代码出现第二次，就是最硬的拆分信号；而且这六行能一句话说清（「读一个数，判断奇偶，打印」），三条信号占了两条。抽成 void checkOne() 之后，三处都变成一行调用，将来改打印格式只改一处。
本讲小结
  • ① 为什么要拆main 越长，改一处越容易漏三处
  • ② 怎么拆写出来 → 圈重复 → 抽出去 → 原处换调用
  • ③ 四个零件返回类型、函数名、参数表、函数体
  • ④ 四种形态有无返回值 × 有无参数，两个问句就能定
  • ⑤ 拿作业试过gcd、约分、菱形，三道题都改成了函数版
记住这一条函数就是给一段代码起名字。有了名字，你才能在另一处说「把这件事做一遍」，而不必把细节再抄一遍。
