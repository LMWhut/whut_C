本讲主线一句话打底：for 就是把三要素并排写在一行里的 while。
先认语法与盒图 → 会双向改写 → 跟踪到不差一 → 三个经典题练手 → 按"次数知不知道"选循环。
本讲学习目标
  • ① 会写给出循环次数，能一次写对括号里的三段
  • ② 会读说清"哪句只做一次、哪句每轮都做"
  • ③ 会换for 与 while 双向改写，不改语义
  • ④ 会算循环结束后 i 等于几，能一口答出
  • ⑤ 会选什么时候该用 for，什么时候该用 while
案例引入：同一件事，for 把三行并成一行
while 版：三要素散在三处
int i = 1, s = 0;  // ① 初值
while (i <= 100) { // ② 条件
    s += i;
    i++;              // ③ 推进
}
for 版：三要素并排
int s = 0;
for (int i = 1; i <= 100; i++)
    s += i;
s = 5050
差别在哪三要素原来散在三个地方，现在并排站在括号里——从哪开始、到哪结束、每步走多远，一眼看全。
语法与执行流程：括号里的三段各管什么
for (表达式1; 表达式2; 表达式3)
    语句;            /* 循环体 */
位置管什么什么时候执行
表达式1初始化进循环前，只 1 次
表达式2条件每轮开头，真才进去
表达式3步进体做完后，每轮 1 次
最容易记错的一点不是走一遍就完，而是 1 → 2 → 3 → 4 → 2 → 3 → 4 → …，到 2 判假才停。
for 与 while：其实只差一个位置
while：判断在门口
int i = 1, s = 0;
while (i <= 100) {
    s += i;
    i++;
}
for：判断在中间
int i, s = 0;
for ( i = 1; i <= 100; i++)
    s += i;
本质for 不是一种新循环，它就是 while 的写法升级。两者都是"先判断、后执行"，都可以一次都不做。
什么时候选 for次数事先算得出来的场合，for 最省心。
改写规则：三步搬家，双向都通
要素whilefor
初值循环前表达式1
条件while( )表达式2
推进循环体内表达式3
 
/* for 改 while */
int i = 0;              // 搬 1
while (i < 10) {          // 搬 2
    printf("%d", i);
    i++;                  // 搬 3
}
反过来也一样把 while 前面的初值塞进第一个分号前，把括号里的条件塞到中间，把循环体末尾的推进挪到第二个分号后。
唯一要留神while 版的推进语句位置很灵活——写在循环体开头也行，但那样条件判断的时机就变了，改 for 之前先看清楚它在哪。
手工跟踪：把每一轮的 i 写在纸上
int s = 0, i;
for (i = 1; i <= 5; i++)
    s += i;
printf("%d, i=%d", s, i);
15, i=6
i 的定义能不能写在 for 里不能！循环后还要读它，所以定义在 for 外面。若写 for(int i=1;…)，出循环后 i 就没了。
高频考点循环结束后 i 等于 6，不是 5——最后那轮 i++ 照样执行了，只是判断没过。凡是问"循环后 i 是几"，答案永远是最后一个合法值再加一步。
边界与差一：跑几次，看 i 有几个合法值
写法（若 n = 10）i 依次取值次数
i=1; i<=n; i++1 … 1010
i=0; i<n; i++0 … 910
i=1; i<n; i++1 … 99
i=0; i<=n; i++0 … 1011
数次数的方法别死记，数 i 有几个合法值：从起点数到终点，含两端就是 末−始+1 个。
最稳的习惯数组下标从 0 开始就用 i<n；数第几个就从 1 开始用 i<=n。
一句话记牢想跑 n 次：从 0 开始就配 <n，从 1 开始就配 <=n。两个都往同一个方向错，才会刚好多一次或少一次。
三段都能省，但省了要负责
for (;;)              // 全部省略：死循环
for (; i <= n; )      // 退化成 while
for (i = 0; i < n; )  // 省略推进：死循环
for (i = 1, j = 10;   // 逗号管两个
     i < j; i++, j--)
逗号表达式括号里可以用逗号写多个动作，从左到右依次执行，整个表达式的值是最后一个的值。
教学提醒省略三段是"看得懂、但别写"。尤其别省表达式3——循环变量不再变，直接死循环。
阅读题常考for (i = 5; i; i--) 里的 i 当条件用，等价于 i != 0——非 0 即真，0 即假。
陷阱一：for 后面多打一个分号

✓ 正确：分号只在括号里

int s = 0, i;
for (i = 1; i <= 5; i++)
    s += i;
// s = 15 ✓

✗ 错误：括号后多一个分号

int s = 0, i;
for (i = 1; i <= 5; i++);
    s += i;
// s = 6 ✗
为什么那个分号是一条空语句，被当成了循环体。循环老老实实空转了 5 次，s += i 只在循环结束后执行了一次，此时 i = 6。
陷阱它不报错、不警告，编译通过，结果只是悄悄变错。所以写完 for 先看一眼括号后面有没有多余的分号。
陷阱二：在循环体里又动了 i
✗ 想打 01234，结果打了 024
for (int i = 0; i < 5; i++) {
    printf("%d", i);
    i++;      // 多余
}
0 2 4
✓ 想隔一个打一个：直接写步长
for (int i = 0; i < 5; i += 2)
    printf("%d", i);
// 0 2 4 ✓
记住分工推进由 for 替你完成。你在循环体里再动一次 i，等于每轮推了两步——想改步长，改表达式3，别在体里偷偷加。
陷阱三：拿浮点数当循环变量

✗ 死循环：永远等不到 1.0

for (double x = 0; x != 1.0; x += 0.1)
    printf("%.1f ", x);

✓ 用整数计数再换算

for (int i = 0; i < 10; i++)
    printf("%.1f ", i * 0.1);
为什么0.1 在二进制里是无限循环小数，存进去就有误差。累加 10 次得到的是 0.999…9 或 1.000…1，恰好不等于 1.0，条件永远为真。
规律循环变量用 int；实在要用浮点，条件写成 x < 1.0 - 1e-9 这种区间判断，别用 !=。
循环变量活了多久：C99 的一个小坑

✗ 出了循环就没了：编译报错

for (int i = 0; i < 5; i++)
    printf("%d", i);
printf("%d", i);  // i 未定义
error: 'i' undeclared

✓ 外面先定义：循环后还能用

int i;
for (i = 0; i < 5; i++)
    printf("%d", i);
printf("%d", i);  // i = 5
规矩在 for (int i = …) 里定义的 i，作用域只到循环结束。循环外要用它，就得先在外面定义。
版本提醒这种写法要 C99 及以上。用老教材、老编译器（C89、VC6）会直接报错——上机前先确认编译环境。
经典题一：累加与累乘
累加：初值写 0
int s = 0, x, n = 5;
for (int i = 0; i < n; i++) {
    scanf("%d", &x);  s += x;
}
printf("%.2f", (double)s / n);
累乘：初值写 1
double f = 1;
for (int i = 1; i <= 5; i++) f *= i;
printf("%.0f", f);  // 120
初值最容易写反累加器初值 0，累乘器初值 1。把累乘写成 0，从头到尾乘出来还是 0。
经典题二：百钱百鸡——循环能剪掉一层
✗ 三层硬试：7 万余次
for (x = 0; x <= 20; x++)
  for (y = 0; y <= 33; y++)
    for (z = 0; z <= 100; z++)
      if (x+y+z == 100
       && 5*x+3*y+z/3.0 == 100)
        printf("%d %d %d\n",x,y,z);
✓ 算掉一层：只有 714 次
for (x = 0; x <= 20; x++)
  for (y = 0; y <= 33; y++) {
    z = 100 - x - y;
    if (5*x+3*y+z/3.0 == 100)
      printf("%d %d %d\n",x,y,z);
  }
省了多少21 × 34 × 101 = 72114 次，剪掉一层后 21 × 34 = 714 次——差了 100 倍。
剪枝的思路鸡的总数是 100 只，x、y 定了，z 就定了，不必再试。能算出来的量，就别让它进循环。
经典题三：判断素数——for 与 break 的配合
int m, i;
scanf("%d", &m);
for (i = 2; i * i <= m; i++)
    if (m % i == 0)
        break;      // 找到因子
if (i * i > m && m > 1)
    puts("是素数");
else
    puts("不是");
为什么试到 √m 就够大于 √m 的因子必与一个小于 √m 的配对；写 i*i<=m 还避开浮点误差。
循环后看 i 就知道结果break 出来的 i·i ≤ m，找到了因子；循环走完的 i·i > m，没找到。
写循环前，先问自己五个问题
  • ① 重复做什么放进循环体，多条就用 { } 包起来
  • ② 靠什么控制循环变量，一般叫 i、j、k
  • ③ 从几开始填进表达式1，只执行一次
  • ④ 每轮怎么变填进表达式3，多半是 i++
  • ⑤ 什么时候继续填进表达式2，写"继续"不写"停止"
for 的好处就在这前四问 while 要你自己找地方安放，for 给每一问都留好了格子——少一样，括号里就看得出来。
while、do-while、for，到底用哪个
情形选它理由
次数已知（1 到 100）for三要素写在一行
次数未知，可能不做while先判断，不成立就跳过
次数未知，至少做一次do-while先执行，贴合"先试一次"
中途要跳出break三者通用
拿不准就问一句"一共要转几圈，事先知道吗？" 知道 → for；不知道 → while 或 do-while。
三个语句的选择三者可以互相改写，选型是为了让代码一眼看出意图，不是为了追求某种"正宗"。
随堂检测：两题，动笔推一遍

第 1 题：s 和 i 各是多少？

int s = 0, i;
for (i = 1; i <= 10; i += 2)
    s += i;

答案：s = 25，i = 11

第 2 题：输出什么？

for (int i = 5; i; i--)
    printf("%d", i);

答案：54321

考点第 1 题考结束后 i 多加了 2（1,3,5,7,9 之后变成 11）；第 2 题里 i 当条件，非 0 即真，i = 0 时退出。
怎么算"过关"两题都不许心算：拿纸画一张两列的跟踪表（轮次 ｜ i ｜ 条件 ｜ s），一行一行填。第 1 题填 5 行，第 2 题填 5 行——填完答案自己就出来了。
本讲小结
一句话for 就是把三要素并排写在一行里的 while。同样先判断后执行，同样可以一次都不做——区别只在"三要素住哪儿"。
  • ① 三要素缺初始化＝拿垃圾值去算；缺步进＝死循环。三个都得在。
  • ② 别加分号for (...) 后面多打一个分号，循环体就变成那个空语句，循环白转。
  • ③ 别再动 i步进已经管了 i，循环体里再改就会跳数、少跑或多跑。
  • ④ 多走一步i<=5 走完时 i 是 6；i=0;i<n 走完时 i 是 n。问"循环后 i 是几"永远是这个答案。
  • ⑤ 别用浮点0.1 累加十次不等于 1，拿浮点数当循环变量必然多跑或少跑一轮。
